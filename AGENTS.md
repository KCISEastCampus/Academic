# AGENTS.md

Agent-facing instructions for the Academic repository — a Jekyll static site (GitHub Pages) hosting IGCSE / A-level study materials for Kang Chiao International School, East Campus.

## Agent skills

### Issue tracker

Issues live in GitHub Issues for `KCISEastCampus/Academic`; use the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five default triage labels are used: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout: one `CONTEXT.md` plus `docs/adr/` at the repo root. See `docs/agents/domain.md`.
