中文讲解帮助理解，英文术语与真题题干帮助适应考试。每个主题按“先想一想 → 概念与方法 → 真题尝试 → 提示 → 评分解析 → 改错复做”学习。准备纸笔；第一次做题时，把提示和解析保持收起。

## 怎样使用这些内容

- **新学知识：**按顺序读概念，先自己完成“先想一想”，再做紧接该知识点的真题。
- **作业遇到困难：**先打开提示，只查当前卡住的步骤；完成自己的答案后再看解析。
- **考前复习：**跳到真题，计时完成，按每一个评分点自查。分数之外，记录具体错误，例如“漏乘两个离子的水合焓”“把中性直接等同于 pH 7”。

每次改错写下：**原答案 → 错因 → 修正答案 → 隔天闭卷重做**。对于解释题，要能写出英文关键词和完整因果关系；对于方程式，要同时检查原子、电荷、状态和配体数。

## 开始前的 AS 检查

这些是**自拟诊断任务**，没有官方分值。先在纸上完成，再对照答案；做错哪项，就补哪项。

1. $25.0\,\mathrm{cm^3}$ 的 $0.100\,\mathrm{mol\,dm^{-3}}$ NaOH 含多少 mol？
2. 若某反应 $\Delta H=-120\,\mathrm{kJ\,mol^{-1}}$，反向反应的 $\Delta H$ 是多少？
3. 写出 Fe²⁺ 的完整电子排布。
4. 配平酸性条件下 $\ce{MnO4^- -> Mn^{2+}}$ 的还原半反应。
5. $\mathrm{p}K_a=4.80$ 时，$K_a$ 是多少？

<details markdown="1">
<summary>核对 AS 基础</summary>

1. $n=cV=0.100\times0.0250=2.50\times10^{-3}\,\mathrm{mol}$。
2. $+120\,\mathrm{kJ\,mol^{-1}}$；反向改变符号，倍乘反应还要倍乘焓变。
3. $1s^22s^22p^63s^23p^63d^6$；先移除 4s 电子。
4. $\ce{MnO4^- + 8H+ + 5e^- -> Mn^{2+} + 4H2O}$。
5. $K_a=10^{-4.80}=1.58\times10^{-5}\,\mathrm{mol\,dm^{-3}}$。

</details>

## 实验与真题

**RP6（测量 EMF）**在电极电势页；**RP7（酸碱滴定中的 pH 变化）**在酸碱页；**RP9（鉴别过渡金属离子）**在离子反应页。这里训练实验设计与笔试分析，实际操作应在老师指导下完成。
