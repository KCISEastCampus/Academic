第三周期不只是背一个性质趋势。每次解释都按 **结构 → 成键或作用力 → 需要克服的相互作用 → 可观察性质** 写完整。

**先想一想：**SiO₂ 不溶于水，是否说明它不是酸性氧化物？先区分“和水反应”与“和碱反应”。

<span id="elements-and-oxides"></span>

## P1：元素、氧化物与酸碱性

Na、Mg、Al 是金属，具有金属键；从 Na 到 Al，离子电荷与离域电子数增加、半径减小，金属键一般增强。Si 是巨型共价结构，需要破坏大量共价键才熔化。P₄、S₈、Cl₂ 是分子物质，熔化主要克服分子间作用力；S₈ 的分子较大，分子间作用力比 P₄ 更强。Ar 是单原子物质，粒子间只有较弱的 London forces。

**不要把熔化分子物质解释成“打断分子内共价键”。**先辨认是巨型结构还是独立分子。

### 与氧、氯反应的方程式

氧化物反应：$\ce{4Na + O2 -> 2Na2O}$；$\ce{2Mg + O2 -> 2MgO}$；$\ce{4Al + 3O2 -> 2Al2O3}$；$\ce{Si + O2 -> SiO2}$；$\ce{P4 + 5O2 -> P4O10}$；$\ce{S + O2 -> SO2}$。SO₃ 常由 $\ce{2SO2 + O2 <=> 2SO3}$ 在适当催化条件下制得，不能把硫燃烧的主要产物写成 SO₃。

氯化物反应：$\ce{2Na + Cl2 -> 2NaCl}$；$\ce{Mg + Cl2 -> MgCl2}$；$\ce{2Al + 3Cl2 -> Al2Cl6}$；$\ce{Si + 2Cl2 -> SiCl4}$；$\ce{P4 + 10Cl2 -> 4PCl5}$（氯过量）。氯不足时可先生成 PCl₃，不能忽略题目给的反应条件。

Na 与水：$\ce{2Na + 2H2O -> 2NaOH + H2}$；与 Mg 比较时，要分别说明产物、反应快慢与金属性。方程式练习按题目要求加状态符号；尤其注意 PCl₅ 在室温为固体。

| 氧化物 | 结构／成键 | 酸碱性质与主要反应 |
| --- | --- | --- |
| Na₂O | 巨型离子结构 | 碱性；与水形成 NaOH，溶液强碱性 |
| MgO | 巨型离子结构；离子吸引较强，熔点高 | 碱性；与水反应／溶解程度小，形成微溶 Mg(OH)₂；与酸反应 |
| Al₂O₃ | 巨型晶格，成键含离子性与共价性 | 两性；与酸和强碱反应，不与水明显反应 |
| SiO₂ | 巨型共价结构 | 酸性；不与水反应，可与热浓碱反应 |
| P₄O₁₀ | 分子型共价氧化物（常见分子形式） | 酸性；与水形成 H₃PO₄ |
| SO₂、SO₃ | 分子型共价氧化物 | 酸性；与水分别形成酸性体系、H₂SO₄ |

跨周期由金属性转向非金属性，氧化物总体从碱性经两性转为酸性。**水溶性不决定酸碱分类**；SiO₂ 的酸性可由其与碱反应说明。

必须会写的反应：

$$\ce{Na2O + H2O -> 2NaOH},\qquad\ce{MgO + 2H+ -> Mg^{2+} + H2O}.$$

$$\ce{Al2O3 + 6H+ -> 2Al^{3+} + 3H2O}.$$

$$\ce{Al2O3 + 2OH^- + 3H2O -> 2[Al(OH)4]^-},\qquad\ce{SiO2 + 2OH^- -> SiO3^{2-} + H2O}.$$

后两式涉及合适的强碱与反应条件，不能理解为所有氧化物放入稀碱都立即反应。

$$\ce{P4O10 + 6H2O -> 4H3PO4},\qquad\ce{SO3 + H2O -> H2SO4}.$$

SO₂ 溶于水形成酸性平衡，可用 $\ce{SO2 + H2O <=> H2SO3}$ 表示；它不像 Na₂O 那样生成强碱。H₃PO₄ 和该含 SO₂ 的体系是弱酸体系，H₂SO₄ 的第一步电离很强，因此不能只按“酸的分子里 H 的个数”比较相同浓度的 pH。

### 酸及阴离子的结构

画结构时，把酸性 H 接在 O 上，然后依次移去 H⁺、给对应 O 标负电荷：

| 酸的连接方式 | 阴离子 | 画图检查 |
| --- | --- | --- |
| H₃PO₄：$\ce{O=P(OH)3}$ | H₂PO₄⁻、HPO₄²⁻、PO₄³⁻ | P 周围四个 O，四面体排列；三条 O–H 可逐步电离 |
| H₂SO₃ 的教材表示：$\ce{O=S(OH)2}$ | HSO₃⁻、SO₃²⁻ | S 周围三个 O，并有孤对电子，SO₃²⁻ 为三角锥形 |
| H₂SO₄：$\ce{O=S(=O)(OH)2}$ | HSO₄⁻、SO₄²⁻ | S 周围四个 O，四面体排列；两个 H 连在 O 上 |
| SiCl₄ 水解的含 Si–OH 中间物：$\ce{Si(OH)4}$ | 碱反应常以 SiO₃²⁻ 表示硅酸盐 | 四个 O 围绕 Si；可缩合成含 Si–O–Si 的水合 SiO₂ |

这些是连接关系与考试画图模型；阴离子存在电子离域，不能把某一条双键的位置当作唯一真实局域结构。**自拟任务：**画出 H₃PO₄ 与 H₂PO₄⁻，检查移去的是 H⁺，不是整段 OH⁻。

### 真题：镁与冷水、蒸汽

**OxfordAQA CH03 · June 2026 · 01.1 · 2 marks**

> Magnesium reacts slowly with cold water but rapidly with steam.
>
> State one similarity and one difference between the products of these reactions.

<details markdown="1">
<summary>提示：比较产物，不是比较速率</summary>

两次都有哪种气体？两种条件下的固体产物相同吗？

</details>

<details markdown="1">
<summary>评分解析：MS 第 12 页</summary>

相同：都生成 H₂，1 分。不同：冷水生成 Mg(OH)₂，蒸汽生成 MgO，1 分。

$$\ce{Mg + 2H2O(l) -> Mg(OH)2 + H2},\qquad\ce{Mg + H2O(g) -> MgO + H2}.$$

题目已说明速率；重复“蒸汽反应快”没有回答产物的区别。

</details>

### 真题：磷燃烧后加入水

**OxfordAQA CH03 · June 2026 · 01.2 · 2 marks**

> A sample of phosphorus is heated in an excess of oxygen. When the reaction is complete, some water is added to the product and a second reaction occurs.
>
> Write an equation for the reaction between phosphorus and an excess of oxygen.
>
> Write an equation for the reaction that occurs when water is added to the product.

<details markdown="1">
<summary>提示：先确定充分氧化产物</summary>

使用 P₄O₁₀，第二步产物为 H₃PO₄。不要漏配第一步 O₂ 或第二步水的系数。

</details>

<details markdown="1">
<summary>评分解析：MS 第 12 页</summary>

$\ce{P4 + 5O2 -> P4O10}$；$\ce{P4O10 + 6H2O -> 4H3PO4}$，各 1 分。练习中使用分子式 P₄O₁₀，不把经验式 P₂O₅ 当作同一题的分子式。

</details>

### 真题：Al₂O₃ 的酸性反应与水中现象

**OxfordAQA CH03 · January 2025 · 08.2–08.3 · 1 + 1 marks**

> **08.2** Write an equation to show the reaction of aluminium oxide with hydrochloric acid.
>
> **08.3** Aluminium oxide is added to an excess of water. Describe what is observed.

<details markdown="1">
<summary>提示：两性不等于水溶性</summary>

酸反应写出盐与水；第二问只写可见观察。

</details>

<details markdown="1">
<summary>评分解析：MS 第 26 页</summary>

08.2：$\ce{Al2O3 + 6HCl -> 2AlCl3 + 3H2O}$，1 分。08.3：无可见变化，或白色固体仍存在，1 分。不能说“没有反应，所以不是两性”。

</details>

## P2：氯化物、溶解与水解

先区分两个过程：**dissolution** 让原有物种进入溶液；**hydrolysis** 涉及物种与水反应。跨周期的氯化物不能全部用同一种模型解释。

| 氯化物 | 结构线索 | 加水后的解释 |
| --- | --- | --- |
| NaCl | 离子晶体 | 溶解为 Na⁺、Cl⁻，溶液近中性 |
| MgCl₂ | 主要为离子晶体 | 溶解；水合 Mg²⁺ 使溶液略显酸性 |
| AlCl₃ | 无水物有显著共价性，可形成 Al₂Cl₆ | 在水中形成水合 Al³⁺，发生酸性水解 |
| SiCl₄ | 简单分子，共价 | 与水反应，形成含硅产物及 HCl，出现酸性体系 |
| PCl₅ | 固态可用 $\ce{[PCl4]+[PCl6]^-}$ 描述；气态为分子 | 过量水最终生成 H₃PO₄ 和 HCl |

Al₂Cl₆ 中有桥联氯和配位键，不能把它画成两个互不相连的 AlCl₃。水合 Al³⁺ 的酸性在 [离子反应](/alevel/a2-chemistry/ions-in-solution/#aqua-acidity) 中继续解释。

氯化物熔点也要先按结构解释：NaCl、MgCl₂ 的巨型离子晶格需要克服离子间强吸引；无水 Al₂Cl₆、SiCl₄ 等分子物质的相变主要克服分子间作用力。PCl₅ 的固态结构与气态不同，不能把它简单套进“所有右侧氯化物都是常温液体”的规则。

$$\ce{SiCl4 + 2H2O -> SiO2 + 4HCl},\qquad\ce{PCl5 + 4H2O -> H3PO4 + 5HCl}.$$

SiCl₄ 水解可先经含 Si–OH 的物种，再形成水合二氧化硅；上述为常用总体式。观察题应区别“白色烟雾”“白色沉淀”“白色固体”，按实际情境作答。

### 真题：从状态和反应判断结构

**OxfordAQA CH03 · June 2026 · 01.3 · 1 mark**

> A Period 3 element forms a chloride Q. Q is a liquid at room temperature and reacts with water to form a solution with low pH.
>
> Identify the bonding and name the type of structure in Q.

<details markdown="1">
<summary>提示：常温液体提示哪种结构？</summary>

比较巨型离子晶格与简单分子物质的粒子间作用力。

</details>

<details markdown="1">
<summary>评分解析：MS 第 12 页</summary>

**Covalent bonding；simple molecular structure**。两项均正确得 1 分。不要仅由“溶液导电／酸性”倒推原物质必为离子晶体；分子物质也可以与水反应形成离子。

</details>
