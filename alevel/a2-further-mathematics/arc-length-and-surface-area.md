[Further Pure Mathematics](/alevel/a2-further-mathematics/) · FP2.8 Arc length and area of surface of revolution about the x-axis

Find the length of a curve in Cartesian or parametric form. Then use that length element to find the area swept out when the curve is revolved about the x-axis.

- **Learning:** start with the [method](#method), then work through the examples.
- **Homework help:** choose [Cartesian arc length](#cartesian-arc-length), [parametric arc length](#parametric-arc-length) or [surface area](#surface-area-about-the-x-axis).
- **Revision:** try [practice](#practice) before opening the solutions, then use the [quick reference](#quick-reference).

Textbook: Chapter 23, pp. 282–287, in *International A Level Further Mathematics*.

**Before you start:** review [differentiation](/alevel/a2-mathematics/differentiation/), [integration](/alevel/a2-mathematics/integration/) and [parametric equations](/alevel/a2-mathematics/parametric-equations/). You should be able to differentiate a curve, evaluate definite integrals and use a positive square root.

## Method {#method}

**Learning goal:** choose the correct arc-length formula, set limits that cover the required arc once, and calculate the surface area generated by revolving that arc about the x-axis.

The small length of a curve is written as $\mathrm ds$. Add these small lengths to find the whole arc length. The square-root factor in the arc-length formula is always non-negative.

| Curve is given as | Length element | Arc length |
|---|---|---|
| $y=f(x)$, with $a\le x\le b$ | $\displaystyle\mathrm ds=\sqrt{1+\left(\frac{\mathrm dy}{\mathrm dx}\right)^2}\,\mathrm dx$ | $\displaystyle L=\int_a^b\sqrt{1+\left(\frac{\mathrm dy}{\mathrm dx}\right)^2}\,\mathrm dx$ |
| $x=x(t),\ y=y(t)$, with $\alpha\le t\le\beta$ | $\displaystyle\mathrm ds=\sqrt{\left(\frac{\mathrm dx}{\mathrm dt}\right)^2+\left(\frac{\mathrm dy}{\mathrm dt}\right)^2}\,\mathrm dt$ | $\displaystyle L=\int_\alpha^\beta\sqrt{\left(\frac{\mathrm dx}{\mathrm dt}\right)^2+\left(\frac{\mathrm dy}{\mathrm dt}\right)^2}\,\mathrm dt$ |

For a surface of revolution about the x-axis, a short strip of the curve sweeps out a narrow band. The corresponding circle has circumference $2\pi r$, where the radius is the distance from the curve to the x-axis:

$$r=\lvert y\rvert.$$

So the band area is approximately $2\pi\lvert y\rvert\,\mathrm ds$. Adding the bands gives

| Curve is given as | Surface area about the x-axis |
|---|---|
| $y=f(x)$ | $\displaystyle S=2\pi\int_a^b\lvert y\rvert\sqrt{1+\left(\frac{\mathrm dy}{\mathrm dx}\right)^2}\,\mathrm dx$ |
| $x=x(t),\ y=y(t)$ | $\displaystyle S=2\pi\int_\alpha^\beta\lvert y\rvert\sqrt{\left(\frac{\mathrm dx}{\mathrm dt}\right)^2+\left(\frac{\mathrm dy}{\mathrm dt}\right)^2}\,\mathrm dt$ |

**Check the limits and absolute values.**

- Use increasing x-limits in a Cartesian integral. For a parametric curve, use increasing t-limits. The square-root factor is a speed, so these choices make the length non-negative.
- If the curve crosses the x-axis, the radius is still $\lvert y\rvert$. Split the integral at a crossing if that makes the absolute value easier to evaluate.
- If a square root simplifies to $\sqrt{g^2}$, write $\lvert g\rvert$ first. Remove the absolute value only after checking the interval.
- The parameter interval must trace the requested arc once. If the parameter retraces part of the curve, the integral counts that part again.
- For surface area, also check whether different parts of the generating curve sweep over the same surface patch. Count each patch once. For example, the upper and lower semicircles both sweep out the same sphere when revolved about their diameter.

The formula gives the curved surface only. It does not add circular end caps; include caps only if a question asks for the area of a solid's complete boundary.

## Cartesian Arc Length {#cartesian-arc-length}

For $y=f(x)$, differentiate with respect to x, square the gradient, add 1, and integrate the positive square root between the stated x-coordinates.

$$L=\int_a^b\sqrt{1+\left(\frac{\mathrm dy}{\mathrm dx}\right)^2}\,\mathrm dx.$$

The variable is x throughout, so keep the limits as x-values. If an endpoint makes the derivative or integrand undefined, treat the integral as a limit from inside the interval.

## Parametric Arc Length {#parametric-arc-length}

When both coordinates depend on t, differentiate both coordinates with respect to t. The speed is the length of the velocity vector:

$$\frac{\mathrm ds}{\mathrm dt}=\sqrt{\left(\frac{\mathrm dx}{\mathrm dt}\right)^2+\left(\frac{\mathrm dy}{\mathrm dt}\right)^2}.$$

Then integrate with respect to t:

$$L=\int_\alpha^\beta\frac{\mathrm ds}{\mathrm dt}\,\mathrm dt.$$

Do not use only $\frac{\mathrm dx}{\mathrm dt}$ or only $\frac{\mathrm dy}{\mathrm dt}$. Both directions contribute to the distance travelled along the curve.

## Surface Area About the x-axis {#surface-area-about-the-x-axis}

At each point of the curve, the rotation radius is its distance from the x-axis, $\lvert y\rvert$. Multiply the circumference $2\pi\lvert y\rvert$ by the curve length element $\mathrm ds$.

$$S=\int 2\pi\lvert y\rvert\,\mathrm ds.$$

In Cartesian coordinates, substitute the Cartesian length element. In parametric coordinates, substitute the parametric length element. Make sure the limits describe just the generating arc required.

**Do not confuse two kinds of repetition.** If a parameter traces the same arc more than once, the arc-length integral counts each traversal. Separately, a single arc can generate the same surface patch more than once under rotation; then the surface-area integral also counts that patch more than once. In either case, choose limits that cover the required geometric object once.

## Worked Examples {#worked-examples}

### Example 1 — Cartesian arc length by substitution {#example-1--cartesian-arc-length-by-substitution}

**Question:** Find the length of the curve $y=\frac23x^{\frac32}$ for $0\le x\le3$.

Differentiate and use the Cartesian formula:

$$\frac{\mathrm dy}{\mathrm dx}=\sqrt{x}.$$

$$\begin{aligned}
L&=\int_0^3\sqrt{1+x}\,\mathrm dx\\
&=\left[\frac23(1+x)^{\frac32}\right]_0^3\\
&=\boxed{\frac{14}{3}}.
\end{aligned}$$

**Check:** the integrand is positive throughout the interval, and the answer is greater than the horizontal distance $3$.

### Example 2 — Keep the absolute value from a square root {#example-2--keep-the-absolute-value}

**Question:** Find the length of $y=\frac{x^2}{4}-\frac12\ln x$ for $1\le x\le2$.

First find the gradient. The expression under the square root becomes a perfect square:

$$\frac{\mathrm dy}{\mathrm dx}=\frac{x^2-1}{2x},\qquad
1+\left(\frac{\mathrm dy}{\mathrm dx}\right)^2=\frac{(x^2+1)^2}{4x^2}.$$

Therefore

$$\sqrt{1+\left(\frac{\mathrm dy}{\mathrm dx}\right)^2}
=\frac{\lvert x^2+1\rvert}{2\lvert x\rvert}
=\frac{x^2+1}{2x},\qquad 1\le x\le2.$$

The final equality uses $x>0$ and $x^2+1>0$ on the whole interval.

$$\begin{aligned}
L&=\int_1^2\frac{x^2+1}{2x}\,\mathrm dx\\
&=\left[\frac{x^2}{4}+\frac12\ln x\right]_1^2\\
&=\boxed{\frac34+\frac12\ln2}.
\end{aligned}$$

**Check:** replacing $\sqrt{g^2}$ directly by $g$ is only valid when $g\ge0$ on the interval. Here that is true, but it must be checked.

### Example 3 — Parametric arc length from an adapted specimen question {#example-3--adapted-specimen-question}

**Question (adapted):** A curve is defined by $x=\ln(\sec t+\tan t)-\sin t$ and $y=\cos t$, for $0\le t\le\frac{\pi}{3}$. Find its arc length.

Differentiate each coordinate:

$$\frac{\mathrm dx}{\mathrm dt}=\sec t-\cos t=\frac{1-\cos^2t}{\cos t}=\sin t\tan t,\qquad
\frac{\mathrm dy}{\mathrm dt}=-\sin t.$$

The speed is

$$\begin{aligned}
\frac{\mathrm ds}{\mathrm dt}
&=\sqrt{\sin^2t\tan^2t+\sin^2t}\\
&=\sqrt{\sin^2t\sec^2t}\\
&=\lvert \sin t\rvert\,\lvert \sec t\rvert\\
&=\tan t,\qquad 0\le t\le\frac{\pi}{3}.
\end{aligned}$$

Sine is non-negative and secant is positive on this interval. Hence

$$\begin{aligned}
L&=\int_0^{\frac{\pi}{3}}\tan t\,\mathrm dt\\
&=[-\ln(\cos t)]_0^{\frac{\pi}{3}}\\
&=\boxed{\ln2}.
\end{aligned}$$

**Check:** the speed is non-negative and the interval covers the arc once. This example is adapted from Question 11 of the [OxfordAQA FM03 Specimen 2018 paper](https://www.oxfordaqa.com/oaqaresources/maths/assessment/9665-FM03-international-a-level-further-mathematics-specimen-paper-2019-v3.pdf); its method is supported by the [official mark scheme](https://www.oxfordaqa.com/oaqaresources/maths/assessment/9665-FM03-international-a-level-further-mathematics-mark-scheme-2016-v1.pdf). The question wording is adapted, and the working here is written for this lesson.

### Example 4 — Rotate a Cartesian line about the x-axis {#example-4--cartesian-surface-area}

**Question:** Find the area swept out when $y=4-x$, $1\le x\le3$, is revolved about the x-axis.

On this interval, $y\ge0$, so the radius is $y=4-x$. Also, $\frac{\mathrm dy}{\mathrm dx}=-1$:

$$\begin{aligned}
S&=2\pi\int_1^3(4-x)\sqrt{1+(-1)^2}\,\mathrm dx\\
&=2\pi\sqrt2\left[4x-\frac{x^2}{2}\right]_1^3\\
&=\boxed{8\pi\sqrt2}.
\end{aligned}$$

**Check:** the radius decreases from 3 to 1, and no end disks are included.

### Example 5 — Parametric surface area when the curve crosses the axis {#example-5--radius-absolute-value}

**Question:** Find the area swept out when $x=t$, $y=t-1$, $0\le t\le2$, is revolved about the x-axis.

The radius is $\lvert t-1\rvert$, not $t-1$. The speed is constant:

$$\frac{\mathrm dx}{\mathrm dt}=1,\qquad
\frac{\mathrm dy}{\mathrm dt}=1,\qquad
\frac{\mathrm ds}{\mathrm dt}=\sqrt2.$$

Split at the crossing $t=1$:

$$\begin{aligned}
S&=2\pi\sqrt2\int_0^2\lvert t-1\rvert\,\mathrm dt\\
&=2\pi\sqrt2\left(\int_0^1(1-t)\,\mathrm dt+\int_1^2(t-1)\,\mathrm dt\right)\\
&=\boxed{2\pi\sqrt2}.
\end{aligned}$$

This is the curved area of two cones joined at their tips. The two circular ends are boundaries of the surface, not end caps.

### Example 6 — Parametric surface area from a circular arc {#example-6--parametric-surface-area}

**Question:** Find the area swept out when $x=2\cos t$, $y=2\sin t$, $0\le t\le\frac{\pi}{2}$, is revolved about the x-axis.

The parametric speed is constant:

$$\frac{\mathrm ds}{\mathrm dt}
=\sqrt{(-2\sin t)^2+(2\cos t)^2}
=2.$$

Since $y\ge0$ on the interval, the radius is $2\sin t$:

$$\begin{aligned}
S&=2\pi\int_0^{\frac{\pi}{2}}(2\sin t)(2)\,\mathrm dt\\
&=8\pi[-\cos t]_0^{\frac{\pi}{2}}\\
&=\boxed{8\pi}.
\end{aligned}$$

This arc generates the curved surface of a hemisphere. Its flat circular base is not part of the surface traced by the arc.

## Practice {#practice}

**Independent practice · 25–30 minutes**

For each question, write the correct formula and limits before calculating. Show how you handle absolute values, and check that the speed is non-negative. These are original practice questions, not official exam questions; no official marks are assigned.

### Q1 — Length of a straight line {#q1--straight-line-length}

**Question:** Find the length of $y=3x+1$ for $0\le x\le2$.

<details markdown="1">
<summary>Hint</summary>

The gradient is constant. Use the Cartesian arc-length formula.

</details>

<details markdown="1">
<summary>Solution</summary>

$$\begin{aligned}
L&=\int_0^2\sqrt{1+3^2}\,\mathrm dx\\
&=\boxed{2\sqrt{10}}.
\end{aligned}$$

</details>

### Q2 — Integrate a non-constant speed {#q2--non-constant-cartesian-speed}

**Question:** Find the length of $y=\frac{x^2}{2}$ for $0\le x\le2$. Give an exact answer.

<details markdown="1">
<summary>Hint</summary>

You may use $\frac12\left(x\sqrt{1+x^2}+\ln\left(x+\sqrt{1+x^2}\right)\right)$ as an antiderivative; first differentiate it to confirm the result is $\sqrt{1+x^2}$.

</details>

<details markdown="1">
<summary>Solution</summary>

$$\begin{aligned}
L&=\int_0^2\sqrt{1+x^2}\,\mathrm dx\\
&=\left[\frac12\left(x\sqrt{1+x^2}+\ln\left(x+\sqrt{1+x^2}\right)\right)\right]_0^2\\
&=\boxed{\sqrt5+\frac12\ln(2+\sqrt5)}.
\end{aligned}$$

</details>

### Q3 — A quarter-circle in parametric form {#q3--parametric-quarter-circle}

**Question:** Find the arc length of $x=3\cos t$, $y=3\sin t$, for $0\le t\le\frac{\pi}{2}$.

<details markdown="1">
<summary>Hint</summary>

Find both derivatives. The speed is constant.

</details>

<details markdown="1">
<summary>Solution</summary>

$$\begin{aligned}
\frac{\mathrm ds}{\mathrm dt}
&=\sqrt{(-3\sin t)^2+(3\cos t)^2}\\
&=3,\\
L&=\int_0^{\frac{\pi}{2}}3\,\mathrm dt\\
&=\boxed{\frac{3\pi}{2}}.
\end{aligned}$$

</details>

### Q4 — Surface area from a Cartesian graph {#q4--cartesian-surface-area}

**Question:** Find the area swept out when $y=x$, $0\le x\le2$, is revolved about the x-axis.

<details markdown="1">
<summary>Hint</summary>

Here $y\ge0$, so the radius is $x$. The gradient is 1.

</details>

<details markdown="1">
<summary>Solution</summary>

$$\begin{aligned}
S&=2\pi\int_0^2x\sqrt{1+1^2}\,\mathrm dx\\
&=2\pi\sqrt2\left[\frac{x^2}{2}\right]_0^2\\
&=\boxed{4\pi\sqrt2}.
\end{aligned}$$

</details>

### Q5 — Surface area on both sides of the x-axis {#q5--surface-crosses-the-axis}

**Question:** Find the area swept out when $y=x-2$, $0\le x\le4$, is revolved about the x-axis.

<details markdown="1">
<summary>Hint</summary>

The radius is $\lvert x-2\rvert$. Split the integral at $x=2$.

</details>

<details markdown="1">
<summary>Solution</summary>

The gradient is 1, so the speed factor is $\sqrt2$. Thus

$$\begin{aligned}
S&=2\pi\sqrt2\int_0^4\lvert x-2\rvert\,\mathrm dx\\
&=2\pi\sqrt2\left(\int_0^2(2-x)\,\mathrm dx+\int_2^4(x-2)\,\mathrm dx\right)\\
&=\boxed{8\pi\sqrt2}.
\end{aligned}$$

</details>

### Q6 — Do two arcs generate two different surfaces? {#q6--avoid-counting-the-same-surface-twice}

**Question:** The full circle $x=\cos t$, $y=\sin t$, $0\le t\le2\pi$, is revolved about the x-axis. Find the length of the circle and the distinct surface area generated. Explain which parameter interval you use for the surface area.

<details markdown="1">
<summary>Hint</summary>

The circle is traced once over $0\le t\le2\pi$. On rotation, the upper and lower semicircles sweep over the same sphere.

</details>

<details markdown="1">
<summary>Solution</summary>

The speed is 1, so the full circle has length

$$L=\int_0^{2\pi}1\,\mathrm dt=2\pi.$$

For the distinct surface area, use just the upper semicircle, $0\le t\le\pi$:

$$\begin{aligned}
S&=2\pi\int_0^\pi\sin t\,\mathrm dt\\
&=2\pi[-\cos t]_0^\pi\\
&=\boxed{4\pi}.
\end{aligned}$$

Using $0\le t\le2\pi$ for the surface would give $8\pi$, counting every point of the sphere twice. The curve itself is not retraced for its arc length; the duplication happens when the two halves are revolved.

</details>

### Q7 — Find length and surface area from one parameterisation {#q7--combined-parametric-problem}

**Question:** For $x=t^2$, $y=1-t^2$, $0\le t\le1$, find (a) the arc length and (b) the area swept out when the curve is revolved about the x-axis.

<details markdown="1">
<summary>Hint</summary>

For both parts, calculate the same speed. Since $t\ge0$, it simplifies to $2\sqrt2\,t$.

</details>

<details markdown="1">
<summary>Solution</summary>

$$\frac{\mathrm dx}{\mathrm dt}=2t,\qquad
\frac{\mathrm dy}{\mathrm dt}=-2t,\qquad
\frac{\mathrm ds}{\mathrm dt}=2\sqrt2\,t.$$

Therefore

$$\begin{aligned}
L&=\int_0^1 2\sqrt2\,t\,\mathrm dt\\
&=\boxed{\sqrt2}.
\end{aligned}$$

On this interval, $y=1-t^2\ge0$, so the radius is $1-t^2$:

$$\begin{aligned}
S&=2\pi\int_0^1(1-t^2)(2\sqrt2\,t)\,\mathrm dt\\
&=4\pi\sqrt2\left[\frac{t^2}{2}-\frac{t^4}{4}\right]_0^1\\
&=\boxed{\pi\sqrt2}.
\end{aligned}$$

</details>

## Quick Reference {#quick-reference}

| Task | Formula or first step | Check |
|---|---|---|
| Cartesian arc length | $\displaystyle L=\int_a^b\sqrt{1+\left(\frac{\mathrm dy}{\mathrm dx}\right)^2}\,\mathrm dx$ | Limits are x-values; use $a\le b$ |
| Parametric arc length | $\displaystyle L=\int_\alpha^\beta\sqrt{\left(\frac{\mathrm dx}{\mathrm dt}\right)^2+\left(\frac{\mathrm dy}{\mathrm dt}\right)^2}\,\mathrm dt$ | Include both derivatives and use increasing t-limits |
| Cartesian surface about x-axis | $\displaystyle S=2\pi\int_a^b\lvert y\rvert\sqrt{1+\left(\frac{\mathrm dy}{\mathrm dx}\right)^2}\,\mathrm dx$ | Radius is $\lvert y\rvert$ |
| Parametric surface about x-axis | $\displaystyle S=2\pi\int_\alpha^\beta\lvert y\rvert\sqrt{\left(\frac{\mathrm dx}{\mathrm dt}\right)^2+\left(\frac{\mathrm dy}{\mathrm dt}\right)^2}\,\mathrm dt$ | Radius is $\lvert y\rvert$; speed is non-negative |
| A square root of a square | $\sqrt{g^2}=\lvert g\rvert$ | Check the sign of $g$ before removing the absolute value |
| Curve crosses the x-axis | Split where $y=0$, or integrate with $\lvert y\rvert$ | Do not use a negative radius |
| A repeated parameter or surface patch | Choose an interval that covers the requested object once | Distinguish retracing the curve from overlapping after rotation |

**After practice:** if the length formula was wrong, repeat Questions 1–3. If the radius sign was wrong, repeat Questions 4–5. If you counted an overlapping surface twice, revisit Question 6. If you need to combine both formulas, retry Question 7.

**You should be able to:** calculate Cartesian and parametric arc lengths, use $\lvert y\rvert$ as the radius about the x-axis, and distinguish the curved surface from end caps or overlapping patches.
