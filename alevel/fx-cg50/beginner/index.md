## 怎样阅读按键步骤 {#reading-keys}

`SHIFT → MENU` 表示先按 SHIFT，松开后再按 MENU；`F1（数学）` 指屏幕底部“数学”对应的 F1 键。“右方向键”才表示移动光标。

一次计算完成后，直接在下一输入行输入新算式。普通练习无需每次按 AC/ON。

以下题目均为**自拟操作练习**，用于学会按键，并非 AQA 或 OxfordAQA 真题。可配合 [A2 三角函数](/alevel/a2-mathematics/trigonometric-functions-and-formulae/)、[指数与对数](/alevel/a2-mathematics/exponential-and-logarithmic-functions/) 和 [数值方法](/alevel/a2-mathematics/numerical-methods/) 的课程内容学习。

### 任务 1 进入计算界面 {#task-1}

**Calculate $2 + 3 \times 4$.**

1. 按 AC/ON 开机，再按 MENU。
2. 用方向键选中计算·矩阵，按 EXE。英文界面对应 RUN-MATRIX；本指南按中文界面操作。
3. 输入 `2 → + → 3 → × → 4 → EXE`。
4. 结果应为 14。乘法先于加法计算。
5. 按 MENU，确认可以回到应用图标菜单。

### 任务 2 使用 SHIFT 和 ALPHA {#task-2}

**Calculate $\sqrt{49}$. Then enter the letter A.**

1. 进入计算·矩阵。

4. 按 ALPHA，再按上方标有红色 A 的 `X,θ,T` 键。输入行应出现 A。
5. 此时先不要按 EXE；按 DEL 删除刚输入的 A。

### 遇到错误信息时 {#section-4}

出现语法错误等信息时，先按 EXIT 返回输入，再检查括号、运算符和光标位置，用方向键和 DEL 修改错误处。日常输入错误不需要进入系统管理或执行复位。

### 任务 4 检查角度与弧度 {#task-4}

**Calculate $\sin 30^\circ$ and $\sin\left(\frac{\pi}{6}\right)$.**

第一遍使用角度制。

1. 在 计算·矩阵 中按 `SHIFT → MENU`。
2. 用上下方向键选中 角度，按 F1（度）。确认该行显示“度数”，再按 EXIT。
3. 输入 `sin → ( → 3 → 0 → ) → EXE`。
4. 结果应为 $\frac{1}{2}$ 或 $0.5$。sin 键只输入 `sin`；左括号要手动输入，再用右括号关闭。

第二遍使用弧度制。

1. 再次进入 设置，选中 角度，按 F2（弧度），确认后按 EXIT。
2. 输入 `sin → ( → SHIFT → ×10ˣ（π）→ ÷ → 6 → ) → EXE`。
3. 按 SHIFT 再按 π 所在键输入 π；算式应为 $\sin\left(\frac{\pi}{6}\right)$。结果仍为 $\frac{1}{2}$ 或 $0.5$。

看题目给出的角度单位再选设置。A-level 的微积分和弧长等任务通常涉及弧度，但不要因此把所有三角函数题都设为 弧度。更换任务或应用后仍应检查当前设置。

### 任务 5 使用正常显示 {#task-5}

1. 在 计算·矩阵 中按 `SHIFT → MENU`。
2. 用上下方向键找到 显示。
3. 按 F3（常规）。实机底部依次显示位数、科学、常规、工程。
4. 查看“显示”一行。按一次 F3（常规）可切换常规1与常规2；本指南采用常规2。返回计算界面后，顶部应显示 Norm2。
5. 按 EXIT 返回计算界面。

常规1与常规2 影响很小的数什么时候转成科学记数法，不改变数值。选择 常规2 可以让更多较小的数直接显示为小数。

### 位数和科学分别表示什么 {#section-9}

位数（Fix）指定小数位数，例如 位数3 显示三位小数。科学（Sci）指定有效数字位数，例如 科学3 显示三位有效数字。两者不能互换。日常练习先用常规显示，需要特定显示格式时再调整。

### 任务 6 最后一步才取近似值 {#task-6}

**Calculate $10 \div 3$. Give your answer to 3 significant figures.**

1. 输入 `1 → 0 → ÷ → 3 → EXE`。
2. 若结果是分数，按 S↔D，查看小数 $3.333333333\ldots$。
3. 最后写出答案 $3.33$，保留三位有效数字。

屏幕显示有限位数，内部计算通常保留更多精度。继续计算时优先使用 Ans，避免重新输入已经四舍五入的屏幕数值。

## 第 3 章 基础计算与输入 {#chapter-3}

### 任务 7 输入分数并切换小数 {#task-7}

**Calculate one half plus one third. Give an exact answer.**

$$\frac{1}{2}+\frac{1}{3}$$

开始前：进入计算·矩阵，将输入/输出选为数学，使该行显示数学模式；在设置中选中分数结果，按 d/c 对应的功能键，使该行显示假分数。

1. 按实体分数键。它在 `X,θ,T` 键下方，键面是上下两个小方框中间一条横线。
2. 输入 1，按下方向键移到分母，再输入 2。
3. 按右方向键离开整个分数模板，再按 +。
4. 再按分数键，输入 1，按下方向键，输入 3。
5. 按右方向键离开模板，再按 EXE。精确结果应为 $\frac{5}{6}$。
6. 按 S↔D，显示小数 $0.833333333\ldots$；再按一次，回到分数显示。

常见错误：光标还在分母里就按 +，导致后面的内容全部被放进分母。先看光标位置，再继续输入。

要求 exact answer 时保留分数或题目要求的精确形式。不要把 $\frac{5}{6}$ 写成 $0.833$。

### 任务 8 输入有括号的分式 {#task-8}

**Calculate $\frac{2+3}{7-2}$.**

1. 输入 `( → 2 → + → 3 → ) → ÷ → ( → 7 → − → 2 → ) → EXE`。
2. 结果应为 1。这里的 − 使用右下方的减法键。

输入时，两组括号分别把分子和分母组合在一起。若写成 $2+3\div7-2$，运算顺序就变了。

### 任务 9 分清负号与减号 {#task-9}

**Compare $(-3)^2$ and $-3^2$.**

1. 计算 $(-3)^2$：输入 `( → (−) → 3 → ) → x² → EXE`。结果为 $9$。
2. 计算 $-3^2$：输入 `(−) → 3 → x² → EXE`。结果为 $-9$。

输入负数时，使用最底行、EXE 左侧的 (−) 键；进行减法时，使用 + 键右侧的 − 键。括号决定负号是否属于被平方的整体。

### 任务 10 输入任意次幂 {#task-10}

**Calculate $2^5$.**

1. 输入 `2 → ^ → 5`。
2. 在 数学输入格式下，5 应位于指数位置；按右方向键离开指数，再按 EXE。
3. 结果应为 32。

继续在指数后输入加法或乘法时，务必先离开指数区域。例如 $2^5+1$ 的结果为 $33$；若把 $+1$ 留在指数内，得到的就是 $2^6$，即 $64$。

### 任务 12 使用 log 和 ln {#task-12}

**Calculate $\log_{10}(1000)$ and $\ln(1)$.**

1. 输入 `log → ( → 1 → 0 → 0 → 0 → ) → EXE`。结果为 3。
2. 输入 `ln → ( → 1 → ) → EXE`。结果为 0。

log 键表示以 10 为底的对数，ln 键表示自然对数。两者输入的实数参数必须大于 0。

### 任务 13 输入科学记数法 {#task-13}

**Calculate $\frac{6.02\times10^{23}}{3.01\times10^{22}}$.**

1. 输入 `( → 6 → . → 0 → 2 → ×10ˣ → 2 → 3`，按右方向键离开指数，再按 `)`。
2. 按 `÷ → (`，再输入 `3 → . → 0 → 1 → ×10ˣ → 2 → 2`。
3. 按右方向键离开指数，再按 `) → EXE`。结果应为 20。

×10ˣ 键直接输入“乘以 10 的幂”。输入负指数时，在指数区域使用 (−) 键，例如 $1.2\times10^{-3}$。

### 任务 14 使用上一结果 Ans {#task-14}

**Calculate $10 \div 3$, then multiply the unrounded result by $3$.**

1. 输入 `1 → 0 → ÷ → 3 → EXE`。
2. 按 `SHIFT → (−)`，输入 Ans。Ans 的黄色标记位于底行 (−) 键上方。
3. 按 `× → 3 → EXE`。结果应为 10。

Ans 表示最近一次计算结果，每次执行新的计算后会更新。它保留计算器内部的结果，适合连续计算；不要把 Ans 当成永久保存的数值。
