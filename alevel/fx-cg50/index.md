## 考前先看：考试模式 {#exam-mode}

先向老师确认本场考试是否要求考试模式、使用哪一种模式。以下介绍 **UK 模式**的操作；不能据此认定它适用于所有 A-level 考试。IB 模式有不同的进入按键。

### 进入 UK 模式 {#enter-uk}

1. 按 `SHIFT → AC/ON` 关机。
2. **同时按住** `1` 和 `,`（键上红色字母分别是 U 和 K），保持按住，再按 `AC/ON`。这里的逗号是实体逗号键，不是小数点，也不用按 ALPHA。
3. 确认提示中写的是 **UK**，按 `F1（是）`，阅读下一页后按 `F2` 确认。
4. 若出现不适用于 IB 考试的提示，确认你需要 UK 模式后再按 `F1`；如果需要 IB，请取消并重新选择。
5. 完成后按 `EXIT`。UK 模式的屏幕边框是**品红色**，右上角有闪烁图标。

**不要混淆：** `cos + 7 + AC/ON` 是进入 **IB** 模式的组合；IB 的边框是绿色。普通步骤中的 `→` 表示先后按，本节明确写“同时按住”才需要组合按键。

### 退出与恢复 {#exit-exam}

关机再开机不会立即退出考试模式。官方手册提供 USB、等待约 12 小时后开机、连接另一台计算器三种退出方式。USB 方法需要连接电脑、在连接选择中按 `F1`、打开计算器盘并复制或删除一个文件，再正常结束连接。可以复制一个临时文本文件，避免删除自己的文件；仅打开 Screen Receiver 不等同于完成退出流程。

退出后，原有主存储器数据会恢复，考试模式期间创建的数据会被删除。不要用重置或取出电池尝试退出；需要立即退出时请老师协助完成 USB 流程。

本节参考 [Casio 中文手册 β-1 至 β-4](https://www.casio.com/content/dam/casio/global/support/manuals/calculators/pdf/004-zh-cn/f/fx-CG50_Soft_v370_CN.pdf) 和 [Casio UK 考试模式说明](https://education.casio.co.uk/blog/preparing-students-using-the-fx-cg50-in-exams/)。中文版提示文字与进入后的截图待补充。

### 考前 30 秒检查 {#exam-checklist}

- 按老师要求确认模式和屏幕标识；检查电量。
- 三角函数计算先核对度数或弧度。
- 题目要求 exact answer 时保留精确形式；有效数字留到最后处理。
- 解题过程写在答题纸上，不能只抄计算器结果。

## 怎样阅读按键步骤 {#reading-keys}

`SHIFT → MENU` 表示先按 SHIFT，松开后再按 MENU；`F1（数学）` 指屏幕底部“数学”对应的 F1 键。“右方向键”才表示移动光标。

一次计算完成后，直接在下一输入行输入新算式。普通练习无需每次按 AC/ON。

以下题目均为**自拟操作练习**，用于学会按键，并非 AQA 或 OxfordAQA 真题。可配合 [A2 三角函数](/alevel/a2-mathematics/trigonometric-functions-and-formulae/)、[指数与对数](/alevel/a2-mathematics/exponential-and-logarithmic-functions/) 和 [数值方法](/alevel/a2-mathematics/numerical-methods/) 的课程内容学习。

### 任务 1 进入计算界面 {#task-1}

**Calculate $2 + 3 \times 4$.**

1. 按 AC/ON 开机，再按 MENU。
2. 用方向键选中计算·矩阵，按 EXE。英文界面对应 RUN-MATRIX；本指南按中文界面操作。
3. 输入 `2 → + → 3 → × → 4 → EXE`。
4. 结果应为 14。乘法先于加法计算。
5. 按 MENU，确认可以回到应用图标菜单。

### 任务 4 检查角度与弧度 {#task-4}

**Calculate $\sin 30^\circ$ and $\sin\left(\frac{\pi}{6}\right)$.**

第一遍使用角度制。

1. 在 计算·矩阵 中按 `SHIFT → MENU`。
2. 用上下方向键选中 角度，按 F1（度）。确认该行显示“度数”，再按 EXIT。
3. 输入 `sin → ( → 3 → 0 → ) → EXE`。
4. 结果应为 $\frac{1}{2}$ 或 $0.5$。sin 键只输入 `sin`；左括号要手动输入，再用右括号关闭。

第二遍使用弧度制。

1. 再次进入 设置，选中 角度，按 F2（弧度），确认后按 EXIT。
2. 输入 `sin → ( → SHIFT → ×10ˣ（π）→ ÷ → 6 → ) → EXE`。
3. 按 SHIFT 再按 π 所在键输入 π；算式应为 $\sin\left(\frac{\pi}{6}\right)$。结果仍为 $\frac{1}{2}$ 或 $0.5$。

### 任务 5 使用正常显示 {#task-5}

1. 在 计算·矩阵 中按 `SHIFT → MENU`。
2. 用上下方向键找到 显示。
3. 按 F3（常规）。实机底部依次显示位数、科学、常规、工程。
4. 查看“显示”一行。按一次 F3（常规）可切换常规1与常规2；本指南采用常规2。返回计算界面后，顶部应显示 Norm2。
5. 按 EXIT 返回计算界面。

常规1与常规2 影响很小的数什么时候转成科学记数法，不改变数值。选择 常规2 可以让更多较小的数直接显示为小数。

### 位数和科学分别表示什么 {#section-9}

位数（Fix）指定小数位数，例如 位数3 显示三位小数。科学（Sci）指定有效数字位数，例如 科学3 显示三位有效数字。两者不能互换。日常练习先用常规显示，需要特定显示格式时再调整。

### 任务 6 最后一步才取近似值 {#task-6}

**Calculate $10 \div 3$. Give your answer to 3 significant figures.**

1. 输入 `1 → 0 → ÷ → 3 → EXE`。
2. 若结果是分数，按 S↔D，查看小数 $3.333333333\ldots$。
3. 最后写出答案 $3.33$，保留三位有效数字。

屏幕显示有限位数，内部计算通常保留更多精度。继续计算时优先使用 Ans，避免重新输入已经四舍五入的屏幕数值。

## 第 3 章 基础计算与输入 {#chapter-3}

### 任务 7 输入分数并切换小数 {#task-7}

**Calculate one half plus one third. Give an exact answer.**

$$\frac{1}{2}+\frac{1}{3}$$

开始前：进入计算·矩阵，将输入/输出选为数学，使该行显示数学模式；在设置中选中分数结果，按 d/c 对应的功能键，使该行显示假分数。

1. 按实体分数键。它在 `X,θ,T` 键下方，键面是上下两个小方框中间一条横线。
2. 输入 1，按下方向键移到分母，再输入 2。
3. 按右方向键离开整个分数模板，再按 +。
4. 再按分数键，输入 1，按下方向键，输入 3。
5. 按右方向键离开模板，再按 EXE。精确结果应为 $\frac{5}{6}$。
6. 按 S↔D，显示小数 $0.833333333\ldots$；再按一次，回到分数显示。

常见错误：光标还在分母里就按 +，导致后面的内容全部被放进分母。先看光标位置，再继续输入。

要求 exact answer 时保留分数或题目要求的精确形式。不要把 $\frac{5}{6}$ 写成 $0.833$。

### 任务 8 输入有括号的分式 {#task-8}

**Calculate $\frac{2+3}{7-2}$.**

1. 输入 `( → 2 → + → 3 → ) → ÷ → ( → 7 → − → 2 → ) → EXE`。
2. 结果应为 1。这里的 − 使用右下方的减法键。

输入时，两组括号分别把分子和分母组合在一起。若写成 $2+3\div7-2$，运算顺序就变了。

### 任务 9 分清负号与减号 {#task-9}

**Compare $(-3)^2$ and $-3^2$.**

1. 计算 $(-3)^2$：输入 `( → (−) → 3 → ) → x² → EXE`。结果为 $9$。
2. 计算 $-3^2$：输入 `(−) → 3 → x² → EXE`。结果为 $-9$。

输入负数时，使用最底行、EXE 左侧的 (−) 键；进行减法时，使用 + 键右侧的 − 键。括号决定负号是否属于被平方的整体。

### 任务 10 输入任意次幂 {#task-10}

**Calculate $2^5$.**

1. 输入 `2 → ^ → 5`。
2. 在 数学输入格式下，5 应位于指数位置；按右方向键离开指数，再按 EXE。
3. 结果应为 32。

继续在指数后输入加法或乘法时，务必先离开指数区域。例如 $2^5+1$ 的结果为 $33$；若把 $+1$ 留在指数内，得到的就是 $2^6$，即 $64$。

### 任务 11 输入平方根 {#task-11}

**Calculate $\sqrt{72}$. Give an exact answer.**

1. 输入 `SHIFT → x² → 7 → 2`。
2. 按右方向键离开根号，再按 EXE。
3. 在数学模式下，结果为 $6\sqrt{2}$；已在中文版 03.81.0202 实机核对。按 S↔D 可查看约 $8.485281374$。

若显示不符合预期，先检查 输入/输出 是否为数学模式；本例已在 03.81.0202 实机核对精确输出。不要用小数替代题目要求的精确答案。

### 任务 12 使用 log 和 ln {#task-12}

**Calculate $\log_{10}(1000)$ and $\ln(1)$.**

1. 输入 `log → ( → 1 → 0 → 0 → 0 → ) → EXE`。结果为 3。
2. 输入 `ln → ( → 1 → ) → EXE`。结果为 0。

log 键表示以 10 为底的对数，ln 键表示自然对数。两者输入的实数参数必须大于 0。

### 任务 13 输入科学记数法 {#task-13}

**Calculate $\frac{6.02\times10^{23}}{3.01\times10^{22}}$.**

1. 输入 `( → 6 → . → 0 → 2 → ×10ˣ → 2 → 3`，按右方向键离开指数，再按 `)`。
2. 按 `÷ → (`，再输入 `3 → . → 0 → 1 → ×10ˣ → 2 → 2`。
3. 按右方向键离开指数，再按 `) → EXE`。结果应为 20。

×10ˣ 键直接输入“乘以 10 的幂”。输入负指数时，在指数区域使用 (−) 键，例如 $1.2\times10^{-3}$。

### 任务 14 使用上一结果 Ans {#task-14}

**Calculate $10 \div 3$, then multiply the unrounded result by $3$.**

1. 输入 `1 → 0 → ÷ → 3 → EXE`。

### 任务 15 解二次方程 {#task-15}

**Solve $x^2-3x-4=0$.**

1. 按 `MENU`，用方向键选择 **解方程（组）**，按 `EXE`。
2. 按 `F2（多项式）`，选择二次，即 `F1（2）`。
3. 系数按降幂排列。依次输入 `1 → EXE → (−) → 3 → EXE → (−) → 4 → EXE`。
4. 核对屏幕上的系数为 $1,-3,-4$，按 `F1（求解）`。
5. 应得到两个根 $-1$ 和 $4$；显示顺序不影响答案。

多项式模式输入的是系数，不是整条方程。先把方程整理成右边为零的形式：例如 $x^2=3x+4$ 也应输入 $1,-3,-4$。缺项的系数输入零，例如 $x^3-8=0$ 的系数是 $1,0,0,-8$。

<details><summary>怎样验证，而不是只抄两个数字？</summary>

</details>

### 任务 16 解二元一次方程组 {#task-16}

**Solve simultaneously:**

$$\begin{cases}2x+y=7,\\x-y=2.\end{cases}$$

1. 进入 **解方程（组）**，按 `F1（方程组）`，选择两个未知数。
2. 屏幕采用 $ax+by=c$。第一行输入 $2,1,7$，第二行输入 $1,-1,2$；每个数后按 `EXE` 保存。
3. 检查两行，按 `F1（求解）`，读出 $x=3,\ y=1$。
4. 验证 $2(3)+1=7$、$3-1=2$。

**常见错误：** 第二个方程若写成 $x=y+2$，要先改写为 $x-y=2$。这里 $y$ 的系数是 $-1$。不要把常数也移到左边后，仍按照 $ax+by=c$ 输入。

### 任务 17 求一个非多项式方程的数值解 {#task-17}

**Find the root of $e^{-x}=x$ in $0<x<1$. Give your answer to three decimal places.**

1. 进入 **解方程（组）**，按 `F3（解）`。
2. 输入 $e^{-x}-x$，按 `EXE`。省略等号时，求解器把整个表达式看作等于零。$x$ 用实体 `X,θ,T` 键输入，$e^x$ 用 `SHIFT → ln` 输入；完成指数后按右方向键离开指数区域，再输入减去 $x$。

4. 把光标移回 $X$，按 `F6（求解）`。结果应接近 $0.5671432904$，按题目要求写成 $0.567$。
5. 检查结果屏幕的左、右值是否接近，并把结果代回原方程检查。

## 第 7 章 微积分中的计算器辅助 {#chapter-7}

### 任务 22 求指定点的导数值 {#task-22}

**For $f(x)=x^3-3x$, find $f'(2)$.**

1. 进入 **计算·矩阵**，采用数学输入/输出。
2. 按 `OPTN → F4（计算）→ F2（d/dx）` 调出导数模板。
3. 在函数区域输入 $x^3-3x$，用方向键移到求值点的格子，输入 $2$。
4. 核对显示的是在 $x=2$ 处求导，按 `EXE`。结果应为 $9$。

### 任务 23 求定积分并区分面积 {#task-23}

**Evaluate $\displaystyle\int_0^2(x^2-1)\,dx$.**

1. 在 **计算·矩阵** 按 `OPTN → F4（计算）→ F4（∫dx）` 调出积分模板。
2. 函数区域输入 $x^2-1$；用方向键移到下限格子输入 $0$，上限格子输入 $2$。
3. 检查上、下限的位置，再按 `EXE`。结果应接近 $0.6666666667$，也就是 $\frac{2}{3}$。

数值积分的显示形式不保证是精确分数。若题目要求 exact answer，用解析过程：

$$\int_0^2(x^2-1)\,dx=\left[\frac{x^3}{3}-x\right]_0^2=\frac23.$$

<details><summary>这条曲线与横轴围成的总面积也等于 2/3 吗？</summary>

不是。曲线在 $(0,1)$ 位于横轴下方，在 $(1,2)$ 位于横轴上方。总面积应分别计算后取正值：

$$A=-\int_0^1(x^2-1)\,dx+\int_1^2(x^2-1)\,dx=\frac23+\frac43=2.$$

定积分保留符号，面积相加要按正值处理。一个跨越正负区域的积分，可能因为抵消而很小。

</details>

**本章完成检查：** 不颠倒积分上下限，不把导数值当成导函数，不把带符号积分直接当成总面积。参考手册第 2-28 至 2-33 页。

## 第 10 章 常见错误与考前检查 {#chapter-10}

### 任务 30 按现象排查 {#task-30}

| 现象 | 先检查什么 | 接下来做什么 |
| --- | --- | --- |
| 三角函数答案差很多 | 度数或弧度、手动括号 | 对照题目单位，检查完整输入式 |
| 出现语法错误 | 括号是否成对、模板是否填全 | 返回出错位置，修正后重新执行 |
| 出现数学错误 | 除以零、对数或根号的定义域 | 先检查数学表达式是否有定义 |
| 图像空白或关键点看不到 | 函数是否选中、窗口是否合适 | 调整窗口，重新绘图 |
| 只找到一个根 | 采用的模式、起始值、窗口 | 用代数、图像或不同区间交叉检查 |
| 表格不按步长变化 | “变量”是否指定成列表 | 改回表格范围，再核对开始值与终止值 |
| 统计结果的 $n$ 不对 | 旧数据、频数列表、列表长度 | 修正数据来源，再重新计算 |
| 概率非常不合理 | 事件方向、整数边界、$\sigma$ 字段 | 写出事件并估计结果大小后重算 |
| 小数与精确答案不一致 | 舍入、结果形式、内部精度 | 用未舍入结果继续算，纸笔求精确形式 |

修正输入时优先用方向键、`DEL` 和 `EXIT`。一次计算执行完后可以直接输入下一式，不需要例行按 `AC/ON`。不要为一个输入错误重置整台计算器。

### 任务 31 交卷前的答案检查 {#task-31}

- **题目问什么？** 根、坐标、导数值、面积、概率和标准差不能混写。
- **过程够不够？** 要求 show、prove 或解析推导时，计算器结果只用于核对。
- **格式对不对？** exact answer 保留分数、根式或 $\pi$；近似值按题目指定精度写，运算途中保留完整结果。
- **范围和单位对不对？** 不接受定义域外的根；长度、面积、时间等写相应单位；概率应在 $[0,1]$。
- **漏掉结果了吗？** 检查所有根、所有交点以及题目对正值、整数或区间的限制。
- **设置对不对？** 核对角度单位、数据与频数、考试模式要求和电量。
