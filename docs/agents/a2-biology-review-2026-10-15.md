## 审查发现与修正

独立审查者只读检查全部 44 页正文、任务和反馈，核对 117 个标记英文任务／数据块的双语一致性，并复算高风险题目，核对所引 BL04／BL05 配套 MS 页码及大纲范围。确认的问题已修正：

| 问题 | 修正 |
| --- | --- |
| 英文光照实验把距离平方关系写得不完整 | 明确光强与距离平方近似成反比，并保留光源、几何及环境限制 |
| RP2 初始称量顺序可能发生在浸泡之后 | 两种语言均改为先统一吸干并称初重，再浸入、计时，最后吸干并称终重 |
| AS 桥接的蒸腾计重试在题干直接显示结果 | 移除题干结果，保留后续独立折叠核对 |
| 能量收支及氮循环 SVG 的复合路径没有给每一分支画箭头 | 分离路径，补全方向，浏览器逐图复验 |
| 两张呼吸作用图的箭头经过文字 | 调整箭头或标注位置，在最终预览图像弹窗复验 |
| BL05 三页的页内语言链接被自动本地化改回原页 | 六个链接添加现有脚本识别的 `hreflang`，并新增回归断言；实测双向切换正常 |

科学复核包括：气体净变化与耗氧的区别、RQ 的条件、膜两侧质子方向、碳与能量收支、遗传模型及 Hardy–Weinberg 计算、IAA 对不同器官的条件性作用、胰岛素与胰高血糖素机制、PCR 延伸方向、独立实验单位、SD／SE／CI、并列秩与小样本 Spearman 推断、卡方期望频数及 p 值含义。未将通过文本核验解释为保证无任何学科错误。
