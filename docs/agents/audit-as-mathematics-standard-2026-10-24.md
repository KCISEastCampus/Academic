## 2. 优先修补项

P1 表示影响范围或核心目标验收，应在宣布完成之前修复；P2 表示需要改善教学连贯性或可用性。以下是当前源内容与实际页面的判断，不以标题数、题数或脚本通过代替内容验收。

### AS-01 · P1：圆上指定点的法线没有进入教学与任务

官方大纲 PP1.1（印刷第 15 页，PDF 第 14 页）明确包括圆上指定点的切线、法线方程。现有[圆章节](../../alevel/as-mathematics/circles.md#l14)的概念段、完整示范、独立题和重试覆盖配方、圆心半径、弦、切线及平移，但中英文均未出现圆的法线讲解或任务。微分章节学过曲线法线，不代表学生已经把圆心—接触点直线识别为圆的法线。[官方依据](https://www.oxfordaqa.com/wp-content/uploads/2026/07/oxfordaqa-a-level-mathematics-specification.pdf#page=14)

最小修补：在半径与切线的关系中建立圆的法线，示范一般方向及必要的水平／竖直情况；安排学生独立给出切线和法线并检查过点、方向。不需要引入隐函数求导。

### AS-02 · P1：同组有独立题，不代表该组各项目标已被考查

| 位置 | 现有证据 | 尚缺的独立产出 |
| --- | --- | --- |
| [代数 L01](../../alevel/as-mathematics/algebra.md#l01) | 指数改写只在带支架题；独立题比较根式，重试做有理化 | 不借助提示完成有理指数改写，并解释条件与等价性 |
| [坐标 L04](../../alevel/as-mathematics/coordinate-geometry.md#l04) | 目标写直线与精确长度；独立题求直线与抛物线两交点的参数，重试只考竖直线段的中垂线 | 一般斜率下选用直线关系，并求、解释精确距离；保留现有判别式题作为联结练习 |
| [微分 L06](../../alevel/as-mathematics/differentiation.md#l06) | 有理幂求导只在示范和带支架题；独立题是二次函数切线，重试是二次函数驻点法线 | 自主把根式／负幂转换后求导，检查范围与结果 |
| [积分 L08](../../alevel/as-mathematics/integration.md#l08) | 由初始条件恢复常数只在带支架题；独立题、重试均考面积，计算均为多项式 | 自主恢复函数和常数；另验证所教有理幂的积分，而非仅在正文写公式 |
| [随机变量 L19](../../alevel/as-mathematics/random-variables.md#l19) | 线性变换在带支架题，独立题与重试复用既定 X 分布考非线性变换 | 独立建立／补全分布，并辨认何时能直接用线性变换规则 |
| [变加速 L23](../../alevel/as-mathematics/variable-acceleration.md#l23) | 目标包括由条件求常数；独立题给定速度，重试给定位置 | 从加速度及条件恢复速度、位置，分别确定常数并检查 |
| [力 L24](../../alevel/as-mathematics/forces.md#l24) | 讲解给出等张力、等加速度的理想化；独立题计算汽车与拖车，重试判断杆推拉 | 明确解释是哪项假设支持约束，改变假设会使哪条方程失效 |

这些缺口不要求每项目标各加一题，也不要求全页重写。先把目标、现有任务与判定依据对应，再调整或增加能同时考查相关能力的任务。三角、数列、概率和动量中已有有效的条件判断与跨知识任务，应保留。

### AS-03 · P2：有些关键解释压缩成结论，初学者需要自行补桥梁

[L01 概念段](../../alevel/as-mathematics/algebra.md#l01)声明先修是整数幂，却直接列有理幂运算律，没有建立分母指数与根的关系；首个示范也只讲根式。[L03 示范](../../alevel/as-mathematics/algebra.md#l03-worked)从代入因式直接跳到除法得到的商，没有展示选择商项和乘回相减的关键步骤。

[L23 示范](../../alevel/as-mathematics/variable-acceleration.md#l23-worked)用一句“积分并使用条件”直接给出 v、s，学生看不到两个条件怎样分别确定两个常数。这里已有积分先修，不需重新展开每个常规幂次积分；需要补的是两次常数和条件代入这条模型推理链。

最小修补：保留常规计算的简洁，公开展示首次关键选择与检查；不把必须读的解释放进独立题提示。此判断不把此前用户对 FM03 一阶微分方程的逐步积分要求扩大到所有章节。

### AS-04 · P2：诊断后的“再试”常常换了被修复的能力

[对数 L17](../../alevel/as-mathematics/exponentials-logarithms.md#l17-independent)要求检查原对数各自的正参数并拒绝代数候选值，诊断也指出乘积为正不够；但[重试](../../alevel/as-mathematics/exponentials-logarithms.md#l17-retry)变成整数次幂的衰减计算，不能证明定义域错误已经修复。

[L13](../../alevel/as-mathematics/sequences.md#l13-independent)的任务涉及由展开式作截断近似，而重试只求一个系数；L04 的交点判别式后变成特殊中垂线。已有题有练习价值，但一个统一的“再试”标签无法区分修复了什么。

最小修补：按错误原因给一个同目标的新任务，保留必要的其他练习；提示后完成和无帮助完成分开记录。

### AS-05 · P2：有前后课链接，但缺少可执行的恢复与回顾路径

例如[代数 L02](../../zh/alevel/as-mathematics/algebra.md#l02)、[圆 L14](../../zh/alevel/as-mathematics/circles.md#l14)和[二项分布 L21](../../zh/alevel/as-mathematics/binomial.md#l21)的先修主要是无链接的 Lxx 编码。各课结尾重复“回看相关示范再继续”，没有按具体困难指向回补位置；[末课](../../alevel/as-mathematics/momentum.md#next-step)结束后回到目录，没有实际单元综合或稍后回顾任务。

现有课程确有圆与坐标、力学与微积分等跨知识任务；缺的是课程路线中可定位的混合选法与延后提取，不是所有整合都不存在。

最小修补：将关键先修改为主题名称和准确段落链接，诊断指向相同技能的回补；在现有入口／课末安排实际综合与稍后复查，并连接到后续课。无需新账户或打卡系统。

### AS-06 · P2：阅读层次可以改善，但没有证据表明整页宽度失控

实际检查中，正文桌面段宽约 740 px，390 px 手机约 350 px；整体能正常重排。代数侧栏有 26 项，四组活动重复列出相同的示范、支架、独立、诊断、重试标题；其他页面也沿用同样层级。完整示范和下一题主要靠同级标题、留白区分，提示与解答各自占据显著全宽区域。[桌面证据](audit-assets/as-mathematics-audit-2026-10-24/algebra-1365-reading.png)、[手机证据](audit-assets/as-mathematics-audit-2026-10-24/algebra-390-reading.png)

改善重点是让概念主线、完整示范起止和学生作答区域更易辨认，降低重复目录和维护说明的权重；复用共享阅读样式即可。没有 `reading_layout`、`worked-example` 或 `lesson-check` 类名本身不构成缺陷，也不要求给每段加框。当前课程入口的四条路线及折叠旧资料安排应保留。

### AS-07 · P2：部分画图任务缺少对应的图形反馈

[力 L24 独立题](../../alevel/as-mathematics/forces.md#l24-independent)要求汽车、拖车各自受力图，解答只有文字清单；现有配图对应悬挂物，无法直接核对该题画出的力落在哪个物体上。[匀加速 L22 独立题](../../alevel/as-mathematics/constant-acceleration.md#l22-independent)要求四段 v–t 草图，答案没有本题对应的检查图。

最小修补：在关闭的解答中给可核对的关键图形或等效逐点画图反馈，标出方向、坐标与作用对象，不把答案图提前放在任务前。[三角函数的余弦检查图](../../alevel/as-mathematics/trigonometry.md#l16-scaffold)已经采用独立作答后再揭示的方式，可保留。

### AS-08 · P2（小修）：精确值与舍入值用了等号

[对数 L17 示范](../../alevel/as-mathematics/exponentials-logarithms.md#l17-worked)写 `t=log5/log2=2.322`；中文对应位置相同。数值的三位小数正确，但应以近似号连接舍入值，以免与本课所强调的精确替代检查混淆。

## 4. 建议的首个样章

**先改“代数 → 等价形式与精确值（L01）”这一小段，不一次改完整代数四组或全部 15 课。** 它是课程推荐起点，先修明确，指数解释与独立产出缺口具体；也能检验现有共享阅读样式是否适合 AS 新概念建立。[连续阅读证据](audit-assets/as-mathematics-audit-2026-10-24/algebra-390-continuous-example.png)

| 样章设计 | 验收证据 |
| --- | --- |
| 中心问题：何时应改写精确形式，怎样保证等价？ | 目标分别定位有理指数改写、根式精确表示与条件检查，不用一个根式比较题代表全部目标 |
| 先修：分数、整数幂、展开 | 有理幂与根的联系在主线建立；必要回补为可点击的具体位置 |
| 一个连贯完整示范 | 题干、方法选择、关键步骤、结果和代回检查连续可读；常规算术不机械铺满 |
| 撤去支架后的学生任务 | 不预告被考查的方法；各目标有实际无帮助产出机会，提示与解答分别关闭 |
| 诊断、同目标新重试 | 错误指向条件、变形或方法；重试换表达或求问，能检验该错误是否修复 |
| 与后续课程连接 | 链接到 L02，并把指数知识连接到后续微分／积分的实际回顾任务 |
| 双语与阅读 | 英文任务、数据、条件及帮助对齐；桌面／手机连续读完示范、作答、开提示、检查答案、继续下一步 |

制作前须重新阅读相应官方 QP／MS；制作后须做独立内容复核和适用技术检查，再给用户核对。统计建模、受力图等不同学习类型另作相应样段，不能从 L01 自动推广。
