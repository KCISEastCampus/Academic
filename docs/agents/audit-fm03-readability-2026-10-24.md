## 优先修改的五处

### 1. 双曲函数：首次接触时同时出现的定义过多

证据：[中文定义](../../zh/alevel/a2-further-mathematics/hyperbolic-functions.md#definitions)、[英文对应](../../alevel/a2-further-mathematics/hyperbolic-functions.md#definitions)；截图 [手机概念入口](audit-assets/fm03-readability-2026-10-24/hyperbolic-functions-390-concept.png)。

第一段连给 `sinh`、`cosh`、`tanh`，接着给 `coth`、`sech`、`cosech`，再给两个指数恒等式和反函数／倒数的记号区别。第一个示范随后同时求四种函数在 `ln 3` 处的值。定义和计算有依据，但首次学习者须先记住多组新名字与关系，才能看到其中最基本的加减结构。

**最小修改：**先把 `sinh` 和 `cosh` 说成由同两个指数式“相减／相加后除以 2”得到的函数，用 `x=0` 算两者的值，再连接图像和恒等式。随后按使用需要引入比值、倒数及反函数；保留六种函数和全部原有范围。不要在零处计算本来无定义的 `coth`／`cosech`。

### 2. 二阶方程：公式之前缺少“为什么试指数函数”的桥接

证据：[方程与条件](../../zh/alevel/a2-further-mathematics/second-order-differential-equations.md#equation-and-conditions)、[辅助方程](../../zh/alevel/a2-further-mathematics/second-order-differential-equations.md#auxiliary-equation)、[英文对应](../../alevel/a2-further-mathematics/second-order-differential-equations.md#auxiliary-equation)；截图 [手机概念入口](audit-assets/fm03-readability-2026-10-24/second-order-differential-equations-390-concept.png)。

开头先介绍常系数、线性、齐次／非齐次、非齐次项、通解、初始／边界条件与不唯一的例外，再直接“设 `y=e^{mx}`”。代入后得到辅助方程的推理成立，但尚未解释为何选这个候选函数；接着又一次列出三种根型和线性无关性，才进入第一个数值示范。

**最小修改：**先用一个具体指数函数说明“求导后仍是自身的倍数”，于是原方程可以转成关于指数中那个数的二次方程。跟完不同实根的示范后，再汇总三种根型。CF／PI 首次使用时配直白解释：一部分代回左边得到零，另一部分代回得到右边给定的函数。保留线性论证、重复根、复根、两个条件和边界不唯一的说明；调整出现顺序即可。

### 3. 矩阵与特征向量：已有具体示范，应更早帮助理解抽象记号

证据：[矩阵维数与次序](../../zh/alevel/a2-further-mathematics/matrix-algebra.md#dimensions-and-order)、[现有行列乘法示范](../../zh/alevel/a2-further-mathematics/matrix-algebra.md#non-square-example)、[特征向量定义与判断](../../zh/alevel/a2-further-mathematics/eigenvalues-and-eigenvectors.md#definition)；[英文矩阵](../../alevel/a2-further-mathematics/matrix-algebra.md#dimensions-and-order)、[英文特征向量](../../alevel/a2-further-mathematics/eigenvalues-and-eigenvectors.md#definition)。

矩阵开头先列一般维数、带 `i,j,k` 的求和公式、转置与乘积规则，再做诊断，最后才展示一次具体的“第一行与第一列相乘相加”。特征向量已有“变换后仍为自身倍数”的好问题，也有方向、正负号和零的解释，但首次定义仍连续使用“像、标量、奇异”等术语，具体向量的比较在后面的诊断与解答中。

**最小修改：**矩阵复习继续允许掌握 AS 先修者直接诊断，同时提供可直接看到的一个数字乘法，把通式解释成这一步的简写。特征向量先展示两个向量经过同一变换后的对比，再给“特征向量／特征值”的正式名称，最后解释零向量为何排除。新增示范后，诊断题应换一组向量，保留独立判断机会，不能原样展示其答案再称为独立证据。

### 4. 麦克劳林展开：展示了怎样代公式，还可解释系数从哪里来

证据：[中文麦克劳林段](../../zh/alevel/a2-further-mathematics/series-and-limits.md#maclaurin-series)、[英文对应](../../alevel/a2-further-mathematics/series-and-limits.md#maclaurin-series)。

正文先定义幂级数，随后给通式，说明系数是零处的高阶导数除以阶乘，并提醒不要漏除阶乘。后面的 `e^{2x}` 示范求导、代零和求系数均完整；缺的是让首次学习者看懂“为什么导数能确定这些系数”的小桥接。

**最小修改：**先取 `a+bx+cx²`，比较它在零处的值、一阶导数与二阶导数，解释第二次求导产生 `2`，所以二次项系数要除以 `2!`，再推广到通式。明确这是系数关系的解释，不是证明任何光滑函数都等于其泰勒级数；保留现有适用范围、收敛与近似限制。

### 5. 部分开头的方法总览更适合已学过的复习者

证据：[棣莫弗方法](../../zh/alevel/a2-further-mathematics/de-moivres-theorem.md#method)、[反三角方法](../../zh/alevel/a2-further-mathematics/inverse-trigonometric-functions.md#method)、[极坐标方法](../../zh/alevel/a2-further-mathematics/polar-coordinates.md#method)；[英文棣莫弗](../../alevel/a2-further-mathematics/de-moivres-theorem.md)、[英文反三角](../../alevel/a2-further-mathematics/inverse-trigonometric-functions.md#method)。

棣莫弗在首次建立定理前，先列全部复根、倍角与幂次互换等方法；反三角在说明返回什么角度之前，先列六类求导积分策略；极坐标在说明距离与角度之前先列面积积分。内容可作为好用的复习清单，但初学路线目前先指向它们。双曲函数的开头也把多个先修、教材页码、目标及题目身份放在核心定义之前，手机上阅读准备文字较多。

**最小修改：**初学入口直接到最基本的问题和解释；方法清单保留为复习入口，或放到首次概念与示范之后。教材身份、较长先修说明和维护性质文字按用途降低权重；必要范围及条件仍保留。中文导航中的 `inverse-cosh` 改成可辨认的“反双曲余弦的分支”，保持原锚点。棣莫弗可先用一个平方展示模与辐角的变化，再进入完整证明；不删证明。

## 16 课的处理建议

“重点”表示先制作概念样段；“局部”表示明确的小段优化，不要求全章重写；“保留”表示本轮看到的主线可以继续使用，不代表整章已重新验收。

| 课程 | 建议 | 处理边界 |
| --- | --- | --- |
| 根与多项式 | 局部 | 保留根与系数的展开论证；一般次数公式前可先突出当前三次式例子 |
| 数学归纳法 | 局部 | 保留起始、假设、递推和结论；把“从一个成立推进到下一个”说清再用符号概括 |
| 有限级数 | 保留 | 部分分式、首尾展开、相消及边界项已有可追踪示范 |
| 级数与极限 | 重点 | 优先补麦克劳林系数的概念桥接；不改已有收敛性论证 |
| 棣莫弗定理 | 局部 | 调整方法总览和第一个具体幂次例子的位置，保留证明及全部根的条件 |
| 极坐标 | 局部 | 坐标定义与转换示范可保留；让初学先看到点与角度，再看面积策略 |
| 反三角函数 | 局部 | 先解释返回的角度与主值，再进入综合积分策略；保留现有图像和分支 |
| 弧长与旋转曲面面积 | 保留 | 已有小段长度与勾股关系的连接；不因公式多就重写 |
| 双曲函数 | 重点 | 先讲两个基本函数，按用途逐步引入其余记号 |
| 一阶微分方程 | 保留 | 保留已确认的积分因子、完整积分链与检查，不压缩用户要求展开的步骤 |
| 二阶微分方程 | 重点 | 解释指数候选的理由，分步引入 CF／PI 和根型 |
| 向量积与共面 | 局部 | 保留垂直、模和右手方向的解释；让具体计算更早承接分量公式，性质按需出现 |
| 直线与平面 | 局部 | 保留二维到三维和零方向分量的桥接；精简“表征”等抽象措辞 |
| 矩阵代数 | 重点 | 具体行列运算与维数先建立联系，再用一般下标公式概括 |
| 线性方程组与三个平面 | 保留 | 现有低维诊断、公共交集、可逆消元及矛盾解释有助于理解 |
| 特征值与特征向量 | 重点 | 更早用具体向量呈现方向／倍数关系，保留非零条件和特征方程论证 |
