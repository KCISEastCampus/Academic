# Academic 课程内容长期标准

版本：1.0，2026-10-22。适用于 IGCSE、AS、A2 的课程规划、新课、重组、改写、汉化与质量审核。

这是本项目的制作与验收标准，按本轮用户要求建立。目标是让学生获得可独立使用的知识与能力。已有课程须经过实际复核才可声明符合；文档生效不代表全站已经达标。

本标准负责学习设计与质量流程；[AGENTS.md](../../AGENTS.md#学科内容制作准则)负责各学科正确性、来源身份、双语、公式与技术要求。官方材料决定考试范围，教育研究提供设计依据，具体学习路线与验收办法属于项目选择。沿用[跨学科依据](research-subject-content-guidelines-2026-10-15.md)和[物理学习设计](research-physics-learning-design-2026-10-15.md)，补充依据与局限见[本轮研究](research-course-quality-standard-2026-10-22.md)。

## 1. 先定义学生最终要做什么

每个学习段围绕一个中心问题，说明结束后学生能独立作出的判断、解释或操作。目标使用可观察动词，例如选择、推导、比较、建模、论证、评价；“了解某章”“熟悉公式”需要进一步说明实际产出。

写正文前，逐项目标对照以下证据。可在现有课程研究或实施记录中维护一张表，不另建一套重复台账。

| 目标与官方条目 | 必要先修及回补入口 | 概念讲解、示范位置 | 学生独立产出的位置 | 判断依据、常见错误及重试 |
| --- | --- | --- | --- | --- |
| 填写具体能力及范围 | 写清会用到什么，缺失时去哪补 | 指向实际段落或题目 | 指向任务；尚未提供则标“待补” | 写出何种推理算成立、出错后怎么办 |

一项任务可以检验多个目标，一个目标也可能需要多个任务。独立产出须真正调用目标能力：若目标是选择方法，就不能只给出已经指定方法的代入题；若目标是评价证据，就不能只让学生背评价术语。讲解覆盖和独立考查覆盖分开核查。

**验收：**每项目标都有可定位的讲解与独立任务，任务的判定依据与目标相符；没有证据的目标明确列为缺口。删去目标不能掩盖目标资格要求的遗漏。

## 2. 课程、学习页与参考资料各有职责

| 层级 | 学生要解决的问题 | 内容职责 |
| --- | --- | --- |
| 课程入口 | 从哪里开始，哪些部分可学？ | 标明阶段与实际范围；给出推荐起点、主题顺序和能力说明；未提供部分如实标识 |
| 单元路线 | 这些知识为什么放在一起？ | 连接中心问题、先修与后续应用；安排单元综合与回顾入口 |
| 学习段 | 这个概念怎样建立、怎样使用？ | 讲解、示范、学生行动、独立检查和纠错；在需要处提供回补链接 |
| 综合与复习 | 换了情境、隔了一段时间还能做吗？ | 提取、辨别方法、连接知识、迁移与再检查 |
| 速查与资料 | 已学过的内容怎样快速找到？ | 精简定义、条件、关系式和来源，链接回学习页；旧资料可查但不占主要学习路线 |

这些是职责，不要求各自新建一个网址。按概念依赖与学习转折分段，同一推理中的定义、图像和方程保持邻近。一页过长时先检查是否混入多个中心问题；分为多页时检查先修、承接和返回路径。不得按考纲编号、字数或固定课时机械切页。

学生入口使用主题与任务语言；题号、来源身份和必要考试范围仍应可查。作者检查记录、内部活动编号和维护说明放在制作记录或参考区，不让学生先读这些才能开始学习。初学、回补和复习入口可汇入同一正文，避免重复维护三套解释。

**验收：**从课程入口进入一个主题，能找到学习起点、先修回补和学后下一步；范围声明与实际可用内容一致。只有资料目录或部分单元时，不能标成完整课程。

## 3. 讲解必须帮助初学者重建推理

围绕“问题是什么 → 概念或模型如何解释 → 为什么选择这个方法 → 条件如何满足 → 怎样检查”组织讲解。例题的关键选择要说出来：变量怎样设定、图怎样读、式子为何这样列、候选方法为何可用。读者只掌握所声明的先修，也应能追踪这些选择。

首次出现的关键步骤展开解释，已经建立的常规操作可逐渐压缩。初学者所需的解释留在主线；补充推导、替代方法和拓展按需展开。核心概念不能藏在多个折叠框中，独立任务的提示与答案则按需揭示。

图、数据、类比和互动各自承担明确任务，例如观察变化、建立关系、转换表征或检验模型。图像与符号、单位、方向及正文保持一致；类比写清适用处与失效处。需要某种表征时才使用，不以图片、动画或交互数量衡量质量。

**审查例：**数值方法从给定区间 1–2 得到 1.3–1.4，应交代试值策略、实际经过的候选值与停止理由；另说明连续性和异号如何支持含根结论。只补上最终两个函数值，仍未解释端点怎样找到。这是推理审查例，不是要求所有算法逐个试遍区间。

**验收：**审查者能指出关键决策及依据，并用已声明的先修重建解答。若必须依靠未写出的新知识或猜测作者意图才能继续，先修或讲解仍需修补。

## 4. 从示范走向独立，保持任务与能力一致

按需要组合完整示范、解释步骤、补全关键步骤、纠错、单项熟练练习和独立选法。支架随能力建立而减少；先修已充分的学生可直接进入独立检查。首次尝试只使用已有知识，新知识需要明确讲解和合适支持。

独立任务应与示范共享所需知识，同时在条件、表征、情境或求问方向上作有意义的变化。单纯换数字可用于熟练练习，不能独自承担迁移考查。学生应先有机会作答；题目前后的标题、图注、相邻答案和默认展开内容，都不能提前替学生完成被考查的关键判断。保留必要无障碍描述，通过调整任务或布局解决泄露。

独立题可以提供折叠提示，使用后要按“借助提示完成”理解，不能算作无帮助的独立证据。若目标是选法，单元综合中应安排未标方法的任务，避免学生仅凭所在章节猜方法。已掌握的知识可逐渐混合；首次学习仍给足单项解释与练习。

学科的独立产出有所不同：数学需要可检查的推理与条件；科学还包括模型、机制、图表、实验与证据；经济需要具体情境中的传导分析和有条件的判断。按目标资格选择，细则执行 AGENTS，不把同一套计算题或固定栏目复制到所有学科。

**验收：**对照第 1 节逐项检查独立任务，而不是统计“独立练习”标题。比如 AS 代数 L01 的带支架题考指数改写，独立题考根式比较，重试考有理化；若课程要把指数改写也列为独立目标，必须另有对应证据，不能用同组里已有独立题代替。

## 5. 反馈、重试和复习要构成后续学习

反馈指出“哪一步或哪条解释不成立 → 原因 → 如何修复 → 回看哪里”。区分概念、方法选择、条件检查、表征、语言和运算错误；存在合理的替代解法时按论证核验，不只匹配标准答案措辞。评分材料与自拟检查点按 AGENTS 标清身份。

重试应检验刚修复的困难，收起原答案后再做。照抄修正答案只证明完成了订正。即时做对只能说明当前表现；在后续学习中再安排旧知识提取与延后检查，观察能否保留并使用。时间间隔按课程节奏和学生需要安排，不设全站统一的天数、正确率或题数门槛。

单元结束时，让学生在未提示方法的新任务中连接所学知识，再依据错误返回具体段落。可用纸笔记录“首次作答、用过的提示、错误原因、重试结果、稍后复查”；不以新增账户、打卡、积分或自动判分系统为实施前提。

**验收：**错误有可执行的恢复路径，重试确实对应目标，路线中有可定位的综合与回顾任务。页面写“请复习”“请独立完成”只是说明，不能替代实际任务。

## 6. 同一标准不等于同一版式

跨学科统一学生获得的支持：清楚的起点、可信解释、练习与反馈、可找到的下一步。章节标题、页长、图数、例题数、折叠块数以及是否需要模拟，由内容决定。避免把“目标—六个固定小标题—四题”变成批量生产模板。

中文负责清楚解释概念和反馈，保留必要英文术语与考试任务；逐步撤去英文表达支架。双语对齐检查题目身份、条件、数值、论证、答案、目标和学生可获得的帮助；语言可以自然重组，字数、标题数或公式出现顺序相同本身不是充分证据。

共享导航、公式、图像、键盘与手机阅读执行 AGENTS。技术检查用于发现缺项、坏链接或渲染问题；脚本通过不能代替对推理、任务难度和教学连贯性的审查。

## 7. 制作与验收流程

| 步骤 | 实际工作 | 本步结束的证据 |
| --- | --- | --- |
| 定范围 | 核对目标资格、现有内容与缺口 | 官方范围身份、现有资产用途和此次边界可追溯 |
| 做设计 | 写简短设计卡及第 1 节目标对应表 | 每项目标有讲解、独立产出与判定办法；新先修有回补安排 |
| 做样章 | 先完成一个有代表性的学习段及前后连接 | 已按下方四项内容检查修正；涉及页面时完成对应技术检查 |
| 再扩展 | 复用已审查的组织方式，逐章调整任务 | 每章重新检查目标对应和学科正确性；新类型先做该类型样章 |
| 交付 | 审查最终版本并记录范围与状态 | 内容、技术、试用证据分别列明；缺口与未检查项可定位 |
| 迭代 | 根据学生真实作答或明确反馈修订 | 记录具体失败位置、原因、修改与重新检查结果 |

样章至少检查四件事：①范围与学科内容正确；②仅凭声明的先修能读通；③独立任务检验了目标且反馈可用；④课程路径与后续回顾能找到。由审查者独立求解或重建解释，作者复核发现的问题。审查可由具备相应学科能力的人或独立代理承担，并记录实际核验内容；机械检查不算独立内容审查。只有作者自检时据实记录，不能标为独立审查通过；独立审查在扩展前补齐。

概念解释、定量建模、实验数据、证明与长回答等学习类型可以需要不同样章，不能从一个代数样章推断全学科可直接批量制作。可复用已通过审查且类型、阶段和先修相符的样章，不为每个小改动重做全部流程。

### 交付判定

| 状态 | 所需证据与使用边界 |
| --- | --- |
| 草稿／待修 | 尚有范围、正确性、目标任务或阅读流程缺口；可保存和审阅，不能列为已完成学习页 |
| 内容审查通过 | 范围、推理、目标对应、反馈与路线已审查；说明审查者和版本 |
| 技术检查通过 | 适用检查及实际页面验证有记录；可与内容状态分别报告 |
| 待学生试用 | 内容与技术已通过，但未获得目标学生的真实作答；可按既有授权发布，并如实说明试用边界 |
| 已有试用记录 | 记录对象背景、任务、所用帮助、错误与重试；结论限于实际观察，不能据此宣布普遍有效 |

上述状态不替代发布授权，也不要求新建状态管理功能。课程“范围覆盖完整”须逐项完成官方范围映射；“学习活动完整”还须目标、练习、综合和恢复路径齐备；“学习效果”另需相应学生证据。三者分别报告。

正确性错误、错误资格范围、核心目标未教或无有效独立任务、严重答案泄露、关键路径不可用，是内容交付的阻断项，修复前不得宣布完成或批量推广该模式。新版本只继承未受改动影响的证据，修改题目、条件、反馈或路线后重新检查受影响部分。

学生试用由真实参与者提供证据，作者模拟解题不能代替。记录必要背景和匿名任务表现，不收集不必要身份信息。延后任务与首次任务可比较，同时注明先修差异、期间教学和所用帮助；小样本与没有对照的观察用于改进，不能直接作因果效果结论。无法组织试用时，保持“待学生试用”，继续完成可做的内容和技术工作。

## 8. 现有课程怎样逐步优化

优先修复正确性与范围错误、关键先修断点、例题跳步、目标未被任务检验和反馈无处返回的问题；随后补单元综合与延后回顾；最后统一文字与页面表现。入口整理只能改善发现路径，不能替代这些内容修订。

先按目标对应表检查 AS 数学已做样板，再选与它不同的学习类型验证标准，之后才推广至 AS 高数、MA05 和其他学科。现有的可靠正文、真题与图像按用途保留，局部补充或重组；不因换标准就整站重写。

在本次改动对应的实施记录或已有任务中保留以下简短记录，不要求新增独立报告：

```text
课程／范围／页面／版本：
中心问题、目标与必要先修：
目标对应表及来源记录的位置：
样章选择与可复用原因：
内容审查者、发现的问题与修复：
适用技术检查及结果：
学生试用：未进行／对象背景、任务、帮助、错误、重试与延后检查
实际完成、剩余缺口与下一次检查：
```

维护者在出现新资格要求、重复的学习困难或标准与实际教学冲突时修订本文件，并在变更中说明依据与影响。默认做局部修订；稳定规则只维护在这里与 AGENTS 的各自职责内，研究记录保存证据和局限，避免多个“最新标准”并存。仅修改标准文档时检查链接、术语、规则一致性和改动范围，无需构建全站。
