## 方法与边界

逐页提取 Markdown 标题，阅读标题相邻正文及案例与概念之间的过渡，再判断标题所表达的包含关系。计数只统计课程源码中行首的 H2、H3、H4，不把粗体、`summary`、表格标签或布局提供的页面标题混入。中英文同名锚点与实际标题均核对，不以双语标题数相等作为语义正确证明。

语义判据：H2 可以是独立主题或学习阶段；H3 可以是其下并列概念，也可以是在较小主题下直接展开的并列示范／考查。只有当正文明确体现“概念包含任务”，却仍将两者作为兄弟节点时，才判断为扁平。不会机械规定所有题目必须 H4，也不会用“无跳级”替代内容判断。

目录脚本 `assets/js/toc_generator.js:146`–`:168` 按标签等级建立父子关系；同级标题会退出前一个标题的分支。因此下述问题会影响目录分组及按标题理解内容归属。这里只确认源码机制，没有执行浏览器目检。共享 CSS 已分别定义 H2、H3、H4，源码标题问题不需先改全站字号。

## 确认问题

### C-H1 · 第三周期：P1 同级混排，氧化物与含氧酸的上位概念不清

位置：英文 `period-3.md:39` 的 P1 H2；`:45` Example 1、`:59` 反应方程式、`:120` Example 2、`:134` 酸与阴离子结构、`:148` Example 3，以及 `:162`／`:194`／`:222` 的 Q1–Q3，全是 H3。中文对应 `:40`、`:46`、`:60`、`:121`、`:135`、`:149`、`:163`／`:195`／`:223`。

这里不是不同类型标签表面并列的问题：`#oxoacid-structures` 讲从含氧酸移去 H⁺，紧接着的 Example 3 正是这一概念的示范，却与它平级。另一个更实质的问题是 `#reaction-equations` 标题只称“与氧、氯反应”，其正文先列生成反应，又在英文 `:88` 起转到氧化物结构、酸碱性及与酸／碱／水反应，一直延续到 `:118`。目录没有相应的“氧化物结构与酸碱性”节点；Example 2 的酸碱判据看不出归属。P1 从英文 `:39` 延续至 `:247`，确实包含数个不同概念转折，不能全视作一段短导入。

影响：复习时无法从标题树找到氧化物酸碱性这一学习块；含氧酸结构与示范拆成兄弟项；Q1–Q3 列在所有这些概念之后，目录不能表达对应关系。

最小建议：保留 P1／P2 H2 与现有锚点，在 P1 内按正文已有边界设 H3“结构与性质”“生成与水反应”“氧化物结构及酸碱性”“含氧酸与阴离子结构”；将明确隶属的示范与题目放到相应 H3 下用 H4。这需要把现有 Q1–Q3 移到匹配概念附近，不能只把所有 Example／Q 机械改成 H4——那会把后续 Q1 镁与水等题目错误挂到“酸及阴离子结构”之下。P2 现有短模型导入＋Example 4／Q4 的 H3 并列可以保留。

### C-H2 · 热力学：T4 中 Gibbs 概念与其应用例题平级

位置：英文 `thermodynamics.md:317` T4 H2、`:327` 绝对熵示范 H3、`:347` “From entropy to Gibbs free energy” H3、`:360` Example 4 H3、`:381` 熔点熵变 Q6 H3；中文对应 `:318`、`:328`、`:348`、`:361`、`:382`。

`#gibbs-temperature` 不是单独的例题：其正文讲四组焓／熵符号的条件、阈值、图像斜率以及可行与速率的区别，随后 Example 4 正是此模型的数值与图像应用。两个 H3 让目录把概念与从属应用并列，丢失了真实关系。

最小建议：T4 下设 H3“熵与熵变计算”和 H3“Gibbs 自由能与温度”；前者纳入绝对熵示范与熔点 Q6，后者纳入 Example 4，并将这些从属示范／题目用 H4。若仅把 Example 4 降为 H4，虽可修复这一对，但 Q6 仍在 Gibbs 段后且缺少清楚的熵计算归属；要检查完整树而非单点变号。

保留项：T1／T2 直接讲定义或循环，再以 H3 并列示范与真题是合理的。T3 的 `#ionic-model-comparison`（EN `:192`／ZH `:193`）正文实际包含一份短 worked comparison，和水合示范并列不构成自动错误。若以后把 T3 拆成“溶解水合”“离子模型检验”“量热”三个真正概念块，再分别组织 H4；本轮不因其没有 H4 把 T3 整段列为确认缺陷。
