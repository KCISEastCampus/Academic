# A2 Pure Mathematics 标题语义审查

日期：2026-10-15。范围：现有 Pure 入口、15 个学习页与速查，中英文 34 页；不包括 Mechanics、Statistics。逐页阅读当前标题序列，并核对新概念、例题及方法延续处的相邻正文。没有修改课程标题。

## 结论

多数页面具有可理解的 H2 主题 → H3 示例或练习关系，不能说源码只有 H3。确切问题是部分新方法被埋在例题里，以及例题内的另一解法和概念标题被放在同一级。全科英语正文为 H2 106、H3 253、H4 15；中文版相同。H4 少不是错误指标。

当前 Markdown 与生成 HTML 的标题等级一致；细目见证据 `current-heading-trees.json`。这个检查只证明解析一致，不证明语义合理。页面 H1 由共享布局输出。

## 需要重组的确证位置

### M-H1：积分把新方法全部归在“例题”之下

中文 `integration.md:93` 的 H2“例题”包含五个 H3，分别首次示范化简、逆链式法则、换元、分部积分和对数形式。换元只在例题 3（`:121`）中展开，分部积分公式只在例题 4（`:143`）内引入；“对数函数也可以视为乘积”又以普通粗体段落附在同一例题之后。英文对应 `integration.md` 的同名稳定锚点。

这不是五道题本应分为五级，而是“方法 → 适用条件与推导 → 示范”的关系没有写进目录树。学生按目录找 substitution 或 integration by parts 时，只能看见泛称 Worked examples；当前作业帮助链接被迫直接指向例题锚点。

建议按方法设置实际教学节，条件、必要公式和示范放在一起；已有示范标题保留 ID。若保留一个总的“积分方法”H2，方法用 H3，所属例题才用 H4；也可让每个方法直接成为 H2，例题维持 H3。根据正文规模选一种，不为增加层数再造空标题。综合练习仍可统一放在 H2 练习下。

### M-H2：多项式除法中“同一例题的另一种解法”退出了例题分支

中文 `algebraic-fractions-and-division.md:161` 的例题 5 与 `:191` 的“用长除法再做一次”同为 H3。后者正文明确在解同一个三次多项式除以 x+2 的问题，使用相同商和余数。英文同名锚点为 `example-5--remainder-theorem-and-comparison-of-coefficients`、`the-same-example-by-long-division`。

如果这一段仍是例题 5 的第二种解法，应作为其 H4 或例题内部的解法标签。若要教通用长除法，应独立为方法 H3，先交代方法，再把相应示范放在其下。现在的“再做一次”依赖上一个标题，却在结构上与它平级。

## 不应机械改动的结构

- 多数页的 H2 已是较小概念，例如“复合函数”“乘积与商”“隐函数”“两条直线的位置关系”；它们下面的 H3 并列例题合理，无须套一层虚构的“示范”再降为 H4。
- 练习 H2 下的 Q1–Q8 是并列独立任务，可以采用 H3。综合题可能覆盖多个知识块，不应为了标题树把它强塞进单一概念。
- 数值方法已存在“数值积分 H2 → 中点法／辛普森 H3 → 对应例题 H4”，体现真实方法包含关系。
- 速查按大纲领域 H2 → 具体知识 H3 → 必要细目 H4，具备较深层级。它是速查结构，不应原样成为所有学习页的固定模板。
- 定义、检查、常见错误等短段落可以使用普通段落与粗体。不是每个粗体标签都应成为标题。
