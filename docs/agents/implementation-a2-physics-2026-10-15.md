## 与普数、高数的教学结构对齐

逐页对照中文普数的 `partial-fractions.md`、`differentiation.md`，以及高数的 `hyperbolic-functions.md`、`first-order-differential-equations.md`。对齐的是学习过程：先尝试判断方法、说明模型成立的条件、分步示范、独立练习、按错因回看并重做。不同数学课的例题折叠方式并不完全一致，热学沿用可直接阅读的示范和分别折叠的练习提示、解答。

| 数学课中的做法 | 热学中的对应内容 |
| --- | --- |
| 学习目标、先判断方法、选择第一步 | 新增模型选择小节、三项先试情境、题目线索与模型条件表 |
| 公式或方法推导后再应用 | 动量传递推导分成一次碰撞、每秒动量、整个气样三个步骤；补充恒压升温的分子解释 |
| 例题讲清第一步并验算 | 八道例题明确模型、计算和检查；新增双流率消去热损失、恒压压缩与第一定律两道自拟例题 |
| 基础到组合应用，再到解释 | 十道练习按建立模型、组合步骤、解释与评价分三轮，提示与解答独立折叠 |
| 错因回看、关闭答案重新尝试 | 错因表链接到对应知识点或例题，记录卡住的步骤，两天与一周后重做 |
