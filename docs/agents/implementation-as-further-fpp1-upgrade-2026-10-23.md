保留题边界：diag(2,1) 的不变线为全部 y=k 及 x=0，固定点恰 x=0；[[2,1],[0,1]] 的不变线为全部 y=k 与 y=−x，仅后者逐点固定，无竖线；S 关于 y=x/√3 反射，MS 面积 6→12，方向反转。diag(1,3) 为全部 x=h 与 y=0，固定点恰 y=0。

通用断言：可逆 M=[[a,b],[c,d]] 的非竖线 y=mx+k 必须同时满足 c+dm=m(a+bm) 与 (d−mb−1)k=0；竖线 x=h 必须满足 b=0 与 (a−1)h=0。奇异映射须另查直线是否压成一点，不能仅用系数条件宣称“映到整条线”。正文给出任意 x/y 的比较系数论证，计算抽样不充当穷尽证明。
