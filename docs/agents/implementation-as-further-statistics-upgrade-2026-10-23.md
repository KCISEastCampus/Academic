## 几何分布简短设计卡（先于正文）

- **中心问题：**同一条成败序列，计试验次数与计失败次数为何相差一？怎样从概率质量函数推导两种矩，而不把公式当起点？
- **可观察目标：**解释模型条件与支持集；用事件推导点概率、尾概率及条件概率；从收敛级数独立推导均值、方差；平移到失败次数；处理 p=1 和零概率条件事件；稍后在未命名分布中重建这些联系。
- **先修与回补：**AS 独立事件与条件概率；E(Z)、E(Z²)、方差的定义；等比部分和极限及基本微分。入口诊断只用已学概率和有限分布；正文直接补出矩定义、等比和及所需导数关系，不要求学生先会 PGF。
- **模型与条件：**独立、同一成功概率、一直到首次成功；0<p≤1。先处理 0<p<1，再由常量直接检查 p=1；p=0 不在模型内。不放回抽样一般不适用。
- **表征用途：**文字成败序列对照事件与指数，短对照表区分三个尾部边界；无需新增图像。原页无图，不通过删替代文字处理泄露。
- **连续示范：**先讲成败序列与尾部，再补矩定义与等比和 → 以独立变量 t 求导 → 均值 → 二阶阶乘矩 → 二阶原点矩 → 方差与边界 → 完整数值示范 → 失败计数。推导例和数值例各自连续完成，不把原数值题的“moments”拆到别处作答；关键选择、幂次补偿及收敛条件展开。
- **独立与反馈：**保留原反求参数题；新增从 PMF 推导两矩、未标方法的固定窗口/等待时间混合任务。各题自己的默认关闭 hint / solution；失败计数推导重试与混合重试分别修复矩与事件判断；后续 PGF 学完返回未命名 PMF 归一化、推矩和条件概率。

### 交给共享计算测试的关键断言

以下是应断言的数学等式，浮点计算使用既有近似比较助手；零概率条件应断言“不定义”，不能把除零结果当成概率。

```text
q = 1-p, 0<p<1
EX = 1/p
EX_factorial2 = 2*q/p^2
EX2 = EX_factorial2 + EX = (2-p)/p^2
VarX = EX2 - EX^2 = q/p^2
EY = q/p
EY_factorial2 = 2*q^2/p^2
VarY = EY_factorial2 + EY - EY^2 = q/p^2
P(X>k) = q^k                 [integer k>=0; at k=0 use 1]
P(X>=k) = q^(k-1)            [integer k>=1]
p=1: support(X)={1}, support(Y)={0}, EX=1, EY=0, both variances=0
p=1: P(X>2)=0 => P(X>5 | X>2) undefined
Q1: [p, conditional, mean, variance] = [0.4,0.24,2.5,3.75]
Q3: [tail, single-response probability, failures mean] = [0.4096,0.384,4]
R3: [tail, conditional tail, without-replacement tail, independent tail]
    = [0.81,0.729,0.5,0.59049]
W: c=1-a, mean=a/(1-a), variance=a/(1-a)^2, tail=a^3
W: a>0 => conditional=a*(1-a); a=0 => conditional undefined
Official Q8(a): 1-(1-1/5)^3 = 61/125
```
