# FM03 双曲函数通俗化样段

## 制作前设计卡

- 请求与边界：按 2026-10-24 可读性审查，先优化双曲函数的定义入口、首个示范和邻接尝试，供用户确认。只改中英文该页、必要检查及本记录；不扩展其余 FM03 课程，不改共享样式，不发布。
- 中心问题：`sinh`、`cosh` 这些新名字到底表示怎样的计算？它们与后续比值、倒数及恒等式怎样连接？
- 学生：已学指数与对数，但首次学习双曲函数。先会负指数表示倒数、指数与对数互逆、平方展开。反函数与微积分的先修在进入对应部分前再查。
- 核心：先建立两个指数表达式的差／和，正常展开零输入示范，再让学生独立从数值反推定义式。比值与倒数稍后介绍；反函数记号仍与倒数区分。六个指定图像及整章范围保留。
- 示范与提示：复用 reading_layout、worked-example 和 lesson-check；新尝试有分别关闭的提示与答案。原 Example 1、题干、数据与稳定锚点保留。
- 图的作用：保留原六图用于后续图像理解；本样段用两个短定义和计算建立记号，不增加装饰图。
- 独立与重试：新任务不只重复零输入；从 e^a 的值求函数值并比较，再由已知 sinh b 反推 e^b、说明符号。错因回指差／和的定义与负指数回补；新重试在关闭答案后完成。
- 评分与范围：自拟任务无官方分值。当前资格页及其 PDF 正文核对为 OxfordAQA 9665、v5.2、FP2.9（印刷 p19／一基 PDF p18）；不迁移 9765。官方范围见[大纲](https://www.oxfordaqa.com/wp-content/uploads/2026/07/oxfordaqa-a-level-further-mathematics-specification.pdf)。
- 制作前配套阅读：本地 January 2025 FM03 QP 封面、Q2(a)(b)（PDF／印刷 p4），MS Final 1.0 封面及 Q2(a)(b)（p5），提取后实际渲染并读取公式。Q2(a)要求指数定义、至少两步中间式；Q2(b)要求运用前项恒等式、二次方程、排除不合 cosh 范围的根并给全部精确对数解。本次不移植原题及分值；用其确认定义推理和条件不得因通俗化而删去。来源：[QP](../../assets/pdf/fx-cg50/references/oxfordaqa-fm03-2025-january-question-paper.pdf)、[MS](../../assets/pdf/fx-cg50/references/oxfordaqa-fm03-2025-january-mark-scheme.pdf)。
