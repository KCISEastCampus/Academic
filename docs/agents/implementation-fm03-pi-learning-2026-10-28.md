# FM03 找 PI：表格与分步学习改版

日期：2026-10-28。用户授权：根据教师提供的表格开始制作，完成后提供局域网预览。只改双语二阶微分方程及直接相关检查，不推送或发布。

## 制作前设计卡

- 中心问题：怎样选一个合适的 PI，再通过代入确定它？
- 可观察目标：查表选完整函数族；按 CF／根重数修正重复；求导并逐类比较系数；在完整题中合成 CF＋PI 后使用条件。
- 先修：指数／三角求导、乘积法则、CF 与辅助根、比较系数。初练给 CF 或说明不重复，把 PI 选择与 CF 计算分开；后续撤去支持。
- 关键模型：常系数线性二阶方程；PI 代入左边得到非齐次项。表格是起步形式，不能忽略 CF 检查。多项式按零根重数整块乘自变量，不只改某一项。
- 表的用途：按用户提供的教师表整理为可访问的文字／公式表；用 C、D、E 与 CF 的 A、B 区分，补三四次多项式及混合项。图片未给书名、版本、页码，不冒认具体教材或考试局原表。
- 示范与尝试：普通指数示范后立即尝试；完整多项式和三角配对各有漏项诊断；再比较同右边、不同左边；单根、重根、零根与三角重复后进入综合。
- 反馈：每题自己的默认关闭提示／解答；按函数族、重复、求导、比较系数和条件分类回补。新增 PI 重试只检验该技能，原逆向综合题保留。
- 版式：沿用 reading_layout、worked-example、lesson-check；重根的失败与成功分段呈现，不改共享 CSS；保留旧锚点及原有效任务。
