# FM03 全课程升级与学生反馈修订

## 设计与范围（实施前）

基线 `d50b33b`。对象为 OxfordAQA 9665 的 FP2／FM03，现有十六课及双语入口，共 34 页；不扩展到 A2 统计、力学或新版资格。依据现行课程内容长期标准 v1.1，保留正确讲解、原题、图像与稳定锚点，按前次审查的具体缺口局部升级。

中心问题：学生能否跟随完整推理建立方法，独立选择、论证与检查，并在出错后回到同一困难再尝试？先修使用已存在的 AS 高数、MA03 与本课程具体技能段。按代数证明、复数极坐标、微积分与方程、空间与矩阵四组制作，作者检查后由另一审查者复核；主作者负责一阶方程、课程级综合与最终技术验收。

### 已收到的样章反馈

2026-10-23 用户明确报告学生试用反馈：内容结构和格式有大幅改善；截图中从乘积导数直接跳到原函数的积分过程不应省略；其他没有问题。没有参与者人数、背景、作答、帮助使用、重试或延后表现资料。本记录只支持样章阅读反馈，不支持全课程掌握或普遍学习效果结论。

修订先后：先检查一阶页全部解答的积分过程，再扩展到其余 FM03。写清两边积分、右侧积分如何计算、原函数及常数；换元交代变量和微分关系，定积分交代上下限代入，反常积分保留极限。用户随后明确：这个逐项积分要求仅适用于一阶章；其他 FM03 章节保留对应官方评分材料的关键方法、条件和得分步骤，常规运算可合理压缩，不机械逐行展开。自拟／改编题参照同类官方方法核查，不能称有官方分值。

## 官方范围与课程入口设计

本轮从 [9665 现行资格页](https://www.oxfordaqa.com/qualification/international-as-and-a-level-further-mathematics-9665/)的 specification 链接读取[官方 PDF](https://www.oxfordaqa.com/wp-content/uploads/2026/07/oxfordaqa-a-level-further-mathematics-specification.pdf)，正文 v5.2。FP2.1–14 在印刷 pp.16–21／PDF pp.15–20；官方范围为实系数根、整数幂与全根、正半径极坐标、归纳与有限和、级数极限和反常积分、反三角／双曲微积分、弧长和绕 x 轴曲面积、一二阶线性方程、空间向量及三阶矩阵和线性方程。未转移到 9765。不同主题的细项与独立任务定位由四组目标表及原范围研究共同提供。

入口保留原十六主题路线、十四大纲主题表与稳定锚点；先修指向现有 AS 复数、AS 代数与积分，逐课再提供精确技能。新增三道跨章自拟题与三道稍后回顾，提示／解答分别关闭，不把六题当作全课程覆盖证明：

| 入口任务 | 实际连接与学生产出 | 判据与错误恢复 |
| --- | --- | --- |
| mixed-a | 三次全根、Argand 图、根与系数的双重论证 | 三个互异根、完整图示、平方和的理由；返回 complex roots／根系数 |
| mixed-b | 双曲指数定义、一阶解、初值、展开求极限 | 符号、系数、常数与低阶抵消；返回双曲定义、一阶例 1、series |
| mixed-c | 非奇异系统、重特征值完整解空间、候选向量判断 | 唯一性、全解族、排除零、逐坐标比较；返回矩阵、系统、特征值 |
| later-a | 极坐标描绘一次、Cartesian 圆、面积核验 | 角域、半径、积分系数与上下限；返回 polar／多角恒等式 |
| later-b | 参数微元、双曲换元与区间估计 | ds、正根、换限、原函数和上下界；返回 arc／hyperbolic |
| later-c | 固定集合、实特征空间、法向和反射 | 两个独立约束与任意向量分解，区分整平面不动与法向反向；返回 lines／matrices |

主作者已独立推导这六题，另交不同代理重新核算；自拟检查点不赋官方配分。入口综合未安排已学全部主题的每一种题型，逐章独立任务仍为主要证据。来源／教材查找表保持折叠，学生无需先阅读制作记录。

## 本轮验收

### 内容与数学

本轮完成十六课和双语入口，共 34 页。一阶章逐项补齐方法构造、例 1–6、Q1–6、标准化重试和稍后回顾中的积分：明确两边积分、右侧原函数的系数、常数和适用区间，并回原方程检查。其余章节按用户补充保留关键得分证据，未把逐项积分要求扩大成全课程算术逐行展开。

| 分组 | 本轮主要结果 | 独立复核 |
| --- | --- | --- |
| 一阶与课程入口 | 完整积分链；六道可作答的跨章／稍后回顾；精确恢复链接 | [一阶与入口审查](review-fm03-first-order-rollout-2026-10-23.md)，R1–R3、I1 已关闭 |
| 复数与极坐标 | 完整全根与图示、精确值、重试；极坐标表示、描绘角域及面积任务 | [复数极坐标审查](review-fm03-complex-polar-rollout-2026-10-23.md)，CP1 已关闭 |
| 归纳与级数 | 实际求导形成系数、未预告方法的求和、端项重试和后续调用 | [证明级数审查](review-fm03-proof-series-rollout-2026-10-23.md)，R1 已关闭 |
| 微积分与二阶 | 公开首次示范、反函数／双曲图与论证、弧长与曲面积建模、共振及反向恢复任务 | [微积分审查](review-fm03-calculus-rollout-2026-10-23.md)，R1–R3 已关闭 |
| 空间与矩阵 | 几何条件、向量方向、线面关系、可逆条件、完整特征空间和选法任务 | [空间矩阵审查](review-fm03-geometry-matrices-rollout-2026-10-23.md)，G01、G02 已关闭 |

五份审查由相应分组作者以外的审查者完成，包含独立计算、双语任务与帮助、来源及目标证据；审查范围是本轮新增／改变内容和判断它们所需的关联上下文，不冒称重新审完全部历史题目。保留官方题身份与原配分；自拟、改编题不赋伪官方分值。
