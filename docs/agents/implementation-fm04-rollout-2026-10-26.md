## 正文前的设计卡与证据计划

中心问题：如何从随机变量的模型推导平均与变动，再根据抽样方式和未知量，选择估计与检验方法？先修为期望、方差、独立性、指数积分、正态与 MA04 检验基础；每课给出精确回补入口。沿用样章的直观解释、可见完整示范、分别关闭的提示和答案、同目标新重试及稍后混合任务。

| 官方条目／可观察目标 | 教学页及独立证据计划 | 反馈与回顾 |
| --- | --- | --- |
| FS2.1a,b：离散／连续定义、零点导数、仿射变量 | 保留 moment-generating-functions 的 task-a/b；standard-mgfs 连续积分任务 | 原样章三个 retry；连续积分新 retry |
| FS2.1c,d：Poisson、指数、正态的推导，存在范围与独立和 | standard-mgfs：从定义推导、区间交集、识别和的分布 | 对比重复变量与独立变量；跨课混合回顾 |
| FS2.2a,b,c：参数与统计量、抽样分布、无偏、一致、效率及组合 | estimators：枚举抽样分布、比较与修正估计量、相关组合 | 明确偏差与方差分别修复，新的组合任务 |
| FS2.3a–d：三类均值区间、解释、候选均值、宽度与样本量 | confidence-intervals：条件选择、计算、反推及向上取整 | 不将置信度赋给已固定参数；稍后方法辨别 |
| FS2.4a：第二类错误与简单备择下功效 | test-power：固定拒绝域，连续及离散功效计算 | 不把显著性水平和功效混淆 |
| FS2.4b：独立均值差的已知／大样本／合并 t | comparing-means：从样本条件选择并检验 | 不滥用合并方差；后续混合任务不标方法 |
| FS2.4c：配对小样本 t | paired-tests：定义差、选择抽样单位与检验 | 检查差值正态；观察前后不宣称因果 |
| FS2.4d,e：单正态方差及独立正态方差比 | variance-tests：两尾与单尾、分子及自由度次序 | 新情境重试与方法选择 |
| FS2.4f,g：离散／连续拟合、列联表、2×2 Yates | goodness-of-fit、association-tests：概率、期望、合并、自由度、校正与结论 | 所有期望严格大于 5；拟合参数扣自由度；混合回顾 |

教材为用户提供 Oxford 2017 Further Mathematics with Statistics（506 页扫描件，PDF 页 = 印刷页 + 4），章节 29–33。配套实际来源为 Drive 的 2025 年 1 月、6 月 FM04 题卷及评分标准，身份、题号、页码和重新核算见三个 research-fm04-*-pack 及已有 research-fm04-textbook-papers。新增例题均明确自拟，不借用官方分值。教材和试卷不公开复制入库。

课程入口须给出全部实际可用课程及未标方法的综合／稍后回顾；讲解覆盖与独立证据逐项复核，不以页数代替完整性。

| 初次发现 | 修复及相同位置复查 |

| 指数 MGF 推导只讲未独立考查 | standard-mgfs task-e 从平移密度推导积分、有限界、极限和边界；retry-a 重新推导另一速率；补分部积分先修与关键步骤 |
