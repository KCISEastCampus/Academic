## 设计卡：IG 运动与运动图像

- 中心问题：同一次往返运动，平均速率为何不等于平均速度？怎样把运动、位置记录和速度图联系起来？
- 可观察目标：区分路程与位移；从位置—时间图的斜率判断方向和速率；从速度—时间图的斜率、面积判断加速度、位移和路程；解释停下、反向与减速的区别。
- 先修：坐标、正负数、直线斜率、矩形与三角形面积；给出新量定义后再进入多图转换。
- 模型与条件：沿直线运动，预先选定正方向；分段直线图是理想化模型；不把速度图当作空间轨迹。
- 图与数据：一幅位置记录图用于读斜率与补速度表；一幅跨零速度图用于区分减速、反向和有符号面积。图上的坐标和表格由相同构造记录生成，替代文字提供必要读图信息，不提供待求答案。
- 示范与支架：先示范一段，再让学生完成其余段；提示与反馈分别关闭；让学生补图、纠错并用不同运动记录重试。
- 独立考查：无方法标签的往返任务、由描述设计速度图、处理稀疏位置记录的推断边界；英文题干与中文解释配对。

## 设计卡：AS 测量与不确定度

- 中心问题：读数很集中是否就说明结果准确？用哪些证据判断测量结论是否可靠？
- 可观察目标：SI 换算与量级估算；区分随机／系统误差、准确度／精密度、重复性／再现性／分辨率；处理零点修正、差值与幂次传播；用误差棒判断斜率和截距的可接受范围。
- 先修：IG 单位与测量、比例／百分数、直线方程；不要求学生先知道误差传播规则。
- 模型与条件：给定保守绝对不确定度、小不确定度一阶合成；各读数误差独立或相关的模型须说明，尤其是同一零点修正抵消的情形。
- 图与数据：构造直线记录及纵向误差棒，用整组记录约束直线；明确横坐标不确定度在本任务中忽略。图中不提前标出极限直线或参数答案。
- 示范与支架：零点校准、读数差、圆柱体积；误差棒部分先评价一条候选线，再独立找极限斜率和截距。
- 独立考查：带偏差的重复记录、仪器方案选择、原始数据与未标方法的密度任务；用不同观测重新判断，并保留英文输出要求。
