## 范围和设计卡

目标资格为 OxfordAQA International GCSE Mathematics 9260 Extension，当前资格页所链接正文 Version 5.1；不迁移至 9233。按用户最终要求提供单一路线，包含 Extension 所需基础，不另设 Core 路线。官方范围为 N1–N20、A1–A26、G1–G26、S1–S18 共 90 个编号；覆盖须按实际能力细分，不能只匹配编号。PDF 下载与提取不等于完成阅读，作者逐组登记实际读过的试卷与配套评分页。

中心问题：面对数量、关系、图形或数据，怎样选择方法、说明条件，并检查结论？先修从位值、四则和简单图形起步；缺失处链接具体解释。概念用简单语言和必要图表建立，完整示范说明方法选择，独立任务改变表征或求问，反馈指出错误原因，再做同目标新题；分支结束及其他分支之后安排混合与回顾。

### 用户确认后的范围调整

用户明确学校只开设 Extension。最终课程只提供 **9260 Extension 单一路线**，入口和正文取消 Core 学生分流、跳过指引及逐题层级标签。Extension 仍要求运用的分数、比例、基础代数、图形与统计知识继续保留为先修和正文基础；它们不是另行制作的 Core 课程。作者和审查记录可保留官方两列的位置，以追溯范围核验。已认可样章中的 1C 官方题只作基础能力练习，保留真实来源身份，不冒称 Extension 原卷题。

## 制作与复核约定

各组在自己的制作记录先写目标→先修→讲解／示范→独立任务→反馈／重试映射，实际阅读相关 Specimen 2018 QP 与 MS 后再写正文。图形论证、数据图和微分分别先检查一个代表段，再扩展同组；最终由另一位执行者独立复核。作者记录不当作独立审查。

统一复用 subjects、reading_layout、worked-example 和 lesson-check；不改共享样式。各页提供 #start、#practice、#retry、#next-step、#sources 等具体可链接位置，按需要另设概念锚点，不要求固定标题／题数。保留英文题干、数据、条件、公式与答案的双语对应；自拟任务不标官方分值。

旧入口锚点、17 个 PDF、Lynn 署名和已认可样章锚点保留；参考笔记降为可展开资料。没有读过的旧 PDF 不声称其身份或覆盖已验证。其他未跟踪 AI 原型、发布记录及依赖文件均不编辑、不纳入交付。

## 验收状态

### 综合与延后回顾设计（先于正文）

综合页全部自拟、无官方分值，保留英文题干。Number 任务连接比例尺、面积、份额与折扣，以及测量上下界与决策；Algebra 任务从票价情境列联立方程，并在 Extension 处理中限制函数的逆与候选根；Geometry 任务判断相似长度／面积／体积及路线方向；Data 任务比较分布并在限定条件下更新概率分母。延后题再提取百分率／方程及 Extension 导数及驻点类型。每题有分开的关闭提示／解答，错后链接具体主题，再做该页同目标重试。

主执行者实际阅读来源：9260/1E Specimen 2018 Q6（QP PDF p.4／MS p.4）、Q7（QP p.5／MS p.5）、Q10（QP p.8／MS p.6），核对保存周长、质因数与 HCF、体积→容量→时间的证据链；这些只支持设计审查，不将综合自拟任务称为官方题或套用原分值。来源身份已核对封面；不使用 Q11 提取乱码作为公式依据。

复核后的补充设计：garden 的面积尺度错误不能用只求长度的新题验收，因此在综合页增加自拟 `retry-map-area`：给图上周长与一条边，先恢复另一条边，再转换两条实际边求面积，核验是否把比例尺只乘一次；判定依据与结果均在关闭解答中。clubs 的独立性误判回补改用已落地的四格表独立判断题，而非题干已经给出独立条件的计算题。
