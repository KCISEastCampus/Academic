- [Spec 独立记录](review-ma03-plain-language-spec-2026-10-24.md)：核对用户的初学者要求、概念衔接、题目条件及英文任务保留，检查官方材料的代表性方法证据。发现公式检查漏检及 DE 一般记号前置问题；两项均经独立复核关闭，参数条件补充修正也已独立解析核对，最终无开放发现。

具体失败与同处复查：

1. 微分方程在首个具体例题前放了未解释的 `f/g/G/y(x)` 论证。现先用 `dy/dx=2xy` 解释分开变量，在例题中联系已学换元与链式法则；一般论证放在完整例题后，说明 `G` 是关于 `y` 的原函数。除数非零、常数解与合并积分常数仍保留。最终手机逐段截图确认先例题、后一般论证，示范没有被折叠。
2. 参数方程把 `dx/dt` 非零说成水平切线的必要条件。现仅在可用导数比值时采用该检查，并说明两率均零时要消参或另求极限。审查用 `x=t³,y=t⁶` 消去参数得到 `y=x²`，确认原点仍有水平切线；既有数学检查补入此反例。最终手机在驻点段复读条件与后续例题。
3. 初次技术检查把普通英文 `quantity’s` 误报成导数引号错误。修正为仅检查数学片段后，独立审查又发现生成 HTML 的独立公式使用另一种定界符，仍有漏检。最终三个脚本同时识别美元、方括号和圆括号 TeX 定界符；普通撇号不报错，行内及独立公式中的错误导数引号仍检出。三个脚本自身探针、真实生成 HTML 检查及独立探针均通过。未为迁就测试删改正常英文。
4. 中文自然对数直接解释“反过来问指数”，去掉不必要的比喻对照；最终复读其输入正性与指数对应关系。

分组作者记录中的冻结哈希是独立审查前的快照；主代理随后调整了双语微分方程、双语参数方程及中文指数对数这五页。最终版本以 [源码／HTML 清单](audit-assets/ma03-plain-language-2026-10-24/source-manifest.json) 和两份独立审查的最终哈希为准，不将旧哈希视为最终验收。
