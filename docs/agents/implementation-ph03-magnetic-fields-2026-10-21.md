## 学习设计

| 项目 | 安排 |
| --- | --- |
| 中心问题 | 为什么磁场能改变轨迹却不直接给自由粒子增加动能？ |
| 可观察目标 | 根据电荷、电流与场确定力；定义 tesla 并注明垂直条件；由磁力作为径向合力推导半径/周期；连接电场加速、速度选择与质量分离；解释回旋加速器同步条件；从天平原始记录估计 B 并诊断偏差 |
| 先修 | 电场的电荷符号与功、圆周运动、AS 常规电流和牛顿第三定律；在对应转折处链接 |
| 模型与条件 | 匀强静磁场，垂直入射，真空或可忽略碰撞，低于相对论适用速率；忽略重力等较小力。区分导线和磁体两个研究对象、源/探测器零点和有效长度。速度选择器中必须两力反向；回旋加速器中电场只在间隙增能 |
| 图与记录 | 导线/磁体受力示意、独立粒子方向图、选择器与半圆分离示意、回旋加速器两段轨迹。出/入纸面符号配文字；独立题不预画所求力或曲线。天平数据明确构造，不称 RP7 或实际实验 |
| 示范与反馈 | 先直接解释一种正电荷方向和电流约定，再改负电荷/方向；圆周关系从受力建立；提示、解答分别默认关闭，反馈解释半径/直径、电场/磁场、恒速/加速和作用反作用错误 |
| 独立考查 | 改变保持量比较粒子；从电压和轨迹反推质量/电荷比；同速同位素分离；改变电荷符号或场后重试；自己选择天平作图量，解释斜率单位、零点和有效长度偏差 |

独立核验包括：

- 用带符号的洛伦兹力与四阶数值积分检查正负电荷、场反转、半圈直径、整圈闭合及速率不变；电子例题得到约 0.023 m 和 72 ns。
- 从页面实际记录拟合，而非重用给定结果：斜率约 −0.3263 g/A、截距约 −0.00095 g、场约 0.080 T；残差均小于 0.004 g。误用 0.050 m 有效长度使结果偏低 20%。
- 电压加速的能量与质量电荷比一致；同位素分析场约 0.63 T、返回点间距约 9.7 mm；选择器与分析场不混用。
- 回旋加速器逐次跨隙累加电功并检查半圈同步：约 7.6 MHz，40 次跨隙后 40 keV、轨道半径约 0.058 m；没有把磁力写成增能来源。
