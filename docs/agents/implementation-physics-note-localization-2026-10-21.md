# AS 与 IGCSE 物理笔记汉化

日期：2026-10-21。范围：现有中文学习页的题源说明、图片替代文字，以及 AS 物理、IGCSE 物理的笔记正文。未扩大为新课程，也不声称现有笔记覆盖全部大纲。

## 设计卡

- 中心问题：学生能否在中文站内阅读现有物理笔记，同时保留英文任务与公式，并在两种语言之间定位同一主题？
- 可观察目标：阅读中文概念解释与示范解答；用英文回答原有例题和自测题；按原锚点切换语言；先尝试 IGCSE 自测再展开答案。
- 先修与定位：沿用原有 AS 与 IGCSE 笔记的主题顺序和先修；这是复习笔记汉化，不是完整教学活动重设计。
- 核心模型：保留方程及变量定义，补清适用条件；不把量纲、方向或模型问题作为翻译忠实度的借口保留下来。
- 图与数据：本批两份笔记没有新增图片或实验数据；原有英文 PDF 资料仍标明语言。既有 A2 页的图片说明译为中文，保留必要信息。
- 示范与提示：AS 的五道现有自拟示范保留英文题干、中文解答；IGCSE 的 26 道自拟自测保留英文题干，答案分别默认折叠。没有新增官方原题或评分分值。
- 独立考查：沿用原有自测，不能据此宣称已证明迁移能力或学习效果；更完整的课程设计应另行安排。

## 来源与边界

正文依据仓库已有英文笔记翻译，而非从教材抽取或复制整章。核对官方文件正文身份和相关条目：

- [OxfordAQA 9630 大纲](https://www.oxfordaqa.com/wp-content/uploads/2026/07/oxfordaqa-international-as-and-a-level-physics-specification.pdf)，正文 Version 4.4；AS 对应 3.1–3.5。本次不是全范围覆盖审计。
- [OxfordAQA 9203 大纲](https://www.oxfordaqa.com/wp-content/uploads/2026/07/oxfordaqa-international-gcse-physics-specification.pdf)，正文 Version 5.2；核对 3.1–3.8 结构、考试安排、评价目标及相关核物理、空间物理条目。考试局的简化描述与补充科学说明应区分。
- [NASA 黑矮星说明](https://science.nasa.gov/missions/hubble/astronomers-announce-first-clear-evidence-of-a-brown-dwarf/)用于限定理论冷却终态，不将黑矮星写成已观测到的阶段。
- [NASA 重元素观测说明](https://science.nasa.gov/missions/webb/nasas-webb-makes-first-detection-of-heavy-element-from-star-merger/)用于说明超新星不是所有重元素唯一的形成途径；未增加新的必考范围。

同步修正中英文旧笔记中的有符号面积与路程区别、减速的方向约定、γ 衰减、半衰期与本底计数、软组织对 X 射线的相对透过、折射率条件、近似均匀磁场、相同传输功率条件、恒星终态和重元素表述。AS 同步补清平方反比、分压与共振近似，并修正把长度或半径直接等同于百分比的不当符号。
