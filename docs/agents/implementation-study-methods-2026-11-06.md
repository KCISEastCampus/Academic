# 学习方法来稿整理与发布

## 设计卡

- 版本与范围：2026-11-06；跨学科学习建议，不声明新增考试范围或完整课程。页面 `/study-methods/` 与 `/zh/study-methods/`。
- 中心问题：看懂示范后，怎样定位缺口并走向独立应用？
- 先修：已学过一个主题，有课本、纸笔及未看答案的题；新知识先接受讲解。
- 核心：想、推、练；理解逐步形成；提取、反馈与延后检查。无需新图或模拟。
- 样章：一个选法困难的完整学习情境，加一个未给方法的诊断任务及运算错误重试。
- 来源：用户提供的余道宽《学习方法最终版》PDF，主要第 4–7 页；公开研究引用在页面来源区。用户明确要求发布，最终署名余道宽。
- 原文边界：不上传原 PDF；本次只发布已商定的学习方法编辑版。未纳入社会评论、人物引语和无来源数值断言。
- 实现：复用 subjects、reading_layout、原生 details 和首页 quick-nav；无新增样式、脚本、依赖或数据收集。
