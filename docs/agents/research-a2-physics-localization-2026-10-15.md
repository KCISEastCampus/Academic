## 翻译与教学规则

1. 保留英文例题与练习题干、数据、条件、编号和出处；不重新命题，不添加未经核实的官方分值。
2. 中文解释说明“为什么选这个模型、方向和方程”，继续保留先尝试、分层提示、折叠解答与自查的学习顺序。
3. 专业术语首次出现写“中文（English）”；后文以自然中文为主。定义中的方向、参考零点和适用条件必须完整保留。
4. 公式、数值、单位及有效数字与固定的英文来源逐项一致。公式内的 `\text{...}` 也先保留英文，在公式外解释，避免为汉化改动公式。
5. 中文讲解之后，学生仍需能用英文解释物理现象。先保留题干中的英文命令词；新增英文答题示范如有必要，应单独标注为教学示例并核对评分细则。
6. 每道题继续区分“自拟题 / 改编题 / 官方原题”。现有六篇学习页均有自拟及改编说明；汉化不能把简化题干重新称作官方原文。
7. 研究不等于学科审校：现有页面关于曾参考官方评分细则的声明，本轮未逐题重新验证。

## 术语草案与易失真点

以下是本站建议用语，尚不是 OxfordAQA 官方中文词表。

| English | 建议中文 | 必须保留的区别 |
| --- | --- | --- |
| speed / velocity | 速率 / 速度 | 标量与矢量；匀速率圆周运动的速度仍变化 |
| angular speed / angular frequency | 角速率 / 角频率 | 不机械地把所有 omega 都译为角速度 |
| resultant / centripetal force | 合力 / 向心力 | 向心力描述径向合力，不是额外增加的一种力 |
| normal reaction / tension | 支持力（法向接触力）/ 张力 | 山顶失去接触与竖直绳环松弛的条件不同 |
| displacement / amplitude | 位移 / 振幅 | 位移可有正负，振幅是非负大小 |
| restoring force | 回复力 | 指向平衡位置；不能误当成所有实际力中的单独一项 |
| gravitational field strength | 引力场强 | 矢量；与常量 G、势和势能区分 |
| gravitational potential / potential energy | 引力势 / 引力势能 | 单位分别为 J/kg、J；说明无穷远零点 |
| electric field strength | 电场强度 | 按正试探电荷受力定义方向 |
| electric potential / potential difference | 电势 / 电势差 | 标量；不能把负电势译成反向电场 |
| work by the field / external work | 场力做功 / 外力做功 | 与势能变化的正负关系及动能条件 |
| capacitance / capacitor | 电容 / 电容器 | 物理量与器件；隔离时固定 Q、接电源时固定 V |
| permittivity / relative permittivity | 介电常数 / 相对介电常数 | 真空与介质、绝对量与相对量不能混淆 |
| dielectric / polarisation | 电介质 / 极化 | 束缚电荷与极板自由电荷区分 |
| time constant / time to halve | 时间常数 / 减半时间 | RC 与 RC ln 2 不同，电容器能量也有不同衰减速率 |
| gradient / area under a graph | 斜率 / 图线下面积 | 先读横纵轴，再判断单位与物理意义 |
| magnetic flux density / magnetic flux | 磁感应强度 / 磁通量 | B 与 Phi 不能都简称磁场大小 |
| flux linkage / rms value | 磁通链 / 有效值 | N Phi 与 Phi、峰值与有效值区分 |

需优先复核：SHM 的负号与切向/径向加速度；场强大小与有符号分量；势能与外力/场力做功；电容器接电源/隔离条件；充放电电流的正方向；对数图轴标签及单位。

### 讲解风格样例（仅在本研究记录中）

对应英文圆周运动页的 Force Equations 段落：

> **向心力（centripetal force）**描述指向圆心的合力。它由张力、摩擦力、引力或支持力等实际力提供。受力图已经画出所有实际力后，不要再添加一个标为“向心力”的力。
>
> 先画出实际力并标明圆心，再把指向圆心的方向取为正方向，列出径向合力方程。最后检查物体是否仍与表面接触，或绳子是否仍绷紧。

原有公式保持不变：

```tex
\boxed{F=ma=\frac{mv^2}{r}=mr\omega^2}.
```

这能保留“先识别实际力，再列方程”的学习动作，避免中文页只剩公式列表。
