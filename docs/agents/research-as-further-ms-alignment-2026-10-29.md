## 3. 首要建议一：补齐复数轨迹的“条件到圆，再到最远点”

### 原题和原MS要求的行为

FM01 夏季2026 Q9：条件为

$$\lvert z+3-3i\rvert=2\lvert z\rvert.$$

这既不是已经给出圆心半径的圆，也不是到两点等距。QP 提取文本中的模号/系数顺序用原 MS p.17 的首行核清。MS 给出的动作是：

- (a) 写 $z=x+iy$，将模改为距离，平方并整理；两个M1分别对应距离表达和平方，A1对应 $x^2+y^2-2x+2y-6=0$。
- (b) 配方得到 $(x-1)^2+(y+1)^2=8$，再转回复数圆方程 $\lvert z-(1-i)\rvert=\sqrt8$；不能只凭图猜圆心。
- (c)(d) 用所得圆解释草图及实轴、虚轴上的解；原MS p.18明确要求圆心在第四象限且圆经过四个象限。
- (e) MS p.19先计算圆心到固定点 $-3+3i$ 的距离 $4\sqrt2$，再加半径 $2\sqrt2$，得最大距离 $6\sqrt2$。本轮另核：三角不等式给上界，且共线、同向的圆上点可以达到，因而不是只有数值猜测。

全题15分，但这不代表课程已有的模、草图和坐标知识全缺；新增目标是把这些知识连起来处理非模板条件。上述M/A是原卷评分动作；“写出可达点/上界理由”是本研究建议的教学检查点，不冒称本题额外官方得分项。

## 4. 首要建议二：把两球与墙面任务接成同一次事件

### 原题和原MS要求的行为

FM02 夏季2026 Q11，QP pp.24–25，MS原页 p.16：取初始A的运动方向为正，A为6 kg、$u_A=3$，B为4 kg、$u_B=-2$，恢复系数0.8。

$$6v_A+4v_B=10,\qquad v_B-v_A=4,$$

得到 $v_A=-0.6$、$v_B=3.4$ m/s，(a)要求A的**速率**0.6。随后B撞墙，墙冲量为 $-84(0.2)=-16.8$ N s，因此

$$4(w_B-3.4)=-16.8\quad\Rightarrow\quad w_B=-0.8\text{ m/s}.$$

(b)的5分分别涉及B原速度B1、冲量B1、动量改变M1、墙后速度A1、再次碰撞解释E1。原MS最终结论并不止于“都反向了”：B在A右边、两球都向左，B速率0.8大于A的0.6，所以距离继续缩小，会再次碰撞。独立核对相对位置：墙后若间距为 $d>0$，则间距变化率为 $w_B-v_A=-0.2$ m/s，故可以在正时间相遇。

一月2026 Q12的MS p.17另要求把“反向”译为 $v_A<0$，与 $0\le e\le1$ 联立，而非只报一个速度。它支持保留现有有符号速度和物理范围训练；不能据此把一月卷也说成考查墙后再次相撞。

**最小改法：**保留现有“两个独立过程”的回顾（它有方向转换价值），另加一段同一事件的状态图/示范：第一次球碰撞 → B到墙 → 墙冲量 → 原两球的位置次序、速度及间距变化。每段只对当段系统使用合适定律，避免跨墙事件错误守恒两球总动量。独立题不先指定“比较速率”，反馈按方向错、系统错、追及判断错分别回补。

**闭卷检验（自拟，非官方题/分值）：**光滑水平线上A(2 kg)在B(1 kg)左边，初速度分别为+3、−1 m/s，球间 $e=1/2$。B随后撞右侧固定墙，撞墙前无外力，墙给B向左4 N s冲量，其他接触冲量忽略；A未碰其他障碍，墙后两球有正间距。判断两球会否再次碰撞，并说明位置次序和速度为何足够。核对：第一次后 $v_A=1,v_B=3$；墙后 $w_B=-1$，两球相向，会相撞。只得到三个速度不算完成解释。

**匹配重试（自拟）：**只把墙给B的向左冲量改为3 N s，其余条件不变；墙后B速度为0，对应常规模型的 $e_{wall}=0$，A仍向右1 m/s，所以也会碰撞。再问“墙后B向左而A也向左时，是否只凭同向就能判断”：必须说明谁在前、谁在后以及带符号相对速度，不能照抄同向即不相撞的口令。该重试补判断条件；不把真实接触历史或永久粘墙作为额外假设。
