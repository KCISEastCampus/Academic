## 1. 判断及证据边界

优先改变 PI 的教学顺序和学生行动，不能只再换一轮简单措辞或增加更多完整例题。现页已经讲了待定系数、CF 与 PI、求导代入以及共振失败；缺的是让学生分别练会这些判断，再把它们合起来。

这是从现页和反馈提出的设计判断，尚不是经学生作答证实的困难成因。我们还不知道各位同学分别卡在函数类型、CF 重复、乘积求导、比较系数还是条件应用；“找 PI”可能包含其中几种不同困难。

## 3. 局部样章设计卡

**中心问题：**找一个函数，把它和它的导数代回左边，怎样得到题目右边？

**先修：**指数和正余弦的一、二阶导数，乘积法则，二次方程与 CF，恒等式比较系数。先用短任务判断困难；若乘积法则不会，回到本章既有求导示范，不强迫学生同时学习新求导法和新 PI 规则。

**核心模型与条件：**固定的常系数线性方程；PI 是一个使等式在区间内恒成立的函数。无需给 PI 再加任意常数。代入一个数值只能作检查，不能代替恒等验证。

**图表用途：**优先使用邻接的“候选 → 导数 → 代回结果”短表或逐行式，显示相消和剩下的项。曲线图可以帮助说明解族，却不能单凭形状判断某个 PI 形式必定可行；此处不先增加动画或模拟器。

**支持逐步撤去：**给定 CF 与候选，先做代入；给定 CF，自己选候选；只给方程，独立选法并求 PI；最后组成通解与使用条件。无需把每题统一加长成六个固定栏目。

| 可观察目标 | 先讲什么／示范 | 学生自己做什么 | 判据与错误后的去向 |
| --- | --- | --- | --- |
| 解释 PI 要满足什么 | 先用一个成功的指数例，写出左边实际结果 | 判断一个候选为何成功或失败，不能只报系数 | 等式对所有相关 $x$ 成立；失败则回看代入结果 |
| 选能产生所需项的函数族 | 指数保形、三角互换、多项式降次 | 给 CF，只写 PI 形式并解释；暂不解系数 | 指数率／频率正确，三角含一对，多项式含低次项 |
| 判断 CF 重复并调整 | 同一个左边、不同指数的对比；再讲重根和零根 | 给候选检验失败，并提出可检验的新形式 | 看实际抵消与根的重数，不凭“右边有指数就乘 $x$” |
| 求出系数并验证 | 给定形式完成一段求导、代入、分组 | 自己完成另一种函数族；记录首次是否用提示 | 导数、符号、每类系数均正确；算术错误与选法错误分开回补 |
| 把技能放回完整题 | 先 PI，后 CF＋PI，最后条件 | 无方法标签的新混合题，稍后再做同目标任务 | 不漏 PI 形式／求导／代入／比较系数；条件应用于总解 |

## 4. 给学生的讲解应该怎样展开

以下是作者设计示例，供改版使用；不是已上线的新课。沿用现页两个自拟指数示范的数据，便于只改变教学组织。先给 $y_c=Ae^x+Be^{-x}$，让学生专心观察 PI。

### 先看一次能成功的代入

对 $y''-y=6e^{2x}$，先说：“右边有 $e^{2x}$。它求导后仍有 $e^{2x}$，所以先试同一类函数，前面的数暂时不知道，写成 $C$。”

$$y_p=Ce^{2x},\qquad y_p'=2Ce^{2x},\qquad y_p''=4Ce^{2x}.$$

$$y_p''-y_p=(4C-C)e^{2x}=3Ce^{2x}.$$

“题目要 $6e^{2x}$，我们代回得到 $3Ce^{2x}$。因此 $3C=6$，$C=2$。找到了一个 PI：$2e^{2x}$。”马上给一个短尝试，再进入下一种困难。

### 用同一个左边解释为什么有时必须换形式

把右边换成 $4e^x$，仍研究 $y''-y$。先算失败，再展示修正，避免先背“共振”一词。

| 候选函数 | 代入 $y_p''-y_p$ 后 | 现在知道什么 |
| --- | --- | --- |
| $Ce^{2x}$ | $3Ce^{2x}$ | 可调系数，但指数形式不符合新右边 |
| $Ce^x$ | $Ce^x-Ce^x=0$ | 无论 $C$ 是多少都无法得到 $4e^x$ |
| $Cxe^x$ | $C(x+2)e^x-Cxe^x=2Ce^x$ | 可以匹配；$C=2$ |

首次引入 $Cxe^x$ 时，把乘积求导写在旁边：$y_p'=C(1+x)e^x$，$y_p''=C(2+x)e^x$。强调“换了可检验的形式”，不是凭数字调整已注定抵消的候选。

**重要的表述边界：**不能把所有情况简化成“整个试探式已经出现在 CF 中才乘 $x$”。指数可直接这样比较；多项式可能只有常数部分重复，也必须调整整个多项式块。例如 $y''+y'=2x$ 的 CF 为 $A+Be^{-x}$。通常的 $Cx+D$ 代回只能得到常数 $C$，不是 $2x$。应试 $x(Cx+D)$，其左边为 $2Cx+(2C+D)$，得 $C=1,D=-2$。这说明低次项和零根不能省略。

### 由短尝试逐渐走到考试任务

1. **先算一次 PI：**给定 CF 与形式，求导、代回、求系数，不同时要求初始条件。复用上面的完整指数示范，紧接短任务。
2. **分别建立三种函数族：**指数 → 完整多项式 → 正余弦配对；每类讲完就让学生只选形式或补一段代入。开始时给定 CF，避免复根计算遮住 PI 目标。
3. **再处理重复：**先对比普通指数和单根重复，再到重根、零根与三角重复；每次展示失败在哪里。多项式按零根重数将整个多项式块乘 $x^s$，不是只给某个已有项添 $x$。
4. **汇总规则：**这时再放试探形式表、根重数和注意事项，作为整理与复习工具。保留四次多项式非齐次项可因零根得到更高次 PI 的范围说明。
5. **撤去 CF 和方法提示：**两道相同右边、不同左边的方程，让学生判断为何试探形式不同；然后做混合右边，最后加初始／无穷远条件。现有 Q1–7 和 E7 进入相应阶段，原混合顺序作为学后复习。

候选短任务均须标自拟、无官方分值；未来课程页的提示和解答分别关闭。这里列出教师预期以便审核，不直接照搬成学生默认可见内容：

| 自拟任务的改变 | 学生输出 | 教师核对 |
| --- | --- | --- |
| 已给 CF，$y''-y=5e^{3x}$ | 选形式，再求 PI | $Ce^{3x}$，左边 $8Ce^{3x}$；PI 为 $5e^{3x}/8$。此题仅用于熟练，不独自承担迁移证据 |
| 比较 $y''-y=4e^x$ 和 $y''+y=4e^x$，只要求选形式并说明理由 | 由左边而非只看右边作决定 | 前者用 $Cxe^x$，后者用 $Ce^x$；两个 PI 分别为 $2xe^x$、$2e^x$ |
| $y''-2y'+y=7e^x$，给定 CF 为 $(A+Bx)e^x$ | 检验 $Ce^x$、$Cxe^x$ 后提出新形式 | 前两者代入均为零；$Cx^2e^x$ 代回为 $2Ce^x$，PI 为 $7x^2e^x/2$ |
| 给出学生对 $y''+y'=2x$ 使用 $Cx+D$ 的解法 | 指出失败环节并修正 | 代入只有常数，不是系数算错；修正为 $Cx^2+Dx$，PI 为 $x^2-2x$ |

三角配对的原有示范可继续使用：$y''+y'+2y=3\cos x$，设 $C\cos x+D\sin x$ 后，左边为 $(C+D)\cos x+(D-C)\sin x$，得 $C=D=3/2$。先给 CF，使学生能专门解释为什么右边没有的正弦项仍要保留。到独立阶段换条件／求问方向，而非一直照抄这个示范。

## 5. 纠错和真实试用

反馈先区分六种错误：函数族；少低次项／少三角搭档；与 CF 重复；求导；比较系数；过早或错误使用条件。只对出错处提供一个具体回补点和新任务，再关闭帮助重试。若 PI 已能独立完成，但总解条件出错，不让学生从头重学 PI。

**建议首个实际改版范围：**只重组双语 `#pi-trials` 内的入门和指数重复段，移接必要练习，保留所有旧锚点；为多项式和三角补清下一阶段的承接。沿用 `worked-example`、`lesson-check`，不改共享 CSS。先验收一条“看到例子 → 自己选 → 失败解释 → 新重试”的连续路线，再推广本章其余类型。

试用记录采取匿名实际作答，不只问“看懂了吗”：先让学生写拟设形式和理由，再求 PI，最后做未标方法的新题。记录给过的 CF、提示、首次错误位置和新重试；随后一次学习中再查同目标题。不要用固定题数、统一耗时或满意度代替掌握判断。

- 若给 CF 后会选，但自己求 CF 后不会判断重复，修复两者的连接。
- 若形式选对却求导失败，补乘积法则；不能仅再加一张 PI 规则表。
- 若只会紧邻示范的同型题，延后或混合任务仍需保留支持，不能宣布迁移成功。

本轮没有目标学生逐步作答，所提机制与顺序尚待检验；不宣称已证明有效。后续如改课程，按长期标准写最终目标映射、独立内容审查，并完成受影响的双语、构建与实际页面检查。
