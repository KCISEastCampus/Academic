| FS2.1a–b | 从概率表求两个矩，指数求导和链式法则 | 离散均匀 `#demonstration`；PGF `#moments` | 指数权重、零点、普通矩、存在域；从定义到性质，而非更换公式名称。 |
| FS2.1c | 离散无穷和、反常积分、指数运算；normal还需配平方和密度归一化 | 几何 `#moment-foundation`；普通 A2 统计为待主代理核对入口 | 分别建立 Poisson、exponential、normal 推导；积分换元、端点及存在域不能跳步；不要要求从未教过正态积分技术的学生凭空重建。 |

| FS2.3a–d | 抽样均值模型、标准误、正态标准化；未知方差小样本需新教t | 普通 A2 估计/均值检验入口待复核 | 按条件选择区间、解释重复抽样含义、推断及反求整数样本量；区分半宽与全宽。 |
| FS2.4a | 把拒绝域/接受域写成事件；在不同参数下计算事件概率 | 普通 A2 检验入口待复核 | 区分显著性、第二类错误和功效；改变真实参数而保持既定拒绝域。 |
| FS2.4b–c | 样本均值差及方差；理解配对结构与差值变量 | 线性组合；FS2.2–3 | 从研究设计选择独立/配对；分别处理z、合并t、配对t及假设，不把两个样本机械套入同一公式。 |
| FS2.4d–e | 样本方差、正态性、尾部与自由度 | FS2.2抽样及FS2.4均值检验后的新段 | 新建χ²、F统计量与方差/标准差假设的连接；检验比例方向与临界尾一致。 |
| FS2.4f–g | 从假设模型计算期望频数，连续类距用概率积分 | Bayes的概率分割仅作背景；连续分布先修另核对 | 区分独立性与拟合优度任务；处理分组、期望频数条件、Yates和自由度；不能用原始频数代替期望条件。 |

建议路线：**MGF 概念与离散示范 → 连续 MGF 与独立和 → 抽样与估计量 → 区间估计 → 功效 → 两均值比较 → 方差及方差比 → 列联表与拟合优度 → 未标方法的跨章综合/延后回顾**。MGF 不是每个推断主题的必要前置门槛；已有抽样基础者可以从估计量分支进入。跨章综合应迫使学生选择模型与方法，不以“第几章”泄露答案。

## 5. 首个样章建议与设计卡

**建议：从 PGF 到 MGF——为什么在零点求导能得到普通矩？** 主范围 FS2.1a–b，接入 FS2.1d 的独立性判断；Poisson 推导可作为首个分布应用，待主代理确认其先修与配套评分材料后纳入。不要将这一个学习段宣称为 FS2.1 全覆盖。

选择理由：当前最成熟的相关源码是 PGF 和线性组合，学生有可定位的回补。有限概率表能先隔离生成函数的概念转折，再引入无穷和及连续积分；比直接堆三个连续/离散分布公式更容易发现取值点、二阶矩和独立性错误。它也能检验 v1.1 所要求的“连续读完推理→独立尝试→按错因恢复”，而不是只验证题框与栏目。

| 设计项目 | 建议 |
| --- | --- |
| 中心问题 | 同一分布换一种权重编码后，怎样从导数恢复均值与方差，什么时候能合并变量？ |
| 必要先修 | 从有限概率表计算矩；指数与链式求导；独立事件/变量概念。PGF用于建立联系，未掌握时允许从概率表进入。 |
| 核心模型与条件 | 先定义随机变量及支撑集，再引入指数权重；有限例子无收敛负担，推广到无限/连续时明确零附近存在域与求导条件，不讲成“所有分布都存在MGF”。 |
| 图与数据用途 | 同一有限分布的“值—概率—指数加权项”对应表；用于看清期望如何组成函数。若画函数曲线，仅用于辨认零点附近行为，不冒充定义或证明。数据标自拟。 |
| 完整示范 | 同一有限分布先直接求矩，再从定义建立MGF、求导并核对；与PGF的取值点及二阶导意义相连。一个示范连续读到检查，不被无关练习打断。 |
| 支架撤除 | 初次先补一个指数项；随后独立从新支撑集（可含负值）重建函数，求矩并检查；再改变为仿射变换或独立副本，要求说明条件。 |
| 新知识安排 | 仿射性质从指数展开解释；独立和的乘积从联合期望解释。先讲再考，不要求学生首次尝试就发现未经讲解的性质。 |
| 后续连接 | 下一段进入连续指数分布MGF及其存在域，再到normal配平方；回到独立和及估计量。样章发布时应有诚实的“后续待补/当前可回补”路径。 |
| 来源 | 本记录所核对spec；数学题与解答落笔前由主代理补读实际选用FM04 QP及对应MS。现阶段不认领官方题号、分值或评分点。 |
