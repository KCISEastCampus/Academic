## 范围、概念依赖与建议拆页

范围依据 [S44 pp.28–30][spec44]，并与 [S51 pp.29–31][spec51] 对读。拆分围绕模型转折，不把每个大纲编号机械变成一页。

| 建议学习页 | 必须覆盖的范围；学生应产生的证据 |
| --- | --- |
| 核尺寸的证据（3.12.1） | α 最近接近、电子衍射及强度–角度图；典型尺度；由数据建立半径随核子数变化的关系，解释并计算核密度。比较两种方法支持的结论，再处理半径比和数据图。 |
| 质量、结合能与反应能量（3.12.2） | 质能联系、u、质量亏损、总及平均结合能；核质量计算裂变/聚变释能；读平均结合能曲线。设“一个核”与“一个反应”的能量账两个停靠点。 |
| 可控裂变与安全（3.12.3–.4） | 热中子、链反应、临界质量；弹性碰撞慢化模型；慢化剂/控制棒/冷却剂的作用、材料选择及例子；燃料、屏蔽、遥控、停堆、废物和风险收益。先中子机制，再热与放射性管理；不要求具体堆型细节。 |
| 聚变的条件与限制（3.12.5） | 合适核种、所需动能及等离子体温度估算、反应释能、太阳氢循环、实现反应堆的困难。解释高温和约束条件，不只背优缺点。 |

依赖：核素记号/电荷/能量守恒 → 库仑势能与散射 → 核半径；质量亏损 → 结合能曲线 → 裂变和聚变释能；再分别接“弹性碰撞与中子链反应”和“库仑势垒与热运动”。半径球体模型可辅助聚变估算，但测量技术不是理解质量亏损的必要先修；放射性衰变与核反应须区分。

### 设计卡 A：核尺寸的证据

- **中心问题 / 可观察目标：** 如何从散射推断核尺寸？能画出最近接近模型，区分上限估计和衍射测量，由半径数据判断尺度规律及密度。
- **先修：** A/Z、α 电荷、能量守恒、库仑势能、球体体积、de Broglie 波长、基本衍射。入口先用旧知识预测提高 α 初动能的后果，随后直接教授新模型。
- **模型、图与数据：** 自绘并标为示意的正碰轨迹和动能–势能账；给定电子波长的强度–散射角图；半径–核子数数据用于选坐标和拟合。数据须有实验来源，或标“教学构造”；本轮没有获取实测数据表或可见的官方电子衍射原图。
- **示范与支架：** 示范正碰计算及结论限制 → 补解释、读极小位置 → 独立选择模型、比较不同核半径并推导近似恒密度。提示先指出保持量/坐标，完整解答另折叠；待作答图与替代文字不预填答案。
- **独立考查 / 来源：** [S44 §3.12.1][spec44]；[样卷 Q16][qp] 配 [MS p.12][ms] 可检验半径比，但不能单独证明掌握测量模型。再尝试改变能量、表征或求问方向；反馈定位“转折点仍有横向动能”“把 A 当长度”等原因。

### 设计卡 B：质量、结合能与释能

- **中心问题 / 可观察目标：** 更紧密结合为何释放能量？能辨认质量种类，完成质量差 → 总结合能 → 每核子结合能，依据反应前后总量解释释能及符号。
- **先修：** 核素记号、电荷/核子数守恒、J/eV/MeV、科学记数法、能量守恒。入口先统计质子中子和单位，不要求凭空发现质量亏损。
- **模型、图与数据：** 核与分离核子的质量账、B/A–A 图、反应初末能量账。直接讲解结合能定义，再比较图像；纵坐标不是一个核的总结合能。
- **示范与支架：** [样卷 Q5.1–5.2][qp] 配 [MS p.8][ms] 是可选的核质量路线示范；首批样章实际采用的正式卷来源和质量约定以主任务实施记录为准。独立题可由每核子结合能反求核质量、诊断混用原子质量、由各产物总结合能求释能，均标“自拟题”。独立读图须有可读原图，不能以给定读数冒充读图。
- **独立考查 / 来源：** [S44 §3.12.2][spec44]；Q5.3/Q15 待原图核验。反馈分别诊断质量对象、漏乘/多除 A、释能符号；重试允许重新选账。中英版保留相同英文题干、数据和任务，中文解释理由，最后要求独立英文机制解释。

## 作者核验：条件与易错点

以下由能量/动量关系及量纲检查得到；不作为额外的 OxfordAQA 必背要求。

1. **最近接近是有条件的上限估计。** 重靶核近似静止、正碰、远处势能取零、只计库仑斥力时：

   $$K_\alpha=\frac{1}{4\pi\varepsilon_0}\frac{(2e)(Ze)}{r_{\min}}.$$

   正碰转折处 α 瞬时静止，才可把初动能全部计入电势能；非正碰有角动量，最近处总动能不为零。实验仍符合库仑散射时，尚未探到核表面，该距离只限制核尺寸；更精细解释还涉及 α 尺寸、靶反冲和强相互作用，不能把最近距离称精确核半径。

2. **电子衍射先检查动量。** 用 $\lambda=h/p$；只有 $K\ll m_ec^2$ 时才可用非相对论动量。核尺度电子通常不满足此条件。作者校验可用：

   $$pc=\sqrt{K(K+2m_ec^2)}.$$

   [NIST CODATA][constants] 给出 $m_ec^2\approx0.511\,\mathrm{MeV}$。课程可直接给波长/动量及题用模型，不新增相对论推导。极小角所用尺寸系数、半径/直径与散射角定义均按模型核验，不能把光学圆孔系数无条件移植；“第一极小”不自动意味着强度为零，应保留原图实际特征。

3. **核尺寸与密度是近似模型。** $R=R_0A^{1/3}$ 是实验关系；球体体积随 A、质量约为 Au，故核密度近似恒定。若自拟核算取 $R_0=1.2\,\mathrm{fm}$，约得 $2.3\times10^{17}\,\mathrm{kg\,m^{-3}}$，已独立核算；此 R₀ 是教学取值，不称实测或官方指定常量。典型核尺度为 fm 量级，不与原子半径混用。

4. **核质量与原子质量不能拼接。** 核质量路线的质量亏损是“Z 个自由质子与 A−Z 个自由中子总质量”减“核质量”。中性原子质量路线相应使用氢原子质量或明确扣电子，并说明忽略电子结合能的精度；反应两侧电子数平衡才可能抵消。β 过程、离子及正电子另做粒子/电子质量账。本报告公开样卷 Q5 的题给数值支持核质量路线；其他来源须同时核对表头与实际数据，不能只信 nucleus 等标签。若采用原子质量，样章须明写 neutral atoms，不能将氢原子质量教成质子质量；核素符号若不自洽，须核对并明确改编，不直接沿抄。

5. **总量、平均量、符号分别定义。** $B>0$ 是拆核所需能量，$B/A$ 是每核子平均量；由图求一个核总量须乘 A，反应须对全部初末核求和，自由中子的核结合能为零。若 $\Delta m=m_{\rm final}-m_{\rm initial}$，释能 $Q=-\Delta m c^2$；用正质量亏损时才写 $Q=\delta m c^2$。更紧密结合使静质量降低，包含逸出能量的封闭总系统仍守恒。单位写 **1 u c² ≈ 931.5 MeV**，不能把 u 和 MeV 直接视作同量纲。

## 剩余路线与交付边界

- **裂变/安全：** 反应式守恒、每次释能 → 反应率/功率 → 碰撞慢化、吸收/泄漏与临界性 → 热及放射性废物管理。临界质量不是与材料/几何无关的固定阈值；慢化剂减速、控制棒吸收、冷却剂传热不可互换；停堆不等于衰变热和废物危害立即消失。
- **聚变：** 连接核半径、库仑势能、质量账、热运动，选择 D/T 等轻核；估算能量与温度后说明经典越垒模型不是实际恒星/聚变反应的绝对阈值。太阳限氢循环，不扩成完整恒星演化课程。
- **3.13 是另一条力学/电学依赖线：** 建议先独立一页“转动与角动量”（3.13.1）：力矩/圆周运动 → 转动惯量与恒角加速度 → 角动量守恒、转动动能、功/功率；再安排风能（3.13.2）、太阳能/光伏（3.13.3）、水电/抽蓄（3.13.4）情境模块，篇幅允许可合页设停靠点，不把裂变技术当先修。
- **能源任务：** 风能由流率建立 $P_{\rm available}=\tfrac12\rho Av^3$，解释不能全取、尾流布置及环境条件；太阳能联系地面强度、逆平方、I–V 曲线最大 VI、阵列及 RP10（点光源/LDR，检查非线性响应、背景与距离）；水电区分流体动能通量与有水头时的 $P=\eta\dot m g h$，解释抽蓄储能/调峰、基荷/备用和往返损失。不能把风流截面公式无条件套成大坝水头功率，或混淆总辐射功率、面积强度和电输出。
- **综合判断：** 给具体需求、资源与数据，让学生依据能量账、可调度性、环境/安全条件选能源，调用已学热学和电学。RP10 是实验要求，网页/模拟/构造数据不代表实际完成。[S44 §3.11 引言、§3.13][spec44]
