## 第一张学习页建议

入口先给一组短判断：压缩气体、加热金属、熔化冰分别如何改变内能和温度。学生作答后，再阅读解释；结尾用相近情境重做，检查是否真正分清。

1. **确定系统和能量边界。** 在示意图上标出系统、加热和做功的方向。
2. **区分温度与内能。** 内能包含粒子无规则运动的动能和相互作用势能；不能仅凭温度比较不同质量或物质的总内能。
3. **第一定律与符号。** 先写带方向的能量清单，再代入公式，最后解释正负号。
4. **升温与物态变化。** 比较温度变化和内能变化；读加热曲线，选择合适关系式。纯物质在固定压强下平衡相变的平台段，温度不变仍可吸收能量。
5. **电加热测比热容（Required practical 8）。** 解释测量、能量损失和误差方向；图像处理可作为进一步练习。
6. **连续流动。** 大纲明确包含这一类计算，至少安排一道由质量流率求加热功率的题。
7. **综合练习。** 题目与答案分开折叠；每题有单独提示，答案包含方程选择、单位、符号或实验解释。

前置知识可回顾现有 AS 物理中的功与能、功率、电功率、SI 单位和不确定度。气体分子运动的定量推导留给后续学习页。

## 需要先统一的公式与术语

| 表达式或术语 | 制作时的约定与限制 |
| --- | --- |
| \(\Delta U=Q+W\) | OxfordAQA 的 \(W\) 是外界对系统做的功；吸热和外界做功取正，系统放热和对外做功取负 |
| \(Q=mc\Delta\theta\)、\(Q=ml\) | 分别用于温度变化和物态变化；混合过程分段计算，不把同一能量重复计入 |
| \(E\approx VI t\) | 电压、电流近似恒定时成立；赋给样品的能量还需考虑装置吸热与环境交换 |
| \(P\approx\dot m c\Delta\theta\) | 连续流动的简化能量平衡，需说明稳态、热损失可忽略及其他能量变化可忽略 |
| \(P=kA\Delta\theta/L=UA\Delta\theta\) | 采用传热速率的大小；\(U=k/L\) 对应简单均匀平板，不能直接套用于任意复合墙体 |
| \(pV=nRT=Nk_{\mathrm B}T\) | \(T\) 必须为 K；\(n\) 是 mol，\(N\) 是粒子数；体积换为 \(\mathrm{m^3}\) |
| \(W_{\mathrm{on}}=-p_{\mathrm{ext}}\Delta V\) | 恒定外压的体积功；与 \(\Delta U=Q+W\) 联用时，膨胀对应负功，压缩对应正功 |
| \(pV=\tfrac13Nm_0c_{\mathrm{rms}}^2\) | \(m_0\) 为单个分子质量；不能误代总质量后再乘 \(N\) |
| \(\tfrac12m_0c_{\mathrm{rms}}^2=\tfrac32k_{\mathrm B}T\) | 指分子平均平动动能；\(c_{\mathrm{rms}}=\sqrt{\langle c^2\rangle}\)，不是平均速率 |
| internal energy / heat / temperature | 内能 / 热量（因温差传递的能量）/ 温度；避免“物体储存热量”的说法 |
| specific heat capacity / specific latent heat | 比热容 / 比潜热；单位分别为 \(\mathrm{J\,kg^{-1}\,K^{-1}}\)、\(\mathrm{J\,kg^{-1}}\) |
| thermal conductivity / U-value | 热导率 / 传热系数；单位分别为 \(\mathrm{W\,m^{-1}\,K^{-1}}\)、\(\mathrm{W\,m^{-2}\,K^{-1}}\) |

符号提醒：内能 \(U\) 与 U 值不是同一物理量；热导率 \(k\) 与玻尔兹曼常量也不同，讲解中可将后者写成 \(k_{\mathrm B}\)。温差的 K 与 °C 数值相同，气体方程中的绝对温度不能直接用 °C。

若给出 \(U=\tfrac32nRT\)，必须标明适用于只计平动能的单原子理想气体模型，不能推广为所有气体的通式。

## 实验解释最容易写错的地方

- **金属块测比热容：** 若实际有能量流向环境或加热器本身，仍把全部 \(VI t\) 计给金属块，会使计算的比热容偏大。必须说明比较时采用的系统和假设。
- **熔冰测比潜热：** 环境传热也会融冰。若把全部融冰质量归因于加热器，则计算的比潜热偏小。这与上一项的误差方向不同。
- **系统边界：** 系统只含金属块时，可把加热器传给块的能量记作加热；系统包含电阻丝和金属块时，可按电功输入处理。同一次输入不能同时加到 \(Q\) 和 \(W\)。
- **改进实验：** 写“改变什么 → 影响什么误差或能量交换 → 为什么更好”；仅列“保温、重复、换仪器”不足以形成可靠解释。
- **实验安排：** 比热容属于 RP8，气体定律属于 RP9。真实操作说明应包含热部件及加热器使用要求；数值练习不能替代实验技能。

官方实践依据：[Physics practical handbook，印刷页 75–77](https://www.oxfordaqa.com/oaqaresources/science/teaching/a-level-practical-handbook-physics.pdf)。这份手册为 2018 年版；课程范围以现行大纲为准。
