# 物理学习章节如何安排与制作：独立研究与课程方案

日期：2026-10-15。范围：Academic 的物理学习材料，以 OxfordAQA 9630、PH03 和 PH04 热学为当前落点。

状态：研究建议与样章设计，尚未试教。本轮只新增本报告，没有修改课程、导航或样式。本文不延续此前实施记录中“技术检查通过即制作完成”的判断。

## 1. 需要纠正的起点

我此前先处理了汉化、栏目一致性和例题数量，却没有先确定学生怎样从现象建立模型、怎样独立检验理解。这是制作顺序上的问题。增加“学习／作业／复习”、可折叠答案和检查脚本，不能补足这一步。

**物理课程应围绕学生逐步获得的解释、建模和检验能力组织。** 大纲负责规定范围；学习顺序需要另行设计；页面格式负责支持这一顺序。

建议采用三个判断：

1. 一个学习段结束后，学生能独立作出哪项此前不会的物理判断？
2. 学生要连接哪些现象、示意图、语言、数据、图像和方程？
3. 怎样用一道未示范过的任务区分“看懂答案”和“能够迁移”？

这些问题回答清楚后，才决定分几页、放几道题、需要什么图。下文的章节安排是本项目的教学设计建议，不是考试局规定的课次，也不预设每个学习段必须单独建立网址。

## 2. 研究依据，以及证据能支持到哪里

本次查阅官方大纲、官方实验手册、原始物理教育研究和教学体系开发者材料。研究论文部分主要依据公开摘要；未进行系统综述、效应量合并或本校学生实验。

### 2.1 官方边界

[OxfordAQA 9630 大纲，Version 5.1](https://www.oxfordaqa.com/wp-content/uploads/2022/08/oxfordaqa-a-level-physics-specification.pdf)是课程范围依据：PH03 对应 3.6–3.10，热学对应 3.11。其四项评价目标涵盖知识、应用、信息分析和程序评价（4.3），不能只以计算题检验章节。热学中第一定律采用“对系统做功为正”；气体定律的经验关系与分子理论的解释需要区分（印刷页 28–29）。

[官方实验手册](https://www.oxfordaqa.com/oaqaresources/science/teaching/a-level-practical-handbook-physics.pdf)说明，教师与技术员用的完整实验步骤应改编为让学生作程序决策的材料；RP8 示例也有此说明（印刷页 75）。因此，学习页需要学生解释测量和处理数据，而不只是阅读操作清单。手册为 2018 年材料，具体实验编号和范围仍须与当前大纲逐项核对。

### 2.2 研究发现与项目推论分开

| 原始来源与已核查内容 | 支持本项目做什么 | 不能据此声称什么 |
| --- | --- | --- |
| [Kohl、Rosengrant 与 Finkelstein，2007](https://journals.aps.org/prper/abstract/10.1103/PhysRevSTPER.3.010108)：两个大学入门班的电学问题中，完整、正确地使用多种表征与解题表现相关；不同指导方式都有可用性 | 让学生连接受力图、方程和解释，检查它们是否一致 | 插图越多越好；相关性已经证明某一种网页格式有效 |
| [Gjerde 等，2022](https://journals.aps.org/prper/abstract/10.1103/PhysRevPhysEducRes.18.010136)：研究例题自我解释，关注原理、建立方程的方式及适用条件，并检验先提取原理的作用 | 例题要追问“为什么能用这个原理、条件在哪里”，学习后再撤去提示 | 学生复述计算步骤就等于理解；研究中的效果可直接当作本站效果 |
| [Badeau 等，2017](https://journals.aps.org/prper/abstract/10.1103/PhysRevPhysEducRes.13.020112)：三个大学入门物理实验支持自我解释及部分综合例题比较；不同类型比较并非都有改善 | 有目的地比较条件变化和多概念连接，而不只换数值 | 任意成对例题都能改善迁移；所有章节都必须用同一例题模板 |
| [Meltzer，2004](https://physicseducation.net/docs/abstracts/html/p010.htm)：大学热学研究发现学生持续混淆热、功与内能，包括把状态量的性质错误推广到传能过程 | 用概念诊断和能量边界任务检查理解，不能只核对数值 | 本校学生有同样比例的误解；应把论文中的所有大学热力学内容加入 A-level |
| [Etkina 等，2006](https://journals.aps.org/prper/abstract/10.1103/PhysRevSTPER.2.020103)：提出科学过程能力的形成性任务与评价量规 | 评价学生留下的预测、表征、分析和修订，而不只看阅读完成 | 本报告自拟的量规已被该研究验证 |
| [ISLE 开发者说明](https://www.islephysics.net/)：通过观察、解释、预测、检验、反思和修订发展物理认识 | 将“模型如何建立和接受检验”作为章节主线，允许重试 | 几个网页检查点就构成完整 ISLE；本站已复现其课堂环境 |

**证据的适用限制：**这些研究多来自大学入门课程或完整教学环境。把其中原则用于双语 A-level 自学页，是需要试用验证的设计推论。以下具体课序、提示层级和样章任务均为本项目建议。

## 3. 课程、单元、学习段和资料页各做什么

| 层级 | 学生在这里解决的问题 | 应呈现的内容 |
| --- | --- | --- |
| 课程入口 | 我已有何基础，现在学到哪里？ | 先修关系、推荐路线、主题完成状态、实验线索；区分正式学习页与速查笔记 |
| 单元入口 | 这一组物理问题有什么联系？ | 中心问题、概念关系、学习段路线、单元任务、大纲对照 |
| 学习段 | 我怎样解释或解决这一类问题？ | 少量可观察目标、模型建立、必要表征、示范、逐步独立的任务与反馈 |
| 实验活动 | 证据怎样产生，怎样判断模型？ | 装置、测量决策、数据、处理、局限、改进；连接相应概念 |
| 单元综合 | 在未标明题型时，我能否自主选择和连接模型？ | 混合问题、不同表征、实验信息、解释与评价；解答单独展开 |
| 速查 | 我已学过，现在需要提取什么？ | 定义、关系式、条件、图像特征、常见误用，链接回学习段 |

**拆分依据是学习转折，而非大纲小节数量或 Markdown 长度。** 出现以下情况，应考虑新的学习段：引入新的模型；先修能力突然变化；新的装置和数据处理需要独立练习；学生无法用一个清楚的中心问题概括正在学什么。

反过来，同一模型的定义、图像和应用不宜因“格式整齐”被拆成互不相连的页面。先画学习段关系，再用试读决定是否合页。不能预先规定所有课都要八道例题、三张图或固定时长。

## 4. 一段物理学习如何展开

建议的基本过程如下，允许根据内容调整顺序：

```mermaid
flowchart LR
    A[现象与先前判断] --> B[系统、变量与模型]
    B --> C[连接示意图、语言和方程]
    C --> D[解释示范并完成部分步骤]
    D --> E[独立预测或解决新问题]
    E --> F[用数据、条件与极限检查]
    F --> G[修订解释并重新尝试]
    G --> B
```

### 4.1 开始于一个需要解释的问题

圆周运动可以从“速率不变为何仍有加速度”开始；气体可以从“压缩后立即读数与等待后读数为何不同”开始。问题要揭示本段的关键判断，初学者能凭先前知识尝试。

开头不宜要求学生调用整章尚未建立的公式分类表。完整模型选择表适合放在单元总结，或作为复习入口。

### 4.2 明确系统、相互作用和条件

先说研究对象与边界，再决定方程。控制条件需要物理意义：密封保证什么，刚性容器保证什么，缓慢变化允许什么近似；不能让“密封”“恒温”“恒压”成为机械匹配公式的关键词。

每个模型至少说清：研究对象、假设、可预测的量、适用范围、可以用什么证据检查。出现不同粒度的模型时，要区分观察到的现象与提出的解释。

### 4.3 图、文字和方程之间要有任务

图应帮助学生完成某项推理：补受力、标能量流、从数据画图、把图像转成关系式，或指出图与解释的矛盾。已经把结论全部写在旁边的插图，可以用于示范，但不能同时当作独立考查。

不同表征承担不同职责：装置图交代测量条件，微观图解释机制，坐标图表达变量关系，方程给出定量预测。不能用一幅粒子动画替代实验数据，也不能用漂亮的箭头替代受力分析。

### 4.4 方程要说明来历和用途

区分定义、实验归纳、由原理推出的关系，以及模型近似。推导用来解释关系，不以代数长度充当深度。正文保留理解所必需的步骤；考试范围之外的完整推导可以作为明确标注的拓展，不应悄悄增加必学负担。

数学习惯需要就地接入：比例、斜率、面积、指数、对数线性化、矢量和单位。让学生说明这些数学操作在该物理系统中表示什么。

### 4.5 从示范走向独立

采用“解释一个示范 → 完成缺失的关键判断 → 独立解决改变条件的问题”。示范应暴露模型选择的原因；提示按需要依次提供判断方向、适用原理、关键一步，完整解答另开。

新问题至少改变一个有物理意义的条件，例如电容器保持接电源还是断开、气体固定体积还是固定压强、输入电能是否等于试样净吸热。仅换数字可练熟练度，不能独自证明迁移。

### 4.6 反馈之后必须有再尝试

反馈应指出错误所在：系统选错、固定量误判、图像转换失误、代数或单位错误。随后给一个短问题让学生重新判断。不能把“展开答案”当成学习闭环的终点。

重要概念在后续学习段中再次无提示提取；具体间隔结合课表安排，不宣称某个固定天数对本站学生最优。

## 5. 不同物理内容应采用不同展开方式

| 内容性质 | 合适的展开方式 | 应避免的制作方式 |
| --- | --- | --- |
| 力与运动 | 描述运动、区分矢量、实际受力图、选方向、建立运动方程、检查接触等条件 | 先摆出所有公式，随后按题干数字套式 |
| 场与势 | 试探对象与相互作用、空间图像、场与势的区别、图像关系、粒子运动 | 把引力公式机械换成电学符号，忽略电荷符号和方向 |
| 电容与电路过程 | 装置与状态、保持量、能量或电荷变化、时间图像、测量验证 | 混用接电源和断开两种条件；先记指数再理解过程 |
| 经验定律 | 控制变量、测量或给定数据、寻找关系、表示关系、预测新数据 | 先宣布结论，再安排只能确认结论的数据 |
| 微观理论 | 证据、假设、机制、可检验预测、与宏观关系连接、适用边界 | 把不可直接观察的机制说成“实验直接看到” |
| 实验学习 | 问题、方案选择、记录、分析、评价、再次设计 | 完整步骤清单加一句“减小误差”，没有学生决策 |

与普数、高数可以对齐的是导航、可读性、独立练习、提示与解答的关系和来源规范。物理还必须落实系统、条件、表征和证据；数学中的力学材料本身也需要这些。学科差异不应被简化成“数学只有推导、物理只有实验”。

## 6. PH03 的建议学习路线

这是一份学习关系图谱，不是把当前六个文件直接改名的方案。现有 AS 基础应按任务补接：矢量与牛顿定律、能量、动量、电路和图像处理，不应把全部 AS 内容再讲一遍。

| 主题组 | 建议的学习转折 | 必须能留下的独立作品 | 当前落点 |
| --- | --- | --- | --- |
| 圆周运动 | 速度方向变化 → 加速度 → 实际力提供径向合力 → 边界条件 | 在新情境画实际受力图，并解释方程每一项 | 已有学习页，先审关键转折 |
| 简谐运动 | 回复作用与运动条件 → 位移、速度、加速度关系 → 能量 → 振子模型 | 从图像或回复关系判断是否为 SHM，并说明理由 | 已有学习页 |
| 引力场与轨道 | 作用力与场 → 势和能量 → 空间图像 → 与圆周模型连接 | 用场与运动两个模型解释一个轨道问题 | 已有学习页；两个模型分清后再综合 |
| 电场 | 从电荷相互作用建立场 → 势与能量 → 叠加与匀强场运动 | 在带符号的图、力方向与能量变化之间保持一致 | 已有学习页 |
| 电容 | 电荷和电势差关系 → 图像与储能 → 几何和介质 → 不同保持量 | 比较接电源、断开两种操作，给出相互一致的量变关系 | 已有学习页 |
| 充放电 | 电路变化机制 → 变化速率 → 指数图像 → 参数测量 | 从未标注时间常数的数据提取参数，评价方法 | 已有学习页，连接 RP6 |
| 放射性指数变化 | 随机个体事件 → 大量粒子的统计变化 → 指数与半衰期 | 解释单次结果波动与总体规律可以同时成立 | 当前只有速查；不能只复制 RC 的数学形式 |
| 磁场与电荷运动 | 力的方向和条件 → 运动改变 → 与圆周运动连接 | 画轨迹并解释磁力对运动的作用 | 当前只有速查 |
| 电磁感应 | 观察感应现象 → 磁通链变化 → 大小与方向 → 能量解释 | 区分“有磁场”和“磁通链改变”，解释方向 | 当前只有速查 |
| 交流与变压器 | 波形与测量 → 有效值 → 感应与变压 → 损耗与输电 | 分析波形和功率数据，评价效率测量 | 当前只有速查，连接 RP7 |

推荐默认顺序沿上表展开，但引力与电学可分别推进。跨主题连接只在所需模型已经建立之后进行：轨道依赖圆周运动；带电粒子磁场运动也依赖圆周运动；感应之后再解释变压器。指数形式的相似性应在两种物理机制各自讲清后总结。

正式制作每一组时，还需做“具体大纲条目—学习任务—独立考查”的完整覆盖表。以上路线不声称已经代替条目级审核。PH04 的核能和能源主题应另作单元设计，本轮不据热学研究直接展开。

## 7. PH04 热学的建议安排

单元名建议保留 **热学（Thermal physics）**；“热力学第一定律”是其中一部分。中心问题是：**宏观的温度、状态和能量变化，怎样由测量与微观模型共同解释？**

建议先形成下列学习段，再决定网页组合。T1–T9 是设计编号，不是强制九个网址；P8、P9 是在对应位置展开的实验活动。

| 顺序 | 中心问题与学习重点 | 学生应完成的关键任务 |
| --- | --- | --- |
| T1 温度、内能与传能 | 温度说明什么？系统储存什么、怎样与外界交换能量？先建立能量清单和第一定律符号，不抢先展开气体做功计算 | 标出系统边界与传能方向；区分内能、温度、热和功；解释一个能量变化 |
| T2 加热与物态变化 | 为什么吸收能量不一定升温？把过程分段，连接微观解释、加热曲线与能量计算 | 自己标注曲线阶段；从数据求材料参数；解释平台段 |
| P8 电学法测比热容 | 电能输入怎样成为可用的测量？连接 T2 与 AS 电路 | 画测量电路、选择记录方式、处理数据、判断损失造成的偏差方向 |
| T3 稳态能量平衡 | 连续流动时，怎样比较每秒输入、流过和损失的能量？ | 把整份质量改为质量流率；比较两次运行并解释消去损失项的条件 |
| T4 热传导 | 同样温差下，墙体为何有不同的能量损失速率？ | 读几何与温度示意；预测改变材料、厚度或面积的效果，再计算 |
| T5 气体的经验关系 | 怎样从受控数据得到状态量之间的关系？为什么需要绝对温度？ | 标出保持量，选择图像，利用关系预测新状态并检查控制条件 |
| P9 气体实验 | 装置怎样分别维持需要的条件？为何要等待？ | 比较两种装置；处理数据；解释快速读数、死体积或温度不均匀的影响 |
| T6 理想气体状态模型 | 怎样把不同气样放在同一方程中描述？ | 连接物质的量、分子数与质量；说明每个符号描述整份气样还是单个粒子 |
| T7 气体做功与第一定律再应用 | 活塞移动怎样传递能量？图像面积和功的符号怎样对应？ | 从力和位移建立体积功关系；把功接回 T1，检查状态变化是否一致 |
| T8 微观模型与压强 | 看见了什么证据？为何不可见粒子的碰撞能产生压强？ | 区分悬浮颗粒和分子；用动量传递机制解释宏观变化，并说明模型假设 |
| T9 分子运动与温度 | 同温意味着哪些微观量相同，哪些量未必相同？ | 区分平均平动动能、均方根速率和总内能；比较不同气体并解释条件 |
| 单元综合与速查 | 在没有题型标签时，应选择什么模型？证据是否支持它？ | 混合解释、计算、图像和实验信息；最后形成全章模型选择表 |

**排序理由：**先让“能量变化不等于温度变化”站稳，再处理实验和功率平衡；先理解受控气体数据，再建立统一状态方程，随后用微观模型解释它。T4 可作为独立支线。T7 回到 T1，形成有新证据和新表征的再学习。

需要守住的物理边界：

- 连续流动采用本课程所需的功率平衡，不无故引入大学开放系统热力学。
- 比较两次稳态实验时，说明为何损失可近似相同；不能只用联立方程掩盖条件。
- 区分净传给试样的能量与电源输入的能量；明确是否计入装置热容和损失。
- 气体状态、功和内能的数据必须共同自洽，不能只检查加减法。
- 平均平动动能关系不能不加条件地扩大成所有真实气体的总内能公式；使用单原子理想模型时明确写出。
- 第二定律、熵和热机循环不作为本单元默认必学范围。是否作为拓展，另行决定。

## 9. 一个可以实际制作和试用的样章

先制作 T2“温度变化与物态变化”的完整学习样章。这个切口可以同时检验概念、图像、定量模型、提示层级和英文解释，又不必先完成全套热学。

### 9.1 中心问题和成功表现

中心问题：**温度不变，吸收的能量去了哪里？**

学生完成后，应能：

1. 用粒子动能与势能解释升温和熔化的区别。
2. 从图或数据区分过程阶段，建立相应能量关系。
3. 区分加热器输入与试样净吸热，发现损失信息不能被忽略。

先修检查只检验质量、温差、功率、能量和 T1 的基本概念；答错时给短回顾链接。

### 9.2 学习任务顺序

以下全部为**自拟教学任务**，数据为理想化构造数据，不是官方题或实测数据，不赋官方分值。

**任务 A：先判断。** 一份冰水混合物持续接收能量，仍有冰和水共存，温度不变。要求先画能量进入的箭头，再写“内能是否变化、为什么”。保留初次答案，稍后重写。

**任务 B：从数据建立图像。** 在恒定大气压下，0.200 kg 纯冰从 −10 °C 开始吸收能量。表中 Q 是试样累计净吸收能量；忽略宏观机械功，模型假设各阶段达到热平衡。

| Q / kJ | 温度 / °C |
| --- | --- |
| 0.00 | −10.0 |
| 2.10 | −5.0 |
| 4.20 | 0.0 |
| 37.60 | 0.0 |
| 71.00 | 0.0 |
| 75.20 | 5.0 |

明确告知：到 4.20 kJ 时恰好开始熔化，到 71.00 kJ 时恰好全部熔化。不能让学生仅凭稀疏读数猜出未给定的转折点。

学生自行画温度—Q 图、标出三种阶段，再连接到粒子解释。首次讲解示范冰升温段，学生完成熔化段与水升温段。需解释为什么使用某一段的能量差，不能直接把累计 Q 当成该段能量。

教师核算：冰的比热容为 2100 J kg⁻¹ K⁻¹；比熔化潜热为 334000 J kg⁻¹；水的比热容为 4200 J kg⁻¹ K⁻¹。这里是检验任务设计的计算结果，不声称重新测定了实际物性常数。

**任务 C：改变条件，独立尝试。** 英文题干示例：

> A 120 W heater supplies energy for 100 s to 0.200 kg of ice initially at 0 °C. During this time, 2.40 kJ is transferred to the surroundings. Ice and water remain together at 0 °C. Calculate the mass of ice melted, using a specific latent heat of fusion of 334 kJ kg⁻¹. Explain why a zero temperature change does not imply zero energy transfer to the sample. Neglect the heat capacity of the apparatus.

独立解答时不预先列公式。提示依次为“输入能量都到哪里去了”“先求净吸热，再判断过程”“熔化质量对应潜热项”，最后才是完整解答。

教师核算：电能 12.0 kJ，净吸热 9.60 kJ，熔化质量约 0.0287 kg，小于起始冰质量，冰水共存条件自洽。它考查能量边界和模型选择，不能仅靠照抄任务 B 的数值步骤。

**任务 D：修订解释。** 回到 A，要求学生说明自己保留或改变了什么判断，并用两句英文解释。句型支持可以在首次学习提供，之后撤掉；解释需包含能量流入、粒子势能改变、温度为何不变之间的关系。

**任务 E：稍后重新提取。** 换成凝固或具有损失信息的新数据，关闭本课提示，先判断能量方向和阶段，再计算或解释。避免把 C 的原题重做正确当成迁移成功。

### 9.3 怎样评价样章

使用以下自拟观察量规，各维度记为“未建立／有提示能做／独立能做”，记录原始作答依据，不合成未经验证的总分：

| 维度 | 独立能做的证据 |
| --- | --- |
| 概念 | 能区分温度、内能和传能，并解释相变平台 |
| 表征 | 图像的阶段、能量区间和语言解释对应一致 |
| 建模 | 能区分输入与净吸热，说明选择关系式的条件 |
| 定量检查 | 单位、阶段差值、质量及剩余物态互相一致 |
| 英文表达 | 能独立表达关键物理因果，不只翻译关键词 |

试用先观察学生在哪一步停顿、需要第几级提示、是否能完成改变条件的题。教师可记录匿名汇总和少量去身份作答。小规模试读用来修正可用性和误解点；要声称提高成绩，还需要更严谨的比较与追踪。

## 10. 实验材料和汉化应怎样制作

### 10.1 实验必须有可处理的证据

每项实验至少设计一份学生能处理的记录：读数、数据表、图像、装置照片或清晰示意。真实数据注明来源和条件；构造数据明确标注。不能给出已经替学生处理完的图，再声称学生做了图像分析。

任务要覆盖“为什么测这些量、为什么这样连接、什么条件要保持、怎样由记录得到结论、偏差如何改变结果”。区分随机不确定度、系统偏差与模型缺陷；改进建议要说明影响链，而不是列“多次测量、取平均”。

网页可以支持实验准备与分析，不能凭网页作答证明学生已经会搭装置和操作仪器。现场能力由实际活动检验。

### 10.2 汉化需要保留向英文考试输出的桥梁

- 中文用于建立概念、解释原因和诊断错误；首次出现的术语给稳定的英文对应。
- 官方题保留英文原文及图表，附可核查题号和评分依据；改动题干、图或条件就标“改编题”；自拟题清楚标注。
- 单独训练 describe、explain、calculate、determine、evaluate 等任务要求；具体作答期望用已核查的官方题与评分标准校准。
- 关键解释提供短英文示范，随后安排撤去句型的英文作答。全中文解答不能自动证明英文解释能力。
- 中英文共享物理事实、条件、符号、数据和题目身份；教学解释可按语言需要调整，不能以字数或标题数量相等代替内容对齐。

## 11. 制作流程与验收

建议采用以下顺序，每一学习段先完成设计稿，再进入网页制作：

1. **建来源包。** 当前大纲定位；官方试卷、评分标准及可获得的考官报告。记录实际读过的文件、年份、题号、页码；未取到的材料标待核查，不能推测考官意见。
2. **先写评价任务。** 写出学习后的独立任务、必要先修、常见错误和成功表现，再选择讲解与例题。
3. **设计学习转折。** 明确中心问题、系统与条件、所需表征、实验或数据、示范到独立的支架撤除方式。
4. **进行物理审核。** 独立重算，同时检验数据是否能同时满足状态方程、过程约束和能量守恒；检查图像、符号、单位、理想化条件和实验偏差方向。
5. **制作双语内容。** 审题目来源与身份、术语、英文输出任务及中英文物理一致性。先修订内容，再调整视觉排版。
6. **完成技术检查。** 构建、链接、MathJax、折叠交互、键盘操作、图像替代文字及桌面和手机实际阅读。检查题目是否因图、摘要或替代文字提前泄露答案。
7. **试用并返修。** 看独立任务和延后重试的作答，而不是只问“页面看得懂吗”。修订后再扩大到下一组学习段。

每段制作前只需一份紧凑的设计卡：**中心问题；可观察目标；先修；模型与条件；图和数据承担的任务；示范与撤除提示；独立考查；来源。** 不需要先开发新组件、学习状态系统或评分平台。

验收需要分开记录：

| 状态 | 能证明什么 |
| --- | --- |
| 来源与范围核查通过 | 内容和题目依据可追溯，范围未漏列或混用版本 |
| 物理审核通过 | 在声明条件下，概念、计算、图像、数据和解答自洽 |
| 技术检查通过 | 页面在所测环境可访问、可读、可操作 |
| 学习试用完成 | 已观察到学生如何使用及具体问题，记录支持哪些能力判断 |

前三项都通过，也不能自动标为“教学效果已验证”。
