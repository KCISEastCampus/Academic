# 跨学科内容制作准则：研究依据与适用边界

日期：2026-10-15。对象：Academic 当前的 IGCSE、AS、A2 数学与高等数学、化学、生物、经济；物理承接[独立研究](research-physics-learning-design-2026-10-15.md)。可直接执行的准则已写入根 [AGENTS.md](../../AGENTS.md)。

本文是制作规范的依据记录，不是全站错误审计、完整课程设计或教学干预效果报告。官方文件规定范围和评估要求；研究提供设计启发；具体章节、任务、提示和验收方式是项目选择。不能将三者混称为考试局规定。

## 1. 检查了什么

本次只读抽查了现有科目入口及代表性内容，核对官方资格页、大纲、部分评分材料和原始教育研究。没有编辑课程页、改导航或发布。

| 学科 | 当前仓库证据 | 制作准则需要解决的问题 |
| --- | --- | --- |
| 数学／高数 | 9260 Extension、9660、9665；抽查归纳法、数值方法、数学建模及 IGCSE 索引 | 保留已有论证与条件解释；把方法选择、证明、数值校验和工具许可分别处理 |
| 化学 | 9202、9620；当前 AS 首页标 Unit 2，A2 标 CH03；抽查结构性质、反应及热化学 | 避免把部分单元当完整课程；将反应表和符号连接到模型、条件与证据 |
| 生物 | 9201、9610；AS 页目前仅 Unit 2；抽查吸收、疾病和运输相关内容 | 从术语和机制笔记走向学生重建解释、读图和据数据论证 |
| 经济 | 现有 AS 入口主要是署名导图 PDF 的链接；主题与 EC01/EC02 路线相符 | 保留导图的资料属性，另建情境、模型、分析和评价活动；不能宣布现有导图已覆盖全部大纲 |
| IGCSE 共性 | 多个入口是范围清单，Quick Check 常将答案紧接题目 | 区分速查和学习；独立任务应给学生先作答的空间，不能把即时看见答案当掌握 |

以上为文件抽查，不是浏览器视觉审计；经济导图 PDF 内文未逐份核对，不能仅从入口标题确定其资格版本与完整性。

## 2. 共同结论

1. 共同规范应规定来源、学习目标、独立产出、反馈、双语一致性和验收证据；具体学生行动由学科决定。
2. 按概念依赖和学习转折分段，不把大纲顺序、教材页码或文件长度直接当教学顺序。
3. 首次尝试应符合学生先修，随后提供直接讲解、示范和适当提示，再逐步撤除帮助。不能把“先尝试”误用为没有支持的发现学习。
4. 完整课程、学习页、参考笔记、资料目录分别标识；不以题数、图数、折叠块数量或构建成功证明教学完成。
5. 稳定规则写入 AGENTS；资格版本、具体题号和观察快照留在来源记录。后续制作仍需针对目标考季复核。

## 3. 数学与高等数学

### 官方依据

- [9660 Mathematics 大纲 v5.2](https://www.oxfordaqa.com/wp-content/uploads/2026/07/oxfordaqa-a-level-mathematics-specification.pdf)：核查数学语言、统计、力学和评价目标相关段落。
- [9665 Further Mathematics 大纲 v5.2](https://www.oxfordaqa.com/wp-content/uploads/2022/06/oxfordaqa-a-level-further-mathematics-specification.pdf)：核查先修、证明及统计／力学范围。
- [9260 Mathematics 大纲 v5.1](https://www.oxfordaqa.com/wp-content/uploads/2022/06/oxfordaqa-gcse-mathematics-specification.pdf)：核查阶段与计算器要求。
- [9660 command words](https://www.oxfordaqa.com/oaqaresources/maths/assessment/a-level-maths-command-words.pdf)、[9665 command words](https://www.oxfordaqa.com/oaqaresources/maths/assessment/a-level-further-maths-command-words.pdf)和 [MA03 官方示例及考官评语](https://www.oxfordaqa.com/oaqaresources/maths/assessment/a-level-maths-example-responses-ma03-unit-p2.pdf)：核查任务要求与得分证据，未对全部手写响应逐页视觉审阅。

这些来源支持把推理、完整作答、模型解释和工具限制分别核查。9260 的计算器规则不能从 9660 或计算器专题页推断；两门 A-level 数学与物理也不能只因主题同名就互抄深度。

### 研究启发

[Renkl 等，2002，作者机构摘要](https://asu.elsevierpure.com/en/publications/from-example-study-to-problem-solving-smooth-transitions-help-lea/)讨论从完整示例逐渐过渡到独立解题，结论边界包含近迁移。[Rohrer、Dedrick 与 Stershic，2015 原始论文](https://files.eric.ed.gov/fulltext/ED557355.pdf)比较数学练习编排，研究对象为七年级学生，支持让练习包含策略辨别；不等于已经证明本站 A-level 综合题的效果。

**项目落实：**解释方法为什么适用，安排补步骤、纠错和未标明方法的混合任务；同时保留必要的单项熟练练习。不能强制每课按固定三级题数排列。证明检查逻辑和范围；统计检查随机对象、条件与结论；力学检查假设、受力、约束与方程；计算器结果检查输入和数学意义。

## 4. 化学

### 官方依据

- [9202 当前资格页](https://www.oxfordaqa.com/qualification/international-gcse-chemistry-9202/)所链接的 [v6.2 大纲](https://www.oxfordaqa.com/wp-content/uploads/2026/07/oxfordaqa-gcse-chemistry-specification.pdf)：核查结构性质、计量及实验技能。
- [9620 v5.3 大纲](https://www.oxfordaqa.com/wp-content/uploads/2026/07/oxfordaqa-a-level-chemistry-specification.pdf)：核查成键、热化学、平衡、机理及实验段落。3.3.1.2 对电子对弯箭起点有明确要求；自由基机理不要求弯箭。因此，不应把更高阶段或其他课程的表示要求加成必考内容。

### 研究启发

[Galloway、Stoyanovich 与 Flynn，2017](https://pubs.rsc.org/en/content/articlehtml/2017/rp/c6rp00231e)通过大学有机化学初学者访谈研究学生如何解释机理语言。它支持检查学生理解的电子移动和符号意义，而非只看复制出的机理图；不是 A-level 网页教学效果实验。

**项目落实：**按需要连接观察、粒子或结构、符号，不强制每段塞入三种表征；用补箭头、据结构预测、解释条件改变和纠错检验理解。结构性质必须经过作用力或可移动电荷的因果环节。定量题先判定实际体系和化学关系，再计算；混合后的计量与平衡不能颠倒。实验要求学生区分观察与推断，作出可解释的方法选择。

现有 IGCSE 结构性质表以“无净电荷”解释简单分子不导电，提示制作审核应检查“缺乏可移动带电粒子”这一机制。本次只记录该例，没有修改页面或宣布所有类似错误已修复。

## 5. 生物

### 官方依据

- [9610 资格入口](https://www.oxfordaqa.com/qualification/international-as-and-a-level-biology-9610/)及其 [v4.2 大纲](https://www.oxfordaqa.com/wp-content/uploads/2026/07/oxfordaqa-international-as-and-a-level-biology-specification.pdf)：核查先修原理、运输、变异、实验及数学要求。
- [9201 v5.2 大纲](https://www.oxfordaqa.com/wp-content/uploads/2026/07/oxfordaqa-gcse-biology-specification.pdf)：核查结构功能、尺度、实验技能及测量术语。
- [9201 样题](https://www.oxfordaqa.com/wp-content/uploads/2026/07/9201-92011-international-gcse-biology-specimen-paper-v2.pdf)与[评分标准](https://www.oxfordaqa.com/wp-content/uploads/2026/07/9201-92011-international-gcse-biology-mark-scheme-v2.pdf)：抽查尺度、结构功能、失水实验和免疫曲线等任务。
- [BL01 样题](https://www.oxfordaqa.com/wp-content/uploads/2026/07/9610-BL01-international-as-biology-specimen-paper-2016-v1.pdf)与[评分标准](https://www.oxfordaqa.com/oaqaresources/science/assessment/9610-BL01-international-as-biology-mark-scheme-2016-v1.pdf)：抽查对照、数据及机制推理，不能把旧题中的简化判断扩展成普遍统计规则。

### 研究启发

[Wilson 等，2006，细胞生物学动态系统中的物质追踪](https://pmc.ncbi.nlm.nih.gov/articles/PMC1681358/)记录大学生追踪物质、区分物质与能量的困难。[Doherty 等，2025，生物原理与机制推理](https://pmc.ncbi.nlm.nih.gov/articles/PMC12667368/)研究大学入门生物的小组讨论，支持把一般原理与情境细节相连，同时显示错误先备知识可能导致错误解释。它们不证明某一种因果图模板对所有中学生有效。

**项目落实：**写清实体、过程、位置、方向和条件，连接结构到功能；图像让学生标注、比较、预测和重建因果；跨层级解释追踪物质、能量和信息。数据任务要求证据与结论范围。重复测量与独立样本不同；误差条先明确所代表的量，不能将 SD、SE、CI 的重叠判断混作通用显著性检验。

## 6. 经济

### 官方依据

从 [9640 资格页](https://www.oxfordaqa.com/qualification/international-as-and-a-level-economics-9640/)进入官方资源目录，当前链接的 [Economics 大纲为 v2.0](https://www.oxfordaqa.com/aqadownloads/other/oxfordaqa-a-level-economics-specification.pdf)。核查了 3.1.1.4 的命题与判断、3.5 定量技能及 4.3 评价目标，范围覆盖情境应用、分析及有证据的判断。

[官方 Teaching Guidance](https://www.oxfordaqa.com/oaqaresources/economics/oxfordaqa-a-level-economics-teaching-guidance.pdf)印刷页 10 说明高分值题采用综合等级评价，可信的不同回答可获得认可；页 11 等处区分 AS 与 A2 深度。它是 2020 年指南，课程边界应再与当前大纲核对，不单凭旧指南删去现行内容。

**项目落实：**围绕具体问题连接主体、模型、机制、数据与条件判断；图中变化必须与文字因果一致。评价用目标、时间尺度、利益分配、实施条件和证据权衡，不以固定段落数或空泛“depends”验收。数据练习核查百分比／百分点、名义／实际、基期、口径和单位，并解释经济含义。真实案例有日期和出处，构造案例标明自拟。

本次未读取跨考季经济试卷与评分标准语料，不能声称已经建立所有题型的逐分评分模板。正式制作某个例题时，仍需读取该题配套评分标准。

## 7. 来源与版本审核的实际发现

- 旧官方 PDF 仍可能在线但不是资格页当前版本。本次化学 9202 旧链接返回 v6.1，资格页指向 v6.2；经济旧 `/oaqaresources/specifications/` 链接返回 v1.2，当前资源入口指向 v2.0。使用“官方域名”不足以完成版本核查。
- 数学 9660 课程页的一个 example mark scheme 链接实际打开 9665/FM01 样题评分文件。必须核对文件正文的资格、试卷与题号，不能只信入口标签。
- 官网已有 revised 数学资格，例如 [9765](https://www.oxfordaqa.com/qualification/international-as-and-a-level-further-mathematics-9765/)。应按目标学生考季与课程决定是否迁移，不能自动改写现有资格。
- 不同科学学科、资格和阶段的评价目标权重与统计要求不完全相同。根 AGENTS 保留核对规则，不存一套通用百分比或未经限定的检验法。

## 8. 规则怎样验收

| 层面 | 应检查的证据 | 不能用什么替代 |
| --- | --- | --- |
| 范围与来源 | 目标资格条目、实际读过的题目及配套评分材料、清楚的题目身份 | 教材标题、过时链接或其他考试局的同名主题 |
| 学科正确性 | 独立推导、条件与反例、图和数据的一致性、机制及结论范围 | 只重算末行数字、复制答案、关键词齐全 |
| 学习设计 | 明确目标、适合先修的任务、提示撤除、独立迁移、反馈后重试 | 题数、页面长度、折叠块或“阅读完成” |
| 技术 | 针对课程变更的构建、现有检查、生成 HTML 与桌面／手机实际阅读 | 仅 Markdown 源码、脚本匹配标题 |
| 教学试用 | 学生实际作答、提示需求、错误类型与再尝试 | 研究论文的效果量、作者自测或主观“看起来清楚” |

本轮只修改指导文档，需核查 Markdown、链接、规则一致性与改动范围；不因写入 AGENTS 就重建全站或宣称现有课程已经符合新标准。没有新增计算器按键流程、实验操作或学生学习数据。
