## 化学、标准液与操作

- carbonate/HCl 总反应和净离子式原子及电荷均守恒，完全中和为 carbonate:H+ = 1:2；NaOH/HCl 为 1:1，H2SO4/NaOH 为 1:2。强酸强碱净式 H+ + OH− → H2O 的净电荷两边均为零。溶液中 Na+、Cl− 为旁观离子。各示例物态合理。
- 甲基橙适用于所设 carbonate 完全中和；不能把酚酞的第一阶段误作同一 1:2 终点。equivalence point 是计量点，endpoint 是观察判据，两者不定义为 pH 7。少量指示剂、近终点逐滴、摇匀、白瓷板与一致判色的理由成立；需补的观察和选择证据为 F3。
- 以题设纯、干燥、无水 Na2CO3 和 106.0 计算标准液成立。含结晶水、吸湿或杂质的称量不能直接代表同量无水 carbonate；本页明确假设，未把任意试剂瓶都当 primary standard。无须为纸面题擅加学生加热干燥规程；实际批次纯度、无水状态、处理及储存须由教师确认。标准液的已知浓度须来自实际质量和校准最终体积；未知 HCl 本身不是称量制备的标准。
- 配制流程“少量水溶解 → 定量转移并洗入烧杯／玻璃棒／漏斗残液 → 回到校准温度 → 眼平凹液面定容 → 倒转混匀”合理。过刻度后倒出混合液不能恢复原目标浓度；加入固体前已量好水或已到刻度也不能建立目标最终体积。标签包含物质、水合状态、浓度、日期合理。
- 容量瓶确定最终体积，容量移液管和吸球给固定 aliquot，滴定管测可变加入体积，锥形瓶用于混合而非精确定容。容量瓶、移液管及滴定管作用没有互换。水洗后以所装试剂润洗移液管／滴定管；锥形瓶清洁但可含去离子水。尖嘴先充满、移去漏斗、眼平读数、初读数不强制为零均正确。移液管按具体校准方式放液，不应概括为所有型号都必须吹尽。

## 不确定度、偏差及方向链

| 条件（其他量按题设固定） | 独立推理 | 网页判断 |
| --- | --- | --- |
| carbonate 标准液，HCl 在滴定管；过终点 | c(HCl) = 2c(carbonate)V(aliquot)/V(titre)；多加酸使记录分母大，计算酸浓度低。 | 正确 |
| 初读数时尖嘴有气泡，随后液体填满尖嘴 | 读数差包含未进入锥形瓶的填充体积，记录 titre 大，所算 HCl 浓度低。条件说清后方向成立；不能推广为所有气泡情形。 | 正确 |
| `fault-check` A：湿移液管未经 carbonate 润洗 | 实际 carbonate mol 少 → 所需 HCl titre 小；计算仍假设原标准浓度和固定 aliquot mol → HCl 结果高。相同错误可重复得到一致结果。 | 正确；润洗针对原因 |
| `fault-check` B：正确 aliquot 已入瓶后加去离子水 | carbonate mol 不变 → 等当点酸 mol 不变 → titre 和计算结果不变。该理想化不声称任意大稀释对真实指示剂终点都绝无影响。 | 正确，且正文明确理想化 |
| `retry-titration`：滴定管中 NaOH 被残水稀释，名义浓度仍用于计算 | 中和同量瓶中 H2SO4 需要更多 NaOH 体积 → 用偏高的名义浓度乘较大 titre 高估碱 mol → 高估酸浓度；先用 NaOH 润洗。 | 正确；未知物位置变换后重新推理 |

读数最坏界限、endpoint 估计、标准液及移液体积的贡献须分开；重复性不是准确度。正文没有声称“多做几次”可以消除系统偏差，也没有把 ±0.10 cm³ 固定为所有滴定的总界限。配制重试确实检验实际质量、溶质守恒和最终体积；硫酸重试确实检验新反应比例及滴定液稀释方向；但不能替代 F1/F2/F3 所需证据。

### 综合页 `record-check`：延后不确定度练习已定位

实际阅读和独立解答的位置：

- EN：[quantitative-review.md，record-check](../../alevel/as-chemistry/quantitative-review.md#record-check)，源文件第 48 行标题、第 50 行题干、第 56 行解答。
