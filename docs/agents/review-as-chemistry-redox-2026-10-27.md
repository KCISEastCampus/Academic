## 全部示范与题目独立核算

### 电子转移示范及agent-check

Zn(s)→Zn2+(aq)+2e−：电荷0→2−2=0，Zn各1；Cu2+(aq)+2e−→Cu(s)：2−2=0。相加Zn+Cu2+→Zn2++Cu，Zn／Cu各1，电荷两侧+2。Zn失电子、被氧化、为还原剂；Cu2+得电子、被还原、为氧化剂。定义与方程一致。

Mg(s)→Mg2+(aq)+2e−；2H+(aq)+2e−→H2(g)。相加Mg+2H+→Mg2++H2：Mg各1、H各2，总电荷+2→+2；HCl中的Cl−两侧不变，是旁观离子。Mg为被氧化物／还原剂，H+为被还原物／氧化剂。提示仅在展开后给出电子数；不用提示时学生须自己写半式、配出H2，任务有效。

### 氧化态示范及state-check

| 物种 | 独立方程／结果 | 与正文比较 |
| --- | --- | --- |
| SO4^2− | x+4(−2)=−2，S=+6 | 一致 |
| Fe2O3 | 2x+3(−2)=0，Fe=+3 | 一致 |
| Fe2(SO4)3 | 三个SO4^2−总−6，2Fe须+6，Fe=+3；每个SO4的S仍+6 | 一致，不能把整个离子电荷赋给S |
| NH4+ | x+4(+1)=+1，N=−3 | 一致 |
| H2O2 | 2(+1)+2x=0，O=−1 | 一致 |
| OF2 | x+2(−1)=0，O=+2 | 一致 |
| NaH（规则例子） | Na为+1、总和0，H=−1 | 一致 |
| O2、Cl2（规则例子） | 均为单质，元素氧化态0 | 一致 |

2Fe2++Cl2→2Fe3++2Cl−：Fe各2、Cl各2，总电荷+4→+6−2=+4。每Fe从+2到+3失1e，总2e；Cl2中两Cl各从0到−1，总得2e。Fe2+被氧化／为还原剂，Cl2被还原／为氧化剂，答案正确。形式氧化态与实际单原子离子电荷的区分讲清，没有把共价化合物说成含对应游离离子。

### 酸性半反应示范

MnO4−→Mn2+：Mn各1；右加4H2O配4O，左加8H+配8H；左电荷−1+8=+7，右+2，故左加5e−后均+2。Mn由+7到+2亦要求得5e。Fe2+→Fe3++e−，两侧电荷+2。全部项乘5后相加：MnO4−+8H++5Fe2+→Mn2++4H2O+5Fe3+。Mn1、Fe5、O4、H8两侧均相同，电荷−1+8+10=17、2+15=17；1:5物质的量比成立，不由初始浓度决定。

推理顺序完整：先说明为何添水、再配H、再定位电子、再等电子合并，最后检查；不需要初学者猜省略步骤。

### combine-check

Cr2O7^2−→2Cr3+先配Cr2；右加7H2O，左加14H+；左电荷−2+14=12，右2×3=6，因此左加6e−：

`Cr2O7^2− + 14H+ + 6e− → 2Cr3+ + 7H2O`。

Fe2+→Fe3++e−乘6，合并为`Cr2O7^2− + 14H+ + 6Fe2+ → 2Cr3+ + 7H2O + 6Fe3+`。Cr2、O7、H14、Fe6两侧匹配；半式电荷均+6，总式左−2+14+12=24、右6+18=24。Fe2+用量6×0.00200=**0.0120 mol**，保留3位有效数字。Cr从+6到+3，每个得3e、两个共6e，另一路核验一致。产物已给定，任务考核算与配平，不额外要求AS学生背A2过渡金属反应。

### audit-check

错误式`MnO4− + 8H+ → Mn2+ + 4H2O + 5e−`左电荷+7、右2−5=−3，虽原子配平，电荷不守恒；5e应移到左边。Mn原本为+7，变+2是还原，不能把MnO4−整体的−1和Mn2+的+2当作同一原子氧化态的上升。答案分别处理原子、电荷和概念错误。

给定`Cl2 + 2OH− → Cl− + ClO− + H2O`：Cl2、O2、H2两侧匹配，总电荷−2→−2；Cl−为−1，ClO−中Cl为+1。两Cl原子原本为0，一个得1e，一个失1e，是歧化；并非单个Cl原子同时成为两种产物。原文解释与题目要求一致。本题未要求从任意温度浓度预测产物，不将给定反应反推成所有碱性条件的普遍实验结论。

### retry-redox

H2O2→2H2O，补2H+于左，再加2e−使电荷两侧0：`H2O2 + 2H+ + 2e− → 2H2O`。氧从−1到−2，两O共得2e；`2I− → I2 + 2e−`，电荷两侧−2。相加`H2O2 + 2H+ + 2I− → 2H2O + I2`，H4、O2、I2各守恒，总电荷+2−2=0→0，电子完全相消。

H2O2接受电子、是氧化剂；若把其O误设−2，会漏掉这次还原。I−消耗2×0.00300=**0.00600 mol**，3位有效数字。aq／l标注与给定水溶液情境相容；未给体积，因此不能凭空假定超过I2溶解度，也不能据纸面方程宣布完成真实实验。新任务换了氧化态例外、反应物及电子比，能检验电子放置、代理角色及配比；不是抄回Cr示范或仅改原题数字。
