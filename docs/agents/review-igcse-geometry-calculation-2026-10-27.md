## 首次审查发现（关闭状态见文末）

### R1 · P1 · G21 基础正比例放大作图和反求描述没有独立考查

位置：双语 transformations 的 #enlargements、#check-single、#check-description、#check-enlarge、#retry-enlarge、#later-check；英文起始版本对应95、53、75、119、195、241行。

官方 G21 要求 describe **and transform** 2D shapes using single rotations, reflections, translations or positive-scale enlargements。原锁定版 #check-single 只画平移、反射、旋转；要求画整个放大像的 #check-enlarge 是1/2和-2。#enlargements 仅有一个点的公开比例2示范；#later-check 的比例3只要求判断是否与反射相同，学生发现第一点不同就能答“不同”，不必作完整放大图。按最新 Extension 单一路线，分数／负比例题也属于同一学习路线的有效证据；本项保留基础正整数放大的独立作图与新重试补强，不再以不同学生群体为判据。解答中额外列出的点仍不能替代学生被要求提交的图。

反求完整描述也只有镜线的独立题与新镜线重试。正文说明了平移须向量、旋转须中心／角／方向、放大须中心／比例，但没有要求学生从原图与像反求这些内容的任务；放大重试的中心已给定。故“完整描述各种单变换”不能据现有任务宣称完成。

最小修补：补一个正整数比例、非原点中心的整三角形放大作图及不同数据的新重试；给原图与像，要求反求平移向量、旋转完整描述、放大中心与比例，并逐项给可核对的反馈。可扩展现有题，不需新页面或样式。复查学生需要自己确定中心／对应，而不是题干已给待测量。

### R2 · P1 · G22 向量差／数乘的图示及结合律缺少独立产出和匹配重试

位置：双语 vectors-and-matrices #vectors、#check-vectors、#retry-vectors；英文起始版本123、143、351行附近。

PDF22 G22 右列明确要求 calculate **and represent graphically** the sum, difference and scalar multiple，并 understand and use commutative **and associative** properties。现有 #check-vectors 只要求画 u后接v及合向量；u-v和2v-u只要求calculate。#retry-vectors只画AB后接BC，仍是和的路线。正文虽讲了“差就是加反向箭头”，却没有学生真正画差／数乘的考查；仅算列向量不能代替图示。结合律只出现一次公式，独立题都是两个向量，不能识别三向量分组错误。

最小修补：现有独立题增加实际画u-v、一个含负数因子的向量与合成路线，并要求说明起点、终点、反向和长度倍数；在新重试换一组向量检验同一操作。补一个三向量的两种分组图／式对照或纠错任务及对应新重试。不要把交换两个向量当成结合律。

### R3 · P2 · G26 的矩阵次序错误无法被当前新重试检验

位置：双语 vectors-and-matrices #check-composition 与 #retry-composition；英文起始版本290、420行附近。

首次题要求比较RF与FR，确实检验“右边先做”。新重试却是同一个90°顺时针矩阵乘自己，即R²。即使学生仍把先后次序颠倒，也会得到同一乘积R²，因而做对不能证明次序错误已经修复。该重试数值- I本身正确，问题是判定能力与目标不符。

最小修补：另给两个不同且不交换的变换，例如反射y=x和90°顺时针旋转，要求写先后对应的乘积、保留中间点并比较反序。保留现题可作平方熟练题，但不能让它独自承担“次序已修复”的证据。

### R4 · P2 · 中文反射定义把原来的点写成了“原点”

位置：zh/igcse/mathematics/transformations.md 第31行，#moves；英语对应段没有此歧义。

“与原点到镜线的垂直距离相等”和“原点和像点的横坐标平均数为c”应指**原来的点／原像点**。本页后面又明确把“原点”用于坐标原点O，因此初学者会把这里理解成固定的(0,0)。反例就来自本页：关于x=1，P(2,1)映到(0,1)，原像横坐标2与像0的平均为1；若用坐标原点0与像0，平均为0，并不是镜线位置。

最小修补：只把该段两处“原点”改成“原来的点”或“原像点”；保留后面真正指坐标原点的表述。逐段复读，不以TeX序列一致代替语义核对。

### R5 · P2 · 立体解释省略直棱柱条件，中文又额外断言正棱锥

位置：双语 units-area-and-volume #solids（英文31、中文33行），以及中文 #check-solids 解答第55行。

“A triangular prism … three rectangular side faces／三棱柱有…三个长方形侧面”只对**直三棱柱**保证成立。一般棱柱的侧面是平行四边形；无需在本课增加斜棱柱计算，只须给现有模型补上right／直的限制，避免把模型特例写成定义。

中文解答把英文square-based pyramid写成“正四棱锥”。正四棱锥还断言顶点在正方形底面中心正上方；题干／SVG未给这个垂足条件。面、棱、顶点计数5/8/5没有错，但译文比英文多了条件。

最小修补：把矩形侧面限定为right triangular prism，并用“正方形底的四棱锥”对应square-based pyramid；或若确实要考正棱锥，须给明确条件并双语一致。不要靠删替代文字掩盖几何信息。
