| 编号／定位 | 具体发现、影响与最小闭合办法 |
| --- | --- |
| F1：等值分数解释的模型条件。英文第 35 行、中文第 37 行，`same-amount` | 两页把“分子分母同乘任意非零数”直接对应纸带份数变化；中文更明确说“相当于把每份分得更细”。取倍数 1/2 会合并而非细分，取 −2 更不能解释成负数个纸带等份。数值等价规则本身成立，**细分模型的解释范围过宽**。本课最小修补：把这里限定为“同乘正整数，如 2 或 5，把每份再等分”，同除公因数解释为合并；若保留任意非零倍数的抽象结论，要把它与纸带模型分开并给出其依据，不能让一个图承担未说明的推广。 |
| F2：任务首次使用未引入的英文术语。英文 `same-amount` 至 `practice-forms`、`retry-forms`；中文对应位置 | 英文只说 top／bottom，首道独立题却使用 numerator／denominator；中文讲了分子／分母，但未配这两个英文词。`simplest form`、common factor 也没有明确的术语桥梁。数学会做的中文读者可能因题干词汇卡住。**必须在首次任务前引入 numerator（分子）、denominator（分母），并解释 simplest form 是不能再用共同的整数因子约分**，可用已出现的 6/10→3/5 作说明，不需要新增术语表页面。fraction／decimal／percentage 也宜在正文首次出现时配对。`fiction / non-fiction` 的翻译目前藏在同时给出解法方向的提示中；若学生仅因词义打开提示，将无法区分语言帮助和数学帮助。可把必要情境词义放在题旁，不透露先算哪一组。 |
| F3：新小数位值未承接。设计卡“必要先修”、两页 `before-start`、`example-forms` | 设计卡只要求读到百分位，回顾只解释 0.6、0.06，却立即使用 0.375，稍后还有 0.625 和 0.275。3÷8 的结果正确，也允许计算器完成除法；问题是**尚未说明第三位表示千分之一**，初心者可能只会复制显示值。最小补一句并连接已有量：0.375 是 375/1000，即 3 个十分之一、7 个百分之一和 5 个千分之一，乘 100 后百分号前可以是 37.5。无需增加整套长除法；如选择教长除法，再展开实际余数链。单纯把“千分位”改列先修而不给回补，不会补上当前阅读断点。 |
| F4：共同原始基准错误没有对应重试。两页 `mixed-check`→`repair`→`retry-part`／`retry-share` | 综合题正确反馈“下午按剩余票数算，答的是另一题”；但三个错误回补项目没有指向“连续两个时间段仍以同一原总量为基准”，重试 B 是单次求补集，重试 C 是目标比值，均不会重新暴露这个错误。它们各自有效，**只是不能当作该综合错误已修复的证据**。最小闭合：增加这一错误的回补指向，并提供改变数值／情境的共同基准重试；也可让后续既有综合任务承担，但须给出确切位置并再次检查。 |

F1 对应长期标准第 3 节模型条件和可重建解释；F2–F3 对应声明先修、初次独立作答与双语术语支持；F4 对应第 5 节错误原因、具体回补和匹配重试。修补后只重审受影响解释、题目与帮助，并重新记录源码哈希；本报告不直接改文。
