# A2 双语课程大更新：更新日志与总结

日期：2026-10-17。本次整理范围为 A2 纯数学、高等数学、物理及 CH03 化学；验收范围共 45 对、90 页。此范围不代表整个 A-level 资格课程均已完成，也不包含本轮新增生物课程。

## 学生可见的变化

### 物理

- 新增 PH03 中文课程入口及圆周运动、简谐运动、引力场与卫星、电场、电容、电容器充放电的中文对应页，保留英文题干、公式、单位、答案及旧锚点。
- 新增 PH04 热学中英文学习页，组织温度与热量、比热容、比潜热、气体定律、分子动理论、内能与热力学过程的解释、示范和独立练习。
- 补充 RC、比热容测量、Boyle 定律及 Charles 定律的数据分析活动。教学数据明确标为构造数据，提示和反馈分开。
- 修复热学平均动能公式被 Markdown 强调标记拆开的情况，以及手机速查卡片中长计算链末尾被裁切的问题。
- 物理入口保留 56 个旧书签；中英切换保留目标小节。

### 纯数学与高等数学

- 修复积分、弧长与旋转曲面、双曲函数、级数与极限等页面的公式、条件说明、表格及章节归属。
- 在初讲段落中明确模型及适用条件，把过长的独立计算改为可读的显示公式。
- 调整二阶微分方程练习标题，避免题目在学生选法前泄露根型或共振判断。
- 为六课九道旧 AQA 题补充原卷、配套评分材料、考季、题号及核对记录；不把无法恢复的历史来源编造成事实。

### CH03 化学

- 补充绝对熵及计量、实验值与离子模型比较、四类滴定曲线、RP6 电动势原始记录等示范与独立任务。
- 修正氨水少量与过量时的物种、反应式及观察解释，独立核对原子、电荷和计量。
- 补充必要图表的等价说明，避免独立作答前直接暴露完整解答。
- 将手机上被截断的 Tollens 总反应改为三行显示，保留全部反应物、产物、系数及电荷。
- 保留 main 已上线的“A2 化学”命名。

### 阅读与交互

- 统一整理四科标题层级，保留稳定 ID、语言切换及页内定位。
- 图片放大改用原生对话框，支持键盘打开、关闭、焦点返回、适屏与四倍放大，以及放大后的滚动查看。
- 简表自适应宽度，密集比较表保留局部滚动，避免手机说明栏挤成每行两三字。
- 语言选择器反映当前正文语言，保留切换时的锚点。
- 修复页脚访问计数标签中撇号显示为 HTML 实体的问题。

## 仍然保留的边界

- 七个旧物理速查算例标有“原始来源待考”，没有冒称官方题或自拟题。
- 没有开展学生试用、真实实验、真实手机或完整屏幕阅读器验收；技术检查通过不等于学习效果已经验证。
- 部分历史作者设计卡和原始材料无法恢复，详见修复汇总的逐项说明。

## 总结

本次更新把物理中文课程与热学新课连同四科修复整理为可审查的交付版本。学生可以在保留英文考试任务的同时阅读中文解释，并使用分开的提示、反馈、实验数据分析及可操作的图表。后续应继续补足旧例题来源、未制作单元及学生试用证据。
