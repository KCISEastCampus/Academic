## 导入与先修 {#introduction}

- **新学：**从[方法选择](#method)开始，练习完整解释链。
- **作业求助：**按[方法表](#method)区分结构、酸碱反应与水解，再找对应示范。
- **复习：**先做[独立练习](#practice)，再用[速查与纠错](#quick-reference)复核。

**开始前：**应会区分离子、巨型共价与简单分子结构，识别分子内键和分子间作用力，并配平原子与电荷。若不熟悉，先完成[课程首页的先修检查](/zh/alevel/a2-chemistry/#prerequisites)。

第三周期不只是背一个性质趋势。每次解释都按 **结构 → 成键或作用力 → 需要克服的相互作用 → 可观察性质** 写完整。

**先想一想：**SiO₂ 不溶于水，是否说明它不是酸性氧化物？先区分“和水反应”与“和碱反应”。

| 题目要你解释什么 | 第一步 | 完整作答方向 |
| --- | --- | --- |
| 熔点／沸点或状态 | 先辨认结构与粒子 | 点明克服的作用，再联系能量与性质；见[示范 1](#example-1)、[Q5](#q5) |
| 氧化物酸碱性 | 看与酸、碱的反应 | 用配平方程式支持分类，不靠水溶性；见[示范 2](#example-2)、[Q3](#q3) |
| 元素与水、氧或氯反应 | 读冷水／蒸汽／过量等条件 | 确定产物再配平；见[Q1](#q1)、[Q2](#q2) |
| 含氧酸及阴离子结构 | 先连中心原子与 O，再把 H 接在 O 上 | 移去 H⁺ 后保留 O，检查负电荷；见[示范 3](#example-3)、[Q6](#q6) |
| 氯化物加水 | 先区分溶解与水解 | 写实际生成物与 HCl，不能由水中离子倒推原结构；见[示范 4](#example-4)、[Q4](#q4) |

## P1：元素、氧化物与酸碱性 {#elements-and-oxides}

### 结构、作用力与物态变化 {#structure-and-phase-changes}

Na、Mg、Al 是金属，具有金属键；从 Na 到 Al，离子电荷与离域电子数增加、半径减小，金属键一般增强。Si 是巨型共价结构，需要破坏大量共价键才熔化。P₄、S₈、Cl₂ 是分子物质，熔化主要克服分子间作用力；S₈ 的分子较大，分子间作用力比 P₄ 更强。Ar 是单原子物质，粒子间只有较弱的 London forces。

**不要把熔化分子物质解释成“打断分子内共价键”。**先辨认是巨型结构还是独立分子。

#### 示范 1：写完整结构与性质解释（自拟） {#example-1}

**题目：**解释为什么 SiO₂ 的熔点很高，而 SO₂ 的沸点较低。

**方法：**分别识别结构，指出相变时需要克服的作用，最后说明能量差异。不要把两种相变当成同一种温度数据。

1. SiO₂ 是巨型共价结构，Si 与 O 由大量强共价键构成连续网络。
2. 熔化需要破坏网络中的大量强共价键，所需能量大，因此熔点高。
3. SO₂ 是简单分子物质。沸腾主要克服分子之间较弱的作用力，所需能量较小，因此沸点低；不是打断分子内的 S–O 共价键。

**独立检查：**两种物质都有共价键，但相变时克服的作用不同。答案必须包含“结构、克服什么、能量、性质”四环，不能只写“SiO₂ 的键强”。

<span id="与氧氯反应的方程式"></span>

### 生成反应与和水的反应 {#reaction-equations}

**氧化物的生成：**

- $\ce{4Na + O2 -> 2Na2O}$
- $\ce{2Mg + O2 -> 2MgO}$
- $\ce{4Al + 3O2 -> 2Al2O3}$
- $\ce{Si + O2 -> SiO2}$
- $\ce{P4 + 5O2 -> P4O10}$
- $\ce{S + O2 -> SO2}$

SO₃ 常由 $\ce{2SO2 + O2 <=> 2SO3}$ 在适当催化条件下制得；不能把硫燃烧的主要产物写成 SO₃。

**氯化物的生成：**

- $\ce{2Na + Cl2 -> 2NaCl}$
- $\ce{Mg + Cl2 -> MgCl2}$
- $\ce{2Al + 3Cl2 -> 2AlCl3}$
- $\ce{Si + 2Cl2 -> SiCl4}$
- $\ce{P4 + 10Cl2 -> 4PCl5}$

最后一式为氯过量；氯不足时可先生成 PCl₃。上面 AlCl₃ 写组成式；Al₂Cl₆ 是特定相态的结构表示，见[相态边界](#chlorides)。

**Na 与水：**

$$\ce{2Na + 2H2O -> 2NaOH + H2}.$$

与 Mg 比较时，分别说明产物、反应快慢与金属性。按题目要求加状态符号，尤其注意 PCl₅ 室温为固体。

**OxfordAQA CH03 · June 2026 · 01.1 · 2 marks**

> Magnesium reacts slowly with cold water but rapidly with steam.
>
> State one similarity and one difference between the products of these reactions.

<details markdown="1">
<summary>提示</summary>

两次都有哪种气体？两种条件下的固体产物相同吗？

</details>

<details markdown="1">
<summary>评分解析与自查</summary>

MS 第 12 页。

$$\ce{Mg + 2H2O(l) -> Mg(OH)2 + H2}.$$

$$\ce{Mg + H2O(g) -> MgO + H2}.$$

题目已说明速率；重复“蒸汽反应快”没有回答产物的区别。

</details>

### 氧化物结构、酸碱性与水反应 {#oxide-acid-base-character}

| 氧化物 | 结构／成键 | 酸碱性质与主要反应 |
| --- | --- | --- |
| Na₂O | 巨型离子结构 | 碱性；与水形成 NaOH，溶液强碱性 |
| MgO | 巨型离子结构；离子吸引较强，熔点高 | 碱性；与水反应／溶解程度小，形成微溶 Mg(OH)₂；与酸反应 |
| Al₂O₃ | 巨型晶格，成键含离子性与共价性 | 两性；与酸和强碱反应，不与水明显反应 |
| SiO₂ | 巨型共价结构 | 酸性；不与水反应，可与热浓碱反应 |
| P₄O₁₀ | 分子型共价氧化物（常见分子形式） | 酸性；与水形成 H₃PO₄ |
| SO₂、SO₃ | 分子型共价氧化物 | 酸性；与水分别形成酸性体系、H₂SO₄ |
{: .wide-table}

跨周期由金属性转向非金属性，氧化物总体从碱性经两性转为酸性。**水溶性不决定酸碱分类**；SiO₂ 的酸性可由其与碱反应说明。

必须会写的反应：

$$\ce{Na2O + H2O -> 2NaOH}.$$

$$\ce{MgO + 2H+ -> Mg^{2+} + H2O}.$$

$$\ce{Al2O3 + 6H+ -> 2Al^{3+} + 3H2O}.$$

$$\ce{Al2O3 + 2OH^- + 3H2O -> 2[Al(OH)4]^-}.$$

$$\ce{SiO2 + 2OH^- -> SiO3^{2-} + H2O}.$$

后两式涉及合适的强碱与反应条件，不能理解为所有氧化物放入稀碱都立即反应。

$$\ce{P4O10 + 6H2O -> 4H3PO4}.$$

$$\ce{SO3 + H2O -> H2SO4}.$$

SO₂ 溶于水形成酸性平衡，可用 $\ce{SO2 + H2O <=> H2SO3}$ 表示；它不像 Na₂O 那样生成强碱。H₃PO₄ 和该含 SO₂ 的体系是弱酸体系，H₂SO₄ 的第一步电离很强，因此不能只按“酸的分子里 H 的个数”比较相同浓度的 pH。

#### 示范 2：水溶性不决定酸碱分类（自拟） {#example-2}

**题目：**Al₂O₃ 不与水明显反应，为什么仍可称为两性氧化物？怎样证明 SiO₂ 是酸性氧化物？

**方法：**用与酸、碱的反应作证据；不从是否溶于水下结论。

1. Al₂O₃ 与酸反应生成 Al³⁺ 和水，也能在合适的强碱条件下生成四羟基合铝酸根；上面两条方程式分别证明碱性与酸性行为，因此它是两性的。
2. SiO₂ 可与热浓碱反应生成硅酸盐和水。上面的离子方程式支持其酸性分类，即使它不与水反应。
3. **答案：**两性需要酸、碱两类反应证据；酸性氧化物可用与碱反应作证据，不能把“不溶于水”当成“中性”。

**独立检查：**Al₂O₃ 与碱的式子左右各有 2 个 Al、8 个 O、8 个 H，总电荷均为 −2；SiO₂ 与碱的式子两侧各有 1 个 Si、4 个 O、2 个 H，总电荷也为 −2。

<span id="酸及阴离子的结构"></span>

### 酸及阴离子的结构 {#oxoacid-structures}

画结构时，把酸性 H 接在 O 上，然后依次移去 H⁺、给对应 O 标负电荷：

| 酸的连接方式 | 阴离子 | 画图检查 |
| --- | --- | --- |
| H₃PO₄：$\ce{O=P(OH)3}$ | H₂PO₄⁻、HPO₄²⁻、PO₄³⁻ | P 周围四个 O，四面体排列；三条 O–H 可逐步电离 |
| H₂SO₃ 的教材表示：$\ce{O=S(OH)2}$ | HSO₃⁻、SO₃²⁻ | S 周围三个 O，并有孤对电子，SO₃²⁻ 为三角锥形 |
| H₂SO₄：$\ce{O=S(=O)(OH)2}$ | HSO₄⁻、SO₄²⁻ | S 周围四个 O，四面体排列；两个 H 连在 O 上 |
| SiCl₄ 水解的含 Si–OH 中间物：$\ce{Si(OH)4}$ | 碱反应常以 SiO₃²⁻ 表示硅酸盐 | 四个 O 围绕 Si；可缩合成含 Si–O–Si 的水合 SiO₂ |
{: .wide-table}

这些是连接关系与考试画图模型；阴离子存在电子离域，不能把某一条双键的位置当作唯一真实局域结构。

#### 示范 3：从含氧酸画出共轭碱（自拟） {#example-3}

**题目：**用一种有效的连接式表示 H₃PO₄ 与 H₂PO₄⁻。

**方法：**先连接 P 与四个 O，把酸性 H 放在 O 上；只移去一个 H⁺。

1. H₃PO₄ 可画成 O=P(OH)₃：一个 P=O 和三个 P–O–H。
2. 移去一条 O–H 上的 H⁺，得到 O=P(OH)₂(O⁻)；原来的 O 留在结构中。
3. **答案：**H₂PO₄⁻ 仍有四个 O、两个 O–H，整体带一个负电荷。P 周围四个成键方向呈四面体排列。

**独立检查：**两式都含一个 P 和四个 O；H 从 3 减至 2，酸变成 −1 阴离子。酸电离产物的总电荷为 −1 + 1 = 0，与中性酸一致；没有移去 OH⁻。

<span id="p2氯化物溶解与水解"></span>

## P2：氯化物、溶解与水解 {#chlorides}

先区分两个过程：**dissolution** 让原有物种进入溶液；**hydrolysis** 涉及物种与水反应。跨周期的氯化物不能全部用同一种模型解释。

| 氯化物 | 结构线索 | 加水后的解释 |
| --- | --- | --- |
| NaCl | 离子晶体 | 溶解为 Na⁺、Cl⁻，溶液近中性 |
| MgCl₂ | 主要为离子晶体 | 溶解；水合 Mg²⁺ 使溶液略显酸性 |
| AlCl₃ | 结构依相态而变；液体可用 Al₂Cl₆ 二聚体表示 | 在水中形成水合 Al³⁺，发生酸性水解 |
| SiCl₄ | 简单分子，共价 | 与水反应，形成含硅产物及 HCl，出现酸性体系 |
| PCl₅ | 固态可用 $\ce{[PCl4]+[PCl6]^-}$ 描述；气态为分子 | 过量水最终生成 H₃PO₄ 和 HCl |
{: .wide-table}

Al₂Cl₆ 中有桥联氯和配位键，不能把它画成两个互不相连的 AlCl₃。水合 Al³⁺ 的酸性在 [离子反应](/zh/alevel/a2-chemistry/ions-in-solution/#aqua-acidity) 中继续解释。

解释氯化物相变，先指定相态及结构。NaCl、MgCl₂ 的巨型离子晶格有强的离子间吸引；SiCl₄ 是简单分子，其相变主要克服分子间作用力。PCl₅ 的固态结构与气态不同，不能把右侧所有氯化物都当作常温液体。

**AlCl₃ 的模型边界：**Al₂Cl₆ 二聚体用于描述液体及适当温度范围内的蒸气，不等于常温晶体由互相独立的二聚体构成。晶态 AlCl₃ 熔化时结构与 Al 配位环境会改变；不能把整个变化说成“只克服二聚体之间的分子间力”。[Bernasconi 等（2002）的研究摘要](https://pubs.rsc.org/en/content/articlelanding/2002/qu/b107715e)区分晶态与二聚体液态，并报告 Al 配位由六变四。本课用这一点限制模型，不增加晶体理论的必考要求。

$$\ce{SiCl4 + 2H2O -> SiO2 + 4HCl}.$$

$$\ce{PCl5 + 4H2O -> H3PO4 + 5HCl}.$$

SiCl₄ 水解可先经含 Si–OH 的物种，再形成水合二氧化硅；上述为常用总体式。观察题应区别“白色烟雾”“白色沉淀”“白色固体”，按实际情境作答。

### 示范 4：氯化物溶解与水解（自拟） {#example-4}

**题目：**比较 NaCl 和 SiCl₄ 加入水后的过程与酸碱性。

**方法：**先判断原物质结构，再问是否只是原有离子进入水中，还是生成了新物质。

1. NaCl 是巨型离子晶体；溶解后原有 Na⁺、Cl⁻ 分散在水中，溶液近中性。
2. SiCl₄ 是简单分子物质；它与水发生水解，按上面的总体式生成含硅产物和 HCl，水溶液显酸性。
3. **答案：**NaCl 的过程是溶解，SiCl₄ 的过程包含化学反应；水溶液中的离子并不证明原物质是离子晶体。

**独立检查：**SiCl₄ 总体水解式两侧各含 Si 1、Cl 4、H 4、O 2；HCl 是新生成物，不能说是原晶格中的 H⁺ 溶出来。

### Q5 结构与性质解释（自拟） {#q5}

不用看[示范 1](#example-1)，完整解释 SiO₂ 高熔点与 SO₂ 低沸点。另解释为什么“SO₂ 沸腾时打断 S–O 共价键”是错误的。

<details markdown="1">
<summary>提示</summary>

每种物质写四环：结构、克服的作用、所需能量、性质。

</details>

<details markdown="1">
<summary>评分解析与自查</summary>

自拟题，无官方分值。SiO₂ 为巨型共价网络；熔化需要破坏大量强 Si–O 共价键，能量需求大，熔点高。SO₂ 为简单分子物质；沸腾主要克服较弱分子间作用力，能量需求较小，沸点低。S–O 共价键位于分子内部，沸腾不是把 SO₂ 分子拆成原子。检查两个解释是否都写完四环，而不是只列结构名称。

</details>

从 H₃PO₄ 画出 HPO₄²⁻ 的一种有效连接式，说明哪些原子被移去，并给出 P 周围的排列。检查原子个数和总电荷。

<details markdown="1">
<summary>提示</summary>

参考[示范 3](#example-3)，这次移去两个 H⁺，保留全部 O。

</details>

<details markdown="1">
<summary>评分解析与自查</summary>

自拟题，无官方分值。一种连接式为 O=P(OH)(O⁻)₂；含 1 个 P、4 个 O、1 个 H，整体电荷 −2，P 周围四面体排列。移去两个 H⁺ 后，阴离子与两个 H⁺ 的总电荷为零。等价的有效共振连接表示也可；不要把某一条双键的位置当作唯一真实结构。

</details>

### Q7 过量水中的 PCl₅（自拟） {#q7}

写出 PCl₅ 与过量水反应的总体方程式，并说明最终溶液为什么呈酸性。

<details markdown="1">
<summary>提示</summary>

先确定最终生成 H₃PO₄ 和 HCl，再配平水。

</details>

<details markdown="1">
<summary>评分解析与自查</summary>

自拟题，无官方分值。方程式见[P2](#chlorides)：1 mol PCl₅ 与 4 mol 水生成 1 mol H₃PO₄ 和 5 mol HCl。两侧各有 P 1、Cl 5、H 8、O 4。产物中的 HCl 和 H₃PO₄ 形成酸性体系；不要写成只是 PCl₅ 中原有离子溶解。

</details>

## 速查与纠错 {#quick-reference}

| 判断任务 | 速查 | 常见陷阱 |
| --- | --- | --- |
| 元素结构 | Na/Mg/Al 金属；Si 巨型共价；P₄/S₈/Cl₂ 分子；Ar 单原子 | 分子物质相变不等于断开分子内共价键 |
| 氧化物酸碱性 | Na₂O/MgO 碱性；Al₂O₃ 两性；SiO₂、磷与硫氧化物酸性 | 水溶性不能直接判定酸碱性 |
| 氧化物反应 | 见[反应方程式](#reaction-equations)与 P1 的酸碱反应 | 硫燃烧的主要产物是 SO₂，不是 SO₃ |
| 氯化物加水 | NaCl 溶解；SiCl₄/PCl₅ 水解；Al³⁺ 水合离子酸性 | 有酸性水溶液不证明原物质是离子晶体 |
| 含氧酸电离 | 移去 O–H 上的 H⁺，留下 O | 移去一整个 OH⁻ 会改变氧原子个数 |
