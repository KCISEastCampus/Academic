## 代数与函数 {#algebra-and-functions}

如果你刚开始学习 A2 纯数学，请从这里开始，并按顺序学习这些课程。

1. <span id="p21-algebra-and-functions"></span>**[函数](/zh/alevel/a2-mathematics/functions/)** — 定义域、值域、复合函数和反函数。
2. **[绝对值函数与变换](/zh/alevel/a2-mathematics/modulus-and-transformations/)** — 图像、变换、方程和不等式。
3. **[代数分式与多项式除法](/zh/alevel/a2-mathematics/algebraic-fractions-and-division/)** — 化简、除法和余数。
4. **[部分分式](/zh/alevel/a2-mathematics/partial-fractions/)** — 分解、重复因式及其在积分中的应用。
5. <span id="p22-sequences-and-series"></span>**[二项式级数](/zh/alevel/a2-mathematics/binomial-series/)** — 展开、近似和适用范围。

## 三角函数、指数函数与对数函数 {#trigonometry-exponentials-and-logarithms}

- <span id="p24-trigonometry"></span>**[三角函数与公式](/zh/alevel/a2-mathematics/trigonometric-functions-and-formulae/)** — 函数、恒等式、和差角公式（compound angle formulae）和二倍角公式。
- <span id="p25-exponentials-and-logarithms"></span>**[指数函数与对数函数](/zh/alevel/a2-mathematics/exponential-and-logarithmic-functions/)** — 增长、衰减、对数法则和方程。

## 微积分 {#calculus}

学习参数方程求导之前先学习微分，学习微分方程之前先学习积分。

1. <span id="p26-differentiation"></span>**[微分](/zh/alevel/a2-mathematics/differentiation/)** — 求导法则、切线、法线和驻点。
2. <span id="p23-coordinate-geometry"></span>**[参数方程](/zh/alevel/a2-mathematics/parametric-equations/)** — 直角坐标方程（Cartesian equations）、曲线和求导。
3. <span id="p27-integration"></span>**[积分：方法选择](/zh/alevel/a2-mathematics/integration/)** — 标准积分、换元积分法、分部积分法和部分分式。
4. **[积分：三角积分与应用](/zh/alevel/a2-mathematics/integration-applications/)** — 三角积分、面积和旋转体体积。
5. <span id="p28-differential-equations"></span>**[微分方程](/zh/alevel/a2-mathematics/differential-equations/)** — 分离变量、给定条件和模型。

## 数值方法、向量与证明 {#numerical-methods-vectors-and-proof}

- <span id="p29-numerical-methods"></span>**[数值方法](/zh/alevel/a2-mathematics/numerical-methods/)** — 根、迭代和数值积分。
- <span id="p210-vectors"></span>**[向量](/zh/alevel/a2-mathematics/vectors/)** — 直线、数量积、角度和距离。
- **[数学证明](/zh/alevel/a2-mathematics/mathematical-proof/)** — 直接证明、反证法和反例。
